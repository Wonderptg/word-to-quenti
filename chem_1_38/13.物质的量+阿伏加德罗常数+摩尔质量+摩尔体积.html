化学计量的核心：物质的量

—— 连接微观粒子与宏观世界的桥梁

为什么要学习“物质的量”？

100mL 水中约有 3.3 x 10²⁴ 个水分子！

直接数粒子数目是不现实的，我们需要一个更宏观的“集合”单位来描述微观粒子。

定义与使用规则

物质的量 (n) 是一个物理量，表示含有一定数目粒子的集合体，单位为摩尔 (mol)。

正确用法 (√)

√ 1 mol 电子

√ 1 mol H₂O 分子

√ 1 mol Na⁺

*只适用于微观粒子*

错误用法 (×)

× 1 mol 苹果

× 1 mol 氧

*必须指明粒子种类*

阿伏加德罗常数 (Nₐ)

1 摩尔任何粒子的集合体，所含的粒子数都是一个固定的值，这个值就是阿伏加德罗常数。

Nₐ ≈ 6.02 x 10²³ mol⁻¹

核心公式 1：

n = N / Nₐ

物质的量 (n) = 粒子总数 (N) / 阿伏加德罗常数 (Nₐ)

摩尔质量 (M) - 质量的桥梁

摩尔质量 (M) 指单位物质的量的物质所具有的质量。

① 微观粒子

1个碳原子

相对原子质量 ≈ 12

× 6.02x10²³

② 宏观集合

1摩尔碳原子

摩尔质量 ≈ 12 g/mol

摩尔质量 - 结论与公式

关键结论：以 g/mol 为单位时，摩尔质量在数值上等于其相对原子/分子质量。

核心公式 2：

n = m / M

物质的量 (n) = 质量 (m) / 摩尔质量 (M)

标况下的气体摩尔体积

在标准状况 (标况) 下，即 0℃, 101 kPa 时, 1 mol 任何气体的体积都基本相同。

标况下 (0℃, 101 kPa)

核心公式 3：

n = V / Vₘ

物质的量 (n) = 气体体积 (V) / 气体摩尔体积 (Vₘ), 标况下 Vₘ≈22.4 L/mol

核心换算关系 (一)

微观粒子数 (N)

连接微观与宏观的基石

n = N / Nₐ

宏观质量 (m)

最常用的宏观物理量

n = m / M

核心换算关系 (二)

气体体积 (V)

特殊条件下的快捷换算
(标准状况)

n = V / Vₘ

溶液浓度 (C)

描述溶液组成的物理量

n = C · V(溶液)

使用 22.4 L/mol 的两大前提

必须同时满足以下两个条件，才能使用 22.4 L/mol 进行计算：

① 条件：标准状况

(0℃, 101 kPa)

② 状态：气体

(纯净气体或混合气体)

反例：标况下的水 (H₂O) 是液态或固态，1 mol 水的体积不是 22.4 L。

随堂练习 (一)

下列说法中，可以使用“物质的量”这个物理量的是？

(A) 5个苹果

(B) 0.5 mol 氧气分子

(C) 1 摩尔人

(D) 2 mol 氢

练习 (一)：解析

答案：(B)

解析：

物质的量只适用于描述微观粒子，且必须指明粒子的具体种类。(A)和(C)是宏观物体。(D)中的“氢”指代不明，可以是氢原子或氢分子。

随堂练习 (二)

3.01 x 10²³ 个 CO₂ 分子的物质的量是多少？

(A) 1 mol

(B) 0.5 mol

(C) 2 mol

(D) 6.02 x 10²³ mol

练习 (二)：解析

答案：(B)

解析：

根据公式 n = N / Nₐ，可得 n = (3.01 x 10²³) / (6.02 x 10²³ mol⁻¹) = 0.5 mol。

随堂练习 (三)

49g 硫酸 (H₂SO₄) 的物质的量是多少？ (H₂SO₄的摩尔质量为 98 g/mol)

(A) 0.25 mol

(B) 0.5 mol

(C) 1 mol

(D) 2 mol

练习 (三)：解析

答案：(B)

解析：

根据公式 n = m / M，可得 n = 49g / 98 g/mol = 0.5 mol。

随堂练习 (四)

在标准状况下，11.2 L 的氮气 (N₂) 的物质的量是多少？

(A) 0.25 mol

(B) 0.5 mol

(C) 1 mol

(D) 2 mol

练习 (四)：解析

答案：(B)

解析：

根据公式 n = V / Vₘ，在标准状况下 Vₘ ≈ 22.4 L/mol，可得 n = 11.2 L / 22.4 L/mol = 0.5 mol。

随堂练习 (五)

下列哪种情况下，1 mol 物质的体积约为 22.4 L？

(A) 标准状况下的水

(B) 25℃, 101 kPa 时的氧气

(C) 标准状况下的氦气

(D) 标准状况下的酒精

练习 (五)：解析

答案：(C)

解析：

使用 22.4 L/mol 必须同时满足“标准状况”和“气体”两个条件。(A)和(D)在标况下不是气体，(B)不是标准状况。只有(C)同时满足两个条件。
