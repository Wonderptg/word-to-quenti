铁三角：氧化关系 (Fe → Fe²⁺)

将 0 价的铁氧化成 +2 价，需要使用较弱的氧化剂。

常见反应

  • Fe + 2H⁺ → Fe²⁺ + H₂↑
  • Fe + S → FeS
  • Fe + Cu²⁺ → Fe²⁺ + Cu
  • Fe + 2Fe³⁺ → 3Fe²⁺ (归中)

铁三角：氧化关系 (Fe → Fe³⁺)

将 0 价的铁氧化成 +3 价，需要使用较强的氧化剂。

强氧化剂

2Fe + 3Cl₂ → 2FeCl₃

与浓硝酸/浓硫酸 (加热)

铁三角：氧化关系 (Fe²⁺ → Fe³⁺)

+2价的铁具有还原性，可以被多种氧化剂氧化为+3价。

常见氧化剂

  • O₂
  • Cl₂ / Br₂
  • H₂O₂
  • HNO₃
  • H₂SO₄(浓)
  • KMnO₄(酸性)
  • K₂Cr₂O₇(酸性)

二价铁的氧化 (一)

与酸性高锰酸钾

现象：紫红色褪去。

5Fe²⁺ + MnO₄⁻ + 8H⁺ → 5Fe³⁺ + Mn²⁺ + 4H₂O

与酸性重铬酸钾

现象：溶液由橙色变为绿色。

6Fe²⁺ + Cr₂O₇²⁻ + 14H⁺ → 6Fe³⁺ + 2Cr³⁺ + 7H₂O

二价铁的氧化 (二)

与过氧化氢

H₂O₂是绿色氧化剂，产物为水。

2Fe²⁺ + H₂O₂ + 2H⁺ → 2Fe³⁺ + 2H₂O

与稀硝酸

Fe²⁺的还原性使稀硝酸的还原产物依然是NO。

3Fe²⁺ + NO₃⁻ + 4H⁺ → 3Fe³⁺ + NO↑ + 2H₂O

铁三角：还原关系 (→ Fe)

将铁的化合物还原为铁单质，需要使用较强的还原剂。

常见反应

2Al + Fe₂O₃ (高温) → 2Fe + Al₂O₃

Fe₂O₃ + 3CO (高温) → 2Fe + 3CO₂

铁三角：还原关系 (Fe³⁺ → Fe²⁺)

将 +3 价的铁还原为 +2 价，使用还原性相对较弱的物质即可。

常见还原剂

Fe
Cu
H₂S / S²⁻
SO₂
I⁻

三价铁的还原：离子方程式

2Fe³⁺ + Cu → 2Fe²⁺ + Cu²⁺

2Fe³⁺ + H₂S → 2Fe²⁺ + S↓ + 2H⁺

2Fe³⁺ + SO₂ + 2H₂O → 2Fe²⁺ + SO₄²⁻ + 4H⁺

2Fe³⁺ + 2I⁻ → 2Fe²⁺ + I₂

随堂练习 (一)

下列哪种物质能将铁单质直接氧化为+3价？

(A) 盐酸

(B) 碘单质

(C) 氯气

(D) 硫单质

练习 (一)：解析

答案：(C)

解析：

氯气 (Cl₂) 是强氧化剂，可以将铁直接氧化到最高的+3价。而盐酸、碘和硫都是相对较弱的氧化剂，只能将铁氧化到+2价。

随堂练习 (二)

为了检验某溶液中是否含有Fe²⁺，不应选用的试剂是？

(A) 氯水

(B) 酸性高锰酸钾溶液

(C) KSCN溶液

(D) H₂O₂溶液

练习 (二)：解析

答案：(C)

解析：

KSCN溶液是用来检验 Fe³⁺ 的（溶液变血红色），它与 Fe²⁺ 不发生颜色反应。A、B、D都是氧化剂，可以氧化Fe²⁺并伴随自身明显的颜色变化（如KMnO₄褪色），或与指示剂配合检验Fe²⁺被氧化。

随堂练习 (三)

将铁粉加入到FeCl₃溶液中，充分反应后，溶液中的主要阳离子是？

(A) Fe³⁺

(B) Fe²⁺

(C) Fe³⁺ 和 Fe²⁺

(D) H⁺

练习 (三)：解析

答案：(B)

解析：

该反应是归中反应：Fe + 2Fe³⁺ → 3Fe²⁺。铁单质会将溶液中的三价铁离子全部还原为二价铁离子。

随堂练习 (四)

下列离子方程式书写正确的是？

(A) Fe + H₂SO₄(稀) → Fe³⁺ + H₂↑ + SO₄²⁻

(B) 2Fe³⁺ + Cu → 2Fe²⁺ + Cu²⁺

(C) Fe²⁺ + Cl₂ → Fe³⁺ + 2Cl⁻

(D) Fe + 2H⁺ → Fe³⁺ + H₂↑

练习 (四)：解析

答案：(B)

解析：

A和D：铁与稀酸反应生成Fe²⁺，不是Fe³⁺。C：电荷不守恒，应为 2Fe²⁺ + Cl₂ → 2Fe³⁺ + 2Cl⁻。B正确，铜可以将三价铁还原为二价铁。

随堂练习 (五)

如何除去FeCl₂溶液中的少量FeCl₃杂质？

(A) 加入过量铁粉，然后过滤

(B) 通入足量氯气

(C) 加入氢氧化钠溶液，然后过滤

(D) 加入铜粉，然后过滤

练习 (五)：解析

答案：(A)

解析：

利用反应 Fe + 2Fe³⁺ → 3Fe²⁺，加入过量的铁粉可以将FeCl₃杂质转化为FeCl₂。过量的铁粉可以通过过滤除去，该方法不会引入新的杂质。
