氨、铵盐与硝酸

—— 重要的含氮化合物

氨 (NH₃) 的物理性质

颜色/气味：无色、有刺激性气味的气体 (类似公厕味)。

密度：相对分子质量17 < 空气平均(约29)，密度比空气小。

溶解性：极易溶于水 (1:700)，水溶液称氨水。

熔沸点：易液化，液氨汽化吸热，可用作制冷剂。

氨的化学性质：与水反应

氨气极易溶于水，且部分与水反应生成一水合氨 (NH₃·H₂O)。

反应方程式

NH₃ + H₂O ⇌ NH₃·H₂O

NH₃·H₂O ⇌ NH₄⁺ + OH⁻

一水合氨是弱碱，能部分电离出OH⁻，使氨水显弱碱性。

一水合氨不稳定，受热易分解为NH₃和H₂O。

氨水成分：分子 (H₂O, NH₃·H₂O, NH₃)，离子 (NH₄⁺, OH⁻, H⁺)。

氨的化学性质：与酸反应

氨气是碱性气体，能与酸反应生成铵盐。

与氯化氢反应 (生成白烟)

NH₃ + HCl → NH₄Cl (固)

现象：产生白烟 (NH₄Cl固体小颗粒)。可用于相互检验。

与硫酸/硝酸反应 (生成肥料)

2NH₃ + H₂SO₄ → (NH₄)₂SO₄

NH₃ + HNO₃ → NH₄NO₃

生成物是常见的铵态氮肥。

氨的化学性质：还原性

氨中的氮为-3价 (最低价)，具有还原性。

氨的催化氧化 (工业制硝酸基础)

氨气在催化剂和加热条件下被氧气氧化。

4NH₃ + 5O₂ (催化剂, Δ) → 4NO + 6H₂O

注意产物是NO，而不是N₂。

铵盐 (NH₄⁺盐) 的性质

物理性质：多为无色晶体，均易溶于水。

用途：重要的氮肥 (如 (NH₄)₂SO₄, NH₄HCO₃, NH₄NO₃)。

化学性质1：受热易分解。

NH₄Cl(s) (Δ) → NH₃(g) + HCl(g)

NH₄HCO₃(s) (Δ) → NH₃(g) + H₂O(g) + CO₂(g)

化学性质2：与碱共热产生氨气。

NH₄⁺ + OH⁻ (Δ) → NH₃↑ + H₂O (铵根离子的检验方法)

储存与施用：需密封、阴凉存放，不能与碱性物质(如草木灰)混合施用。

硝酸 (HNO₃)：物理性质与不稳定性

物理性质

  • 无色、有刺激性气味液体
  • 易挥发 (浓度越大越易挥发，形成白雾)
  • 任意比例溶于水

不稳定性

硝酸见光或受热易分解。

4HNO₃ (光/Δ) → 4NO₂↑ + O₂↑ + 2H₂O

分解产生的NO₂(红棕色)溶于硝酸，使浓硝酸常呈黄色。

保存：棕色瓶、阴凉处、玻璃塞。

硝酸 (HNO₃)：强酸性与强氧化性

强酸性

硝酸是一元强酸，具有酸的通性 (与碱、碱性氧化物、某些盐反应)。

强氧化性 (核心！)

浓硝酸和稀硝酸都具有强氧化性，能与绝大多数金属 (除Au, Pt) 和某些非金属反应，反应不产生H₂！

还原产物：
浓HNO₃ → NO₂ (主要)
稀HNO₃ → NO (主要)

硝酸与金属的反应规律

与铜反应 (不活泼金属代表)

Cu + 4HNO₃(浓) → Cu(NO₃)₂ + 2NO₂↑ + 2H₂O

3Cu + 8HNO₃(稀) → 3Cu(NO₃)₂ + 2NO↑ + 4H₂O

与铁、铝反应 (活泼金属代表)

常温下：遇浓硝酸发生钝化。

加热时：与浓硝酸反应生成Fe³⁺/Al³⁺ 和 NO₂。

与稀硝酸反应：
- Fe少量 → Fe³⁺ + NO
- Fe过量 → Fe²⁺ + NO

硝酸的工业制法 (氨氧化法)

核心流程：利用氨气经过一系列氧化反应最终制得硝酸。

第一步：氨的催化氧化
4NH₃ + 5O₂ (催化剂, Δ) → 4NO + 6H₂O

第二步：NO氧化为NO₂
2NO + O₂ → 2NO₂

第三步：NO₂与水反应
3NO₂ + H₂O → 2HNO₃ + NO (NO可循环利用)

随堂练习 (一)

下列关于氨气的说法，错误的是？

(A) 无色有刺激性气味的气体

(B) 密度比空气大

(C) 极易溶于水，水溶液呈碱性

(D) 液氨可用作制冷剂

练习 (一)：解析

答案：(B)

解析：

氨气的相对分子质量为17，小于空气的平均相对分子质量(约29)，因此其密度比空气小。

随堂练习 (二)

检验某溶液中是否含有NH₄⁺离子，通常采用的方法是？

(A) 加入盐酸，观察是否有气体产生

(B) 加入氢氧化钠溶液并加热，用湿润的红色石蕊试纸检验产生的气体

(C) 加入硝酸银溶液，观察是否有沉淀产生

(D) 焰色反应

练习 (二)：解析

答案：(B)

解析：

铵根离子(NH₄⁺)的检验方法是：向待测液中加入强碱溶液（如NaOH）并加热，若产生能使湿润的红色石蕊试纸变蓝的气体（氨气），则证明含有NH₄⁺。

随堂练习 (三)

关于硝酸的说法，错误的是？

(A) 浓硝酸和稀硝酸都具有强氧化性

(B) 浓硝酸因分解产生的NO₂而常呈黄色

(C) 铁、铝在冷的浓硝酸中会发生钝化

(D) 铜与稀硝酸反应生成H₂

练习 (三)：解析

答案：(D)

解析：

硝酸（无论是浓是稀）与金属反应时，由于其强氧化性，不产生氢气(H₂)。其还原产物通常是氮的氧化物（如NO₂, NO）或其他含氮物质。

随堂练习 (四)

工业制硝酸的核心反应不包括？

(A) N₂ + 3H₂ ⇌ 2NH₃

(B) 4NH₃ + 5O₂ → 4NO + 6H₂O

(C) 2NO + O₂ → 2NO₂

(D) 3NO₂ + H₂O → 2HNO₃ + NO

练习 (四)：解析

答案：(A)

解析：

工业制硝酸（氨氧化法）的主要步骤是 B (氨的催化氧化)、C (NO氧化为NO₂)、D (NO₂与水反应生成硝酸)。反应 A (工业合成氨) 是制备硝酸的原料氨气的过程，但不属于制硝酸的核心反应步骤。

随堂练习 (五)

常温下，下列物质能用铝制容器盛放的是？

(A) 稀盐酸

(B) 浓硝酸

(C) 稀硝酸

(D) NaOH溶液

练习 (五)：解析

答案：(B)

解析：

常温下，铝(Al)在浓硝酸（或浓硫酸）中会发生钝化，表面生成致密的氧化膜，阻止反应继续进行，因此可以用铝制容器盛放冷的浓硝酸。铝与稀盐酸、稀硝酸、NaOH溶液都会发生反应。
