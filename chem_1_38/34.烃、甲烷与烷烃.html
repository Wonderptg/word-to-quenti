烃、甲烷与烷烃

—— 有机化学的起点

烃 (Hydrocarbon) 的概念与分类

定义：仅含碳、氢两种元素的有机化合物，又称碳氢化合物。

分类方式一：按碳碳键类型

饱和烃 (烷烃)

分子中碳原子间只含碳碳单键 (C-C)。

例：乙烷 (CH₃-CH₃), 环丁烷

不饱和烃

分子中含有碳碳双键 (C=C) 或碳碳三键 (C≡C) 或苯环。

例：乙烯 (CH₂=CH₂), 乙炔 (CH≡CH), 苯

烃的分类方式二：按碳骨架结构

链状烃

碳原子连接成链状，分子中不存在环。

包括：链状烷烃、链状烯烃、链状炔烃。

环状烃

碳原子连接成环状结构。

包括：脂环烃 (如环丙烷, 环丁烯) 和 芳香烃 (含苯环，如苯, 甲苯, 萘)。

甲烷 (Methane, CH₄)：物理性质

颜色/气味：无色、无味的气体。

密度：相对分子质量16 < 空气平均(约29)，密度比空气小。

溶解性：极难溶于水。

安全性：本身无毒，但易燃易爆。为安全起见，天然气中常加入有特殊臭味的物质。

甲烷 (Methane, CH₄)：化学性质

通常状况下性质稳定，不与强酸、强碱、强氧化剂 (如 KMnO₄) 反应。

1. 氧化反应 (燃烧)

CH₄ + 2O₂ (点燃) → CO₂ + 2H₂O

燃烧现象

甲烷 (Methane, CH₄)：化学性质

2. 取代反应 (与卤素)

在光照条件下，甲烷中的氢原子可被卤素原子 (如 Cl, Br) 逐步取代。

CH₄ + Cl₂ (光照) → CH₃Cl (一氯甲烷) + HCl

CH₃Cl + Cl₂ (光照) → CH₂Cl₂ (二氯甲烷) + HCl

CH₂Cl₂ + Cl₂ (光照) → CHCl₃ (三氯甲烷/氯仿) + HCl

CHCl₃ + Cl₂ (光照) → CCl₄ (四氯甲烷/四氯化碳) + HCl

特点：光照是必要条件；反应是连锁、逐步进行；产物是混合物 (多种氯代甲烷 + HCl)。

甲烷与氯气取代反应的实验现象

  • 试管内气体黄绿色变浅 (Cl₂ 消耗)。
  • 试管壁出现油状液滴 (CH₂Cl₂, CHCl₃, CCl₄)。
  • 可能观察到白雾 (HCl 溶于水蒸气)。
  • 试管内液面上升 (HCl 易溶于水，气体体积减小)。

烷烃 (Alkanes)：物理性质

链状烷烃通式：CnH2n+2 (n≥1)。

熔沸点：相对较低，随碳原子数(n)增多而逐渐升高。

状态 (常温常压)：
- n ≤ 4：气态 (甲烷~丁烷)
- 5 ≤ n ≤ 16/17：液态
- n > 16/17：固态

密度：均小于水，随碳原子数增多而逐渐增大。

溶解性：难溶于水，易溶于有机溶剂。

烷烃 (Alkanes)：化学性质

与甲烷类似，烷烃通常性质稳定，主要发生两类反应：

1. 氧化反应 (燃烧)

完全燃烧生成 CO₂ 和 H₂O，放出大量热。

CnH2n+2 + (3n+1)/2 O₂ (点燃) → nCO₂ + (n+1)H₂O

2. 取代反应 (与卤素)

在光照条件下，氢原子可被卤素原子 (Cl, Br) 逐步取代。

CnH2n+2 + X₂ (光照) → CnH2n+1X + HX

产物是多种卤代烃和卤化氢的混合物。

随堂练习 (一)

下列物质中，属于烃类的是？

(A) CH₃OH (甲醇)

(B) C₂H₄ (乙烯)

(C) CO₂ (二氧化碳)

(D) CCl₄ (四氯化碳)

练习 (一)：解析

答案：(B)

解析：

烃类是仅含碳(C)和氢(H)两种元素的有机化合物。
A. 甲醇含氧元素。
B. 乙烯只含碳和氢，属于烃类。
C. 二氧化碳是无机物。
D. 四氯化碳含氯元素。

随堂练习 (二)

关于甲烷分子结构的说法，正确的是？

(A) 平面正方形结构

(B) 直线形结构

(C) 正四面体结构

(D) 三角锥形结构

练习 (二)：解析

答案：(C)

解析：

甲烷(CH₄)分子中的碳原子位于中心，四个氢原子位于顶点，构成一个正四面体结构，所有C-H键键长相等，所有H-C-H键角相等 (109°28′)。

随堂练习 (三)

甲烷与氯气发生取代反应的必要条件是？

(A) 加热

(B) 加压

(C) 光照

(D) 催化剂

练习 (三)：解析

答案：(C)

解析：

甲烷与卤素单质（如氯气、溴蒸气）的取代反应需要在光照条件下才能发生。无光照或黑暗中不反应。

随堂练习 (四)

下列关于烷烃物理性质的说法，错误的是？

(A) 熔沸点随碳原子数增多而升高

(B) 密度都小于水

(C) 都易溶于水

(D) 常温下，碳原子数少的烷烃是气体

练习 (四)：解析

答案：(C)

解析：

烷烃属于非极性或弱极性分子，而水是强极性溶剂。根据“相似相溶”原理，烷烃难溶于水。

随堂练习 (五)

等物质的量的甲烷和氯气在光照下充分反应，得到的产物是？

(A) 纯净的CH₃Cl

(B) 纯净的CH₂Cl₂

(C) CH₃Cl和HCl的混合物

(D) CH₃Cl, CH₂Cl₂, CHCl₃, CCl₄和HCl的混合物

练习 (五)：解析

答案：(D)

解析：

甲烷与氯气的取代反应是逐步、连锁发生的，一旦开始，后续的取代会同时进行，直到氯气耗尽或甲烷的氢原子被完全取代。因此，无论反应物的比例如何，只要发生反应，产物必然是多种氯代甲烷（CH₃Cl, CH₂Cl₂, CHCl₃, CCl₄）和HCl的混合物。
