氧化还原反应的基本概念

—— 戴上“化合价”的新眼镜看世界

从生活经验出发

我们来看一个熟悉的反应：把一小片锌丢进盐酸里。

Zn + 2HCl → ZnCl₂ + H₂↑

这是一个标准的置换反应。

锌(Zn)的化合价从 0 升高 到 +2！

氢(H)的化合价从 +1 降低 到 0！

像这样，化合价“有高有低、有起有落”的反应，就是氧化还原反应！

核心概念：特征与本质

特征 (我们能看到的)

反应前后，有元素的化合价发生升降。

本质 (背后发生的事)

反应过程中，发生了电子的转移（得失或偏移）。

电子的“霸气转账”：镁带燃烧

2Mg + O₂ → 2MgO

• 镁 (Mg): 失去电子，化合价从0升高到+2，这个过程叫作被氧化。

• 氧 (O): 得到电子，化合价从0降低到-2，这个过程叫作被还原。

核心口诀

失升氧

得降还

失去电子，化合价升高，被氧化；
得到电子，化合价降低，被还原。

电子的“拉锯拔河”：水的形成

2H₂ + O₂ → 2H₂O

当非金属相遇时，电子不会完全转移，而是形成共用电子对。但力气大的“氧”会把共用电子对拉向自己这边，导致电子偏移。

• 氢 (H): 电子对偏离，“好像”失去了，化合价升高为+1。

• 氧 (O): 电子对偏向，“好像”得到了，化合价降低为-2。

四大反应类型与氧化还原的关系

关系解析

  • 置换反应：一定有单质参与，化合价百分之百会变，全部是氧化还原反应。
  • 复分解反应：只是交换离子，化合价从头到尾都没变，全部不是氧化还原反应。
  • 化合与分解反应：是“墙头草”，部分是，部分不是。
快速判断秘诀：看到有单质参与的化合反应，或有单质生成的分解反应，那它就一定是氧化还原反应！

高手进阶：特殊类型

歧化反应 (内讧)

同一元素，反应后一部分化合价升高，一部分降低。

Cl₂ + 2NaOH → NaCl + NaClO + H₂O

归中反应 (会合)

同一元素的高价和低价，反应后生成中间价态。

2H₂S + SO₂ → 3S↓ + 2H₂O

今日总结

  • 看到什么特征，就知道是氧化还原反应？ 化合价有升有降！
  • 背后的真正原因是什么？ 电子的转移或偏移！
  • 失电子，化合价升高，叫什么？ 被氧化！
  • 得电子，化合价降低，叫什么？ 被还原！

随堂练习（一）

判断一个反应是否为氧化还原反应的根本依据是？

(A) 是否有氧气参与

(B) 是否有单质生成

(C) 反应前后元素化合价是否变化

(D) 反应是否需要加热

练习题（一）：解析

答案：(C)

解析：

氧化还原反应的特征就是反应前后有元素化合价的升降。这是我们判断的直接依据。其本质是电子的转移，但从反应式上最直观的判断方法就是看化合价。

随堂练习（二）

在反应 2Na + 2H₂O → 2NaOH + H₂↑ 中，被还原的元素是？

(A) 钠 (Na)

(B) 氢 (H)

(C) 氧 (O)

(D) 没有元素被还原

练习题（二）：解析

答案：(B)

解析：

我们先标出化合价：

2Na(0) + 2H₂(+1)O(-2) → 2Na(+1)OH + H₂(0)↑

钠(Na)的化合价从0升高到+1，被氧化。水中的氢(H)元素，一部分化合价从+1降低到0（生成氢气），被还原。氧的化合价不变。

随堂练习（三）

下列哪个反应不属于氧化还原反应？

(A) CaCO₃ → CaO + CO₂↑

(B) 2KMnO₄ → K₂MnO₄ + MnO₂ + O₂↑

(C) Cl₂ + H₂O → HCl + HClO

(D) Fe + CuSO₄ → FeSO₄ + Cu

练习题（三）：解析

答案：(A)

解析：

我们逐一检查化合价是否变化：

  • (A) 碳酸钙分解，所有元素的化合价（Ca:+2, C:+4, O:-2）都没有改变。它属于分解反应，但不是氧化还原反应。
  • (B) 氧元素的化合价从-2升高到0，锰元素的化合价从+7降低，是氧化还原反应。
  • (C) 氯元素的化合价从0一部分降低到-1，一部分升高到+1，是歧化反应，属于氧化还原反应。
  • (D) 典型的置换反应，一定是氧化还原反应。

随堂练习（四）

根据口诀“失升氧，得降还”，在氧化还原反应中，发生氧化反应的物质，其元素的化合价会怎样变化？

(A) 升高

(B) 降低

(C) 不变

(D) 可能升高也可能降低

练习题（四）：解析

答案：(A)

解析：

口诀的第一句“失升氧”已经告诉我们答案：

失去电子 → 化合价升高 → 发生氧化反应。

所以，发生氧化反应的物质，其元素的化合价会升高。

随堂练习（五）

下列哪种基本反应类型一定不是氧化还原反应？

(A) 化合反应

(B) 分解反应

(C) 置换反应

(D) 复分解反应

练习题（五）：解析

答案：(D)

解析：

  • 置换反应一定有单质参与，所以一定是氧化还原反应。
  • 化合反应和分解反应，如果有单质参与或生成，就是氧化还原反应；如果没有，就不是。
  • 复分解反应的本质是交换离子，反应前后所有元素的化合价都不会改变，所以它一定不是氧化还原反应。
