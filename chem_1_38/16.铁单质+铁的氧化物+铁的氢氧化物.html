铁及其重要化合物

—— 变价金属的系统性梳理

铁单质 (Fe)

物理性质

  • 银白色金属光泽 (粉末为黑色)
  • 良好的导电、导热、延展性
  • 能被磁铁吸引，具有磁性

存在与含量

  • 地壳中含量排名第四 (O > Si > Al > Fe)
  • 主要以 +2, +3价 化合态存在于矿石中
  • 自然界存在少量游离态的铁

纯铁具有银白色金属光泽

化学性质：与非金属反应

产物的价态取决于氧化剂的强弱。

遇强氧化剂 → Fe³⁺

2Fe + 3Cl₂ (点燃) → 2FeCl₃

2Fe + 3Br₂ (加热) → 2FeBr₃

遇弱氧化剂 → Fe²⁺

Fe + I₂ (加热) → FeI₂

Fe + S (加热) → FeS

与水和盐溶液反应

与高温水蒸气反应

生成四氧化三铁和氢气。

3Fe + 4H₂O(g) (高温) ⇌ Fe₃O₄ + 4H₂

与盐溶液反应

体现了置换反应和归中反应。

Fe + Cu²⁺ → Fe²⁺ + Cu

Fe + 2Fe³⁺ → 3Fe²⁺

与酸的反应 (一)

与非氧化性酸 (盐酸, 稀硫酸)

铁被H⁺氧化，生成二价铁和氢气。

Fe + 2H⁺ → Fe²⁺ + H₂↑

与稀硝酸

硝酸过量 → 生成 Fe³⁺

铁过量 → 生成 Fe²⁺ (生成的Fe³⁺被过量Fe还原)

与浓硫酸/浓硝酸的反应

常温下：钝化

铁表面迅速生成一层致密的氧化膜，阻止反应继续进行。注意：不是不反应。

加热时：反应

2Fe + 6H₂SO₄(浓) → Fe₂(SO₄)₃ + 3SO₂↑ + 6H₂O

“钝化”是铁和铝共有的重要化学性质，常用于运输浓硫酸和浓硝酸。

“钝化”现象详解

“钝化”现象示意图

致密的氧化膜 (主要成分Fe₂O₃, Fe₃O₄) 阻止了酸与内部金属的接触。

铁的氧化物

化学式 名称/俗名 外观 与酸反应
FeO 氧化亚铁 → Fe²⁺ + H₂O
Fe₂O₃ 三氧化二铁 (铁红) → Fe³⁺ + H₂O
Fe₃O₄ 四氧化三铁 → Fe²⁺ + Fe³⁺

注意：FeO 不稳定，在空气中加热易被氧化为 Fe₃O₄。若遇硝酸等氧化性酸，所有含 Fe²⁺ 的氧化物都会被氧化成 Fe³⁺。

铁的氢氧化物

氢氧化亚铁 (Fe(OH)₂)

  • 白色絮状沉淀
  • 性质不稳定，极易被氧化
  • 与酸反应生成 Fe²⁺

氢氧化铁 (Fe(OH)₃)

  • 红褐色沉淀
  • 性质稳定，受热分解为 Fe₂O₃
  • 与酸反应生成 Fe³⁺

随堂练习 (一)

将铁丝在氯气中点燃，生成的主要产物是？

(A) FeCl₂

(B) FeCl₃

(C) Fe₂O₃

(D) Fe₃O₄

练习 (一)：解析

答案：(B)

解析：

氯气是强氧化剂，能将铁氧化至最高的+3价，因此生成三氯化铁 (FeCl₃)。

随堂练习 (二)

将过量的铁粉加入到稀硫酸中，主要发生的离子反应是？

(A) Fe + 2H⁺ → Fe²⁺ + H₂↑

(B) Fe + 4H⁺ + NO₃⁻ → Fe³⁺ + NO↑ + 2H₂O

(C) Fe + Cu²⁺ → Fe²⁺ + Cu

(D) Fe + 2Fe³⁺ → 3Fe²⁺

练习 (二)：解析

答案：(A)

解析：

稀硫酸属于非氧化性酸，其中的氧化剂是 H⁺。H⁺ 的氧化性不足以将铁氧化到+3价，只能氧化到+2价，并生成氢气。

随堂练习 (三)

在空气中，白色絮状沉淀转变为红褐色沉淀，该过程描述的是？

(A) Fe(OH)₃ 的生成

(B) Fe₂O₃ 的生成

(C) Fe(OH)₂ 氧化为 Fe(OH)₃

(D) FeO 氧化为 Fe₂O₃

练习 (三)：解析

答案：(C)

解析：

这是氢氧化亚铁在空气中被氧化的典型现象。初始生成的白色 Fe(OH)₂ 沉淀，在空气中迅速被氧化，最终生成红褐色的 Fe(OH)₃ 沉淀。

随堂练习 (四)

铁与下列哪种物质在常温下会发生“钝化”现象？

(A) 盐酸

(B) 稀硝酸

(C) 浓硫酸

(D) 氯气

练习 (四)：解析

答案：(C)

解析：

铁在常温下遇到冷的浓硫酸或浓硝酸，表面会迅速反应生成一层致密的氧化物保护膜，阻止内部的铁继续反应，这种现象称为钝化。

随堂练习 (五)

黑色粉末A能与盐酸反应生成B和C两种盐，则A是？

(A) FeO

(B) Fe₂O₃

(C) Fe₃O₄

(D) Fe粉

练习 (五)：解析

答案：(C)

解析：

Fe₃O₄可以看作是 FeO·Fe₂O₃ 的混合氧化物，其中铁元素既有+2价也有+3价。因此它与酸反应会同时生成亚铁盐 (FeCl₂) 和铁盐 (FeCl₃)。
