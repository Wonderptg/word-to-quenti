直线与圆的位置关系

从“看”到“算”

"一个圆，一条线，咱让他俩‘碰一碰’！"

核心判断： $d$ vs $r$

我们只比较两个量：圆心 $C$ 到直线 $l$ 的距离 ($d$) 和圆的半径 ($r$)。

相离

(0个交点)

$d > r$

相交

(2个交点)

$d < r$

相切

(1个交点)

$d = r$

下图为这三种情况的直观图像。👇

核心判断：直观图像

相离 ($d > r$)

相切 ($d = r$)

相交 ($d < r$)

核心模型一：相交 ($d < r$) —— “弦长模型”

当直线与圆相交于A, B两点，弦长为 $L$。连接圆心C与弦中点M。

我们得到一个“黄金直角三角形” $\Delta CMA$。

“黄金直角三角形” $\Delta CMA$:

  • 斜边 $CA$ = 半径 $r$
  • 直角边 $CM$ = 距离 $d$
  • 直角边 $AM$ = 弦长的一半 $L/2$
$(\frac{L}{2})^2 + d^2 = r^2$

弦长模型应用 (1/2)：求弦长

应用1：求弦长

例：圆 $(x-1)^2 + (y-2)^2 = 25$ 与直线 $y = 5$ 相交，求弦长 $L$。

弦长模型应用 (2/2)：求参数

应用2：求参数

例：圆 $C: (x-1)^2 + (y-2)^2 = 25$ ($r=5$)。直线 $l: 3x+4y+m=0$ 截得弦长 $L=6$。求 $m$。

核心模型二：相切 ($d = r$) —— “切线模型”

当从圆外一点 $P$ 向圆作切线，切点为 $T$。连接圆心 $C$。

我们得到一个“黄金直角三角形” $\Delta PCT$。

“黄金直角三角形” $\Delta PCT$:

  • 直角边 $CT$ = 半径 $r$ (切线性质)
  • 斜边 $PC$ = 圆心 $C$ 到点 $P$ 的距离
  • 直角边 $PT$ = 切线长
$(PT)^2 + r^2 = (PC)^2$

切线模型应用：求参数

应用1：求参数 (相切 $\implies d=r$)

例：圆 $C: x^2 + y^2 = 4$ 与直线 $l: 3x+y+b=0$ 相切，求 $b$。

切线模型应用：求切线长

应用2：求切线长

例：从圆 $C: (x-1)^2+(y-2)^2=25$ ($r=5$) 外一点 $P(9,8)$ 向圆作切线，求切线长 $PT$。

随堂练习 (1/4)

1. 已知圆 $C$ 的半径 $r = 3$，圆心 $C$ 到直线 $l$ 的距离 $d = 2$，则直线 $l$ 与圆 $C$ 的位置关系是？

(A) 相离

(B) 相切

(C) 相交

(D) 无法判断

随堂练习 (2/4)

2. 直线 $y = kx + 1$ 与圆 $x^2 + y^2 = 1$ 相切，则 $k$ 的值是？

(A) 1

(B) $\pm 1$

(C) 0

(D) 2

随堂练习 (3/4)

3. 圆 $(x-1)^2 + y^2 = 4$ 被直线 $x = 2$ 截得的弦长为？

(A) 2

(B) 4

(C) $\sqrt{3}$

(D) $2\sqrt{3}$

随堂练习 (4/4)

4. 从圆 $x^2 + y^2 = 9$ 外一点 $P(5, 0)$ 向圆引切线，切线长为？

(A) 3

(B) 4

(C) 5

(D) 16

练习题解析

1. 答案：C

解析：半径 $r=3$, 距离 $d=2$。因为 $d < r$ ($2 < 3$)，所以直线与圆相交。

2. 答案：C

解析：圆心 $C(0,0), r=1$。直线 $kx-y+1=0$。相切 $\implies d=r$。
$d = \frac{|k(0)-(0)+1|}{\sqrt{k^2+(-1)^2}} = \frac{1}{\sqrt{k^2+1}}$。
令 $d=r \implies \frac{1}{\sqrt{k^2+1}} = 1 \implies k^2+1=1 \implies k=0$。

3. 答案：D

解析：圆心 $C(1,0), r=2$。直线 $x-2=0$。
距离 $d = \frac{|1-2|}{\sqrt{1^2+0^2}} = 1$。
弦长模型：$(\frac{L}{2})^2 + d^2 = r^2 \implies (\frac{L}{2})^2 + 1^2 = 2^2 \implies (\frac{L}{2})^2 = 3$。
$L/2 = \sqrt{3} \implies L = 2\sqrt{3}$。

4. 答案：B

解析：圆心 $C(0,0), r=3$。点 $P(5,0)$。
圆心到点P距离 $PC = \sqrt{(5-0)^2+(0-0)^2} = 5$。
切线长 $PT$ 满足 $(PT)^2 + r^2 = (PC)^2 \implies (PT)^2 + 3^2 = 5^2$。
$(PT)^2 = 25-9=16 \implies PT=4$。

五、晚节撒花！（总结）

好啦，同学们！今天咱把直线和圆的关系彻底搞明白了！

咱总结一下，所有题，不管多花哨，咱就抓两个模型：

1. 遇到相交、求弦长

立马画“垂径定理三角形” ($r, d, L/2$)，
用勾股定理：

$(\frac{L}{2})^2 + d^2 = r^2$

2. 遇到相切、求切线长

立马画“切线性质三角形” ($r, PT, PC$)，
用勾股定理：

$(PT)^2 + r^2 = (PC)^2$

解析几何，就是把“形”变成“数”。
看准模型，大胆去算！
