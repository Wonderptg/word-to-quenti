数列第一课

初识数列的奥秘

"数列，就是按一定顺序排列的一组数。"

什么是数列？

例子： (1, 4, 9, 16, 25, ...)

数列 vs 集合

  • 顺序： 集合元素无所谓顺序 {1, 2, 3} = {3, 2, 1}。
    数列必须讲顺序 (1, 4, 9) $\neq$ (9, 4, 1)。
  • 重复： 集合元素不能重复 {1, 1, 2} = {1, 2}。
    数列可以重复 (90, 85, 90, 92)。

数列是一种定义域为正整数集的特殊函数。

核心一：通项公式 ($a_n$)

通项公式是数列的“身份证”或“通用规律公式”。

数列 (1, 4, 9, 16, ...)

  • 第一项：$a_1 = 1$
  • 第二项：$a_2 = 4$
  • 第三项：$a_3 = 9$
  • ...
  • 第 $n$ 项：$a_n = n^2$

有了 $a_n = n^2$，就可以求任意一项：

$a_{100} = 100^2 = 10000$

$a_{50} = 50^2 = 2500$

实战演练 1：代入检验法

题目：数列 ( -1, 1, -1, 1, ... )，下列哪个不能作为它的通项公式？

(A) $a_n = (-1)^n$

(B) $a_n = \cos(n\pi)$

(C) $a_n = \sin(n\pi)$

(D) $a_n = -(-1)^{n-1}$

核心二：前 $n$ 项和 ($S_n$)

前 $n$ 项和是数列的“累加器”。

$S_n = a_1 + a_2 + a_3 + ... + a_n$

例：数列 $a_n = n^2$ (1, 4, 9, 16, ...)

  • $S_1 = a_1 = 1$
  • $S_2 = a_1 + a_2 = 1 + 4 = 5$
  • $S_4 = a_1 + a_2 + a_3 + a_4 = 1 + 4 + 9 + 16 = 30$

例：已知 $a_n = 2n - 1$，求 $S_4$。

$a_1 = 1, a_2 = 3, a_3 = 5, a_4 = 7$

$S_4 = 1 + 3 + 5 + 7 = 16$

拓展：递推公式

递推公式是“连锁反应”的规则，通过前一项（或几项）来推出后一项。

例： $a_1 = 1$ 且 $a_{n+1} = a_n + 2$。
（含义：“任何一项 = 前一项 + 2”）

  • $a_1 = 1$
  • $a_2 = a_1 + 2 = 1 + 2 = 3$
  • $a_3 = a_2 + 2 = 3 + 2 = 5$
  • $a_4 = a_3 + 2 = 5 + 2 = 7$

实战演练 2：递推找周期

题目：已知 $a_1 = 1, a_2 = 1$，且 $a_{n+2} = a_{n+1} - a_n$。求 $a_{2025}$。

实战演练 3：递推 + 求和

题目：已知 $a_1 = 10, a_2 = 20, a_5 = 10$。
规则：若 $a_p = a_q$，则 $a_{p+1} = a_{q+1}$。
且 $a_3 + a_4 = 50$。求 $S_{100}$。

随堂练习 (1/4)

1. 下列关于数列和函数的说法中，错误的是？

(A) 数列可以看作是一种特殊的函数。

(B) 数列的图像是一群孤立的点。

(C) 函数的定义域总是实数集 $R$。

(D) 数列的定义域是正整数集 $N^*$ 或其子集。

随堂练习 (2/4)

2. 已知一个数列的通项公式为 $a_n = 3n + 2$，那么这个数列的第 5 项 $a_5$ 是多少？

(A) 10

(B) 15

(C) 17

(D) 20

随堂练习 (3/4)

3. 已知数列 $a_n$ 中，$a_1 = 5, a_2 = -2, a_3 = 8$，那么这个数列的前 3 项和 $S_3$ 是多少？

(A) 5

(B) 3

(C) 11

(D) 15

随堂练习 (4/4)

4. 已知数列 $a_n$ 满足递推公式 $a_{n+1} = 2a_n$，且 $a_1 = 3$。那么 $a_3$ 的值是？

(A) 7

(B) 9

(C) 12

(D) 18

练习题解析

1. 答案：C

解析：函数的定义域不总是实数集 $R$。例如 $f(x) = \sqrt{x}$ 的定义域是 $[0, +\infty)$。而数列是一种定义域为正整数集的特殊函数，所以 A、B、D 都是正确的。

2. 答案：C

解析：通项公式为 $a_n = 3n + 2$，要求第 5 项 $a_5$，只需将 $n=5$ 代入：$a_5 = 3(5) + 2 = 15 + 2 = 17$。

3. 答案：C

解析：$S_3$ 是前 3 项的和，即 $S_3 = a_1 + a_2 + a_3$。
$S_3 = (5) + (-2) + (8) = 3 + 8 = 11$。

4. 答案：C

解析：递推公式 $a_{n+1} = 2a_n$， $a_1 = 3$。
第一步：$a_2 = 2a_1 = 2 \times 3 = 6$。
第二步：$a_3 = 2a_2 = 2 \times 6 = 12$。

总结

今天我们干了三件大事：

  • 认识了数列：有序的数，图像是孤立的点。
  • 掌握了 $a_n$ (通项公式)：数列的“身份证”，用“代入法”检验。
  • 掌握了 $S_n$ (前n项和)：数列的“累加器”，“先求项，再求和”。
  • (附赠) 递推公式：靠“连锁反应”定义，做题核心是找周期！
