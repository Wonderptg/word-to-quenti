圆的一般方程

解开 "乱码" 背后的秘密

"为什么 $x^2+y^2-6x+2y+6=0$ 也是一个圆？"

标准方程 vs 一般方程

标准方程 (“实诚”)：$(x-a)^2 + (y-b)^2 = r^2$
$\implies$ 圆心 $(a, b)$ 和半径 $r$ 一目了然。

它是怎么来的？把标准方程“脱掉外套”（展开）：

$(x-3)^2 + (y+1)^2 = 4$

$(x^2 - 6x + 9) + (y^2 + 2y + 1) = 4$

整理 $\implies x^2 + y^2 - 6x + 2y + 6 = 0$

这就得到了圆的一般方程：

$x^2 + y^2 + Dx + Ey + F = 0$

核心技能：配方法

如何把“乱码” $x^2+y^2-6x+2y+6=0$ 打回原形？

配方三步走：

  1. 分组：x跟x玩, y跟y玩。常数扔到右边。
    $(x^2 - 6x\_\_) + (y^2 + 2y\_\_) = -6$
  2. 配方：加上“一次项系数一半的平方”。
    x项：-6的一半是-3，平方是 9。
    y项：+2的一半是+1，平方是 1。
  3. 平衡：左边加了9和1，右边也要加！
    $(x^2 - 6x + 9) + (y^2 + 2y + 1) = -6 + 9 + 1$
  4. 收工：
    $(x - 3)^2 + (y + 1)^2 = 4$

圆心：$(3, -1)$，半径：$2$。

快捷公式 (“兵器”)

对于 $x^2 + y^2 + Dx + Ey + F = 0$：

圆心： $(-\frac{D}{2}, -\frac{E}{2})$

半径： $r = \frac{1}{2}\sqrt{D^2 + E^2 - 4F}$

验证： $x^2+y^2-6x+2y+6=0$
$D=-6$, $E=2$, $F=6$

圆心： $(-\frac{-6}{2}, -\frac{2}{2}) = (3, -1)$。 完美！

老师忠告：

配方法是“内功”，必须会！公式是“兵器”，可以用来加速或检查。不能只依赖兵器！

陷阱一：这是圆吗？

是不是 $x^2 + y^2 + ...$ 的形式就一定是圆？

例： $x^2+y^2+2x+4y+8=0$

陷阱一：结论

结论：看 $D^2 + E^2 - 4F$ (半径公式的“芯”)

  • $D^2 + E^2 - 4F > 0 \implies$ 是一个圆 (右边是正数)
  • $D^2 + E^2 - 4F = 0 \implies$ 是一个点 (右边是0)
  • $D^2 + E^2 - 4F < 0 \implies$ 不是圆 (右边是负数)

陷阱二：系数的伪装

情况一： $5x^2 + 5y^2 - 10x + ... = 0$
这是圆吗？
是！因为 $x^2$ 和 $y^2$ 的系数相等（都是5）。我们可以在配方前，两边同时除以5，把它变回 $x^2 + y^2 ...$ 的标准一般式。

情况二： $5x^2 - 5y^2 - 10x + ... = 0$
这是圆吗？
不是！$x^2$ 和 $y^2$ 的系数一正一负，这绝对不是圆。（这是我们以后会学的双曲线）

实战应用(一)：求过三点的圆

例：求经过 $A(1,1)$, $B(2,-2)$, $C(5,-1)$ 三点的圆的方程。

实战应用(二)：最值问题

例：已知圆 $C: x^2+y^2+4x-10y+13=0$，求圆上任意一点 P 到原点 O(0,0) 的最大距离。

随堂练习 (1/4)

1. 圆 $x^2+y^2-4x+6y-1=0$ 的圆心坐标是？

(A) $(2, -3)$

(B) $(-2, 3)$

(C) $(4, -6)$

(D) $(-4, 6)$

随堂练习 (2/4)

2. 将方程 $x^2+y^2+2x=0$ 配方后得到的标准方程是？

(A) $(x-1)^2+y^2=1$

(B) $(x+1)^2+y^2=-1$

(C) $(x+1)^2+y^2=1$

(D) $x^2+(y+1)^2=1$

随堂练习 (3/4)

3. 方程 $x^2+y^2+Dx+Ey+F=0$ 表示一个点, 则 D, E, F 满足的条件是？

(A) $D^2+E^2-4F > 0$

(B) $D^2+E^2-4F < 0$

(C) $D^2+E^2-4F = 0$

(D) $F=0$

随堂练习 (4/4)

4. 关于方程 $2x^2+y^2-8x=0$, 下列说法正确的是？

(A) 它表示一个圆, 圆心是(2,0)。

(B) 它表示一个点。

(C) 它不表示一个圆, 因为 $x^2$ 和 $y^2$ 的系数不相等。

(D) 它不表示任何图形。

练习题解析

1. 答案：A

解析：用快捷公式：圆心 $(-\frac{D}{2}, -\frac{E}{2})$。这里 $D=-4$, $E=6$。
圆心 $(-\frac{-4}{2}, -\frac{6}{2}) = (2, -3)$。

2. 答案：C

解析：配方法：$(x^2+2x) + y^2 = 0$。x项配方需加1，两边都加1。
$(x^2+2x+1) + y^2 = 1 \implies (x+1)^2 + y^2 = 1$。

3. 答案：C

解析：当 $D^2+E^2-4F=0$ 时，配方后方程右边等于0，方程变为 $(x-a)^2 + (y-b)^2 = 0$，这只表示一个点 $(a, b)$。

4. 答案：C

解析：圆的一般方程一个重要前提是 $x^2$ 和 $y^2$ 的系数必须相等且不为0。这里系数分别是2和1，不相等，所以它不表示一个圆。

课程总结

今天我们给圆换了件“马甲”，叫一般方程：

$x^2 + y^2 + Dx + Ey + F = 0$
  • 核心技能：配方法！(标准 $\leftrightarrow$ 一般)
  • 快捷方式：圆心 $(-\frac{D}{2}, -\frac{E}{2})$
  • 火眼金睛：用 $D^2+E^2-4F$ 判断它是真圆、是点、还是冒牌货。
  • 应用：凡是碰到一般方程，先配方(扒马甲)，99%的问题都会变回我们上节课熟悉的样子!
