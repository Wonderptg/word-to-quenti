直线的交点与距离

解析几何的计算基础

"今天，我们来啃硬骨头！"

热身复习 (1/2)：求交点坐标

方法：联立方程组

两条不平行的直线，其交点坐标即为它们方程组的解。

例：求 $L_1: x-y-1=0$ 与 $L_2: x+2y-7=0$ 的交点。

$$\begin{cases} x-y-1=0 \quad (1) \\ x+2y-7=0 \quad (2) \end{cases}$$ $(2) - (1)$ 得 $3y - 6 = 0$，解得 $y=2$。
将 $y=2$ 代入 $(1)$，得 $x-2-1=0$，解得 $x=3$。

交点坐标是 $(3, 2)$。

热身复习 (2/2)：两点间距离

原理：勾股定理

设 $P(x_{1},y_{1})$ 和 $Q(x_{2},y_{2})$，两点间的距离 d 为：

$$d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$$

例：求 $A(1,5)$ 与 $B(4,1)$ 的距离。

$$d = \sqrt{(4-1)^2 + (1-5)^2} = \sqrt{3^2 + (-4)^2} = \sqrt{9+16} = 5$$

距离 $d=5$。

核心新知(一)：点到直线距离

点 $P(x_0, y_0)$ 到直线 $L: Ax+By+C=0$ 的距离 d 为：

$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$

记忆口诀：

分子：点代入，取绝对

分母：系数平方和开根号

使用前提：直线方程必须化为一般式 $Ax+By+C=0$！

推导提示：此公式是利用直线法向量 $\vec{n}=(A,B)$，通过向量投影法得到的。

推导思路对比 (1/2)：笨办法 (几何法)

此思路虽然直观，但**计算量大**，步骤繁琐：

  1. 求直线 $L$ 斜率 $k_L$。
  2. 确定垂线斜率 $k_{\perp}$。
  3. 写出垂线方程。
  4. 联立方程组，求出垂足 $Q$ 坐标。
  5. 计算 $P, Q$ **两点间距离** $|PQ|$。
结论：思路是通的，但计算量大到爆炸！

推导思路对比 (2/2)：巧办法 (知识铺垫)

我们初中学 $y=kx+b$，$k$ 是斜率。那高中学的 $Ax+By+C=0$ 里的 $A$ 和 $B$ 是干嘛的？

核心新知(二) (1/2)：平行线间距离

两条平行线 $L_1: Ax+By+C_1=0$ 和 $L_2: Ax+By+C_2=0$ 之间的距离 d 为：

$d = \frac{|C_1 - C_2|}{\sqrt{A^2 + B^2}}$

记忆：分子是常数项之差取绝对值，分母不变。

超级陷阱！
使用此公式前，必须确保两条直线的 A, B 系数完全一样！

随堂练习 (4/4)

4. 使用点到直线距离公式前，必须对直线方程做什么预处理？

(A) 化为点斜式

(B) 化为一般式

(C) 求出斜率

练习题解析

1. 答案：B

解析：套用点线距离公式。$d = |3(1)+4(0)-5| / \sqrt{3^2+4^2} = |-2|/5 = 2/5$。

2. 答案：C

解析：：套用两点距离公式。$d = \sqrt{(5-2)^2+(-1-3)^2} = \sqrt{3^2+(-4)^2} = \sqrt{9+16} = 5$。

3. 答案：C

解析：：陷阱！先将 $L_1$ 变为 $2x+2y+2=0$。再用平行线距离公式。$d = |2-6| / \sqrt{2^2+2^2} = 4 / \sqrt{8} = 4 / (2\sqrt{2}) = \sqrt{2}$。

4. 答案：B

解析：：点到直线距离公式是基于一般式 $Ax+By+C=0$ 推导的，使用前必须化为该形式。

课堂总结与思考题

知识回顾

  • 交点：联立方程组。
  • 两点距离：勾股定理 $d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$。
  • 点线距离：$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$ (需一般式)。
  • 平行线距离：$d = \frac{|C_1 - C_2|}{\sqrt{A^2 + B^2}}$ (需 $A, B$ 系数完全一致)。
  • 几何妙用：遇到含参直线，先找定点！

作业/思考题：等距线

已知两条平行线 $L_1: x+y-2=0$ 和 $L_2: x+y+6=0$。

求一条直线 $L$，使得 $L$ 到 $L_1$ 和 $L_2$ 的距离相等。

提示：直线 $L$ 必定与 $L_1, L_2$ 平行，可设为 $x+y+C=0$。利用距离公式列出方程 $|C - (-2)| = |C - 6|$ 即可求解 $C$。
