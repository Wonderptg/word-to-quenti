核心判断：比较“d”与“和、差”

我们只用比较三个数：圆心距 $d$、半径和 $r_1+r_2$、半径差 $|r_1-r_2|$

临界情况 1：外切

$d = r_1 + r_2$

临界情况 2：内切

$d = |r_1 - r_2|$

$\implies d > r_1 + r_2$ (比和大) $\implies$ 外离

$\implies |r_1 - r_2| < d < r_1 + r_2$ (卡中间) $\implies$ 相交

$\implies d < |r_1 - r_2|$ (比差小) $\implies$ 内含

拓展：公切线例题

例3： $C_1: x^2+y^2=4$ 和 $C_2: (x-3)^2+(y-4)^2=1$ 有几条公切线？

随堂练习 (1/4)

1. 两圆有且仅有一个公共点，则两圆位置关系是？
(A) 相交 (B) 外离 (C) 内含 (D) 相切

随堂练习 (2/4)

2. 两圆有且仅有两条公切线，则两圆位置关系是？
(A) 外离 (B) 外切 (C) 相交 (D) 内切

随堂练习 (3/4)

3. 已知圆 C1 : $x^2 + y^2 = 1$ 和圆 C2 : $(x - 3)^2 + y^2 = 4$，则两圆的位置关系是？
(A) 外离 (B) 外切 (C) 相交 (D) 内含

随堂练习 (4/4)

4. 已知圆 C1 的半径 $r_1 = 5$，圆 C2 的半径 $r_2 = 3$，两圆的圆心距 $d = 1$，则两圆的位置关系是？
(A) 相交 (B) 内切 (C) 内含 (D) 外离

练习题解析

1. 答案：D

解析：唯一公共点，意味着“贴”在了一起，包括“外切”和“内切”，统称“相切”。

2. 答案：C

解析：公切线条数与位置关系对应：外离(4), 外切(3), 相交(2), 内切(1), 内含(0)。2条对应相交。

3. 答案：B

解析：$O_1(0,0), r_1=1$。$O_2(3,0), r_2=2$。圆心距 $d=3$。半径和 $r_1+r_2=3$。因 $d=r_1+r_2$，故外切。

4. 答案：C

解析：$r_1=5, r_2=3, d=1$。半径和=8。半径差=$|5-3|=2$。因为 $d=1 < 2$，即 $d < |r_1-r_2|$，所以两圆内含。

总结

1. 五种关系：
外离、外切、相交、内切、内含。(要会画图)

2. 一个法宝 (核心判断)：
算圆心距 $d$。
算半径和 $r_1 + r_2$。
算半径差 $|r_1 - r_2|$。
...然后 比较大小！

3. 一个推论：
公切线条数 (4, 3, 2, 1, 0) 与位置关系是 一一对应 的。

4. 拓展大招：
求公切线方程时，可以找“位似中心”来简化问题。
