指数运算进阶

攻克“又大又长”的化简题

看到这个“拦路虎”，你慌了吗？

√(x³ · ⁴√x²) ÷ ³√x

别怕！它就是一只“纸老虎”！
核心就是把“根号”变成我们熟悉的老朋友——“指数”。

核心概念一：给根号一个“指数身份”

口诀：分母管开根，分子管次方！

xn/m = ᵐ√(xⁿ)

  • 81/3 = ³√8 = 2
  • 163/4 = (⁴√16)³ = 2³ = 8

来，马上练一下手！

(125/64)-2/3

1. 括号内：125/64 = (5/4)³

2. 幂的乘方：[(5/4)³]-2/3 = (5/4)(3 * -2/3) = (5/4)⁻²

3. 负指数幂：(5/4)⁻² = (4/5)² = 16/25

核心概念二：必须警惕的“绝对值陷阱”

“好了，基本功我们练完了。接下来，我要带大家看一个非常非常重要的点，一个考试里专门用来‘钓鱼’的陷阱，无数人在这里丢过分，大家一定要竖起耳朵听！”

⁴√((-5)²)

“看到这个题目，有同学可能这么想：‘老师我刚学了，根号化指数！’ 于是他写：(-5)2/4。然后他发现，2/4 可以约分啊，变成 1/2。所以就等于 (-5)1/2，也就是 √-5……”

“停！大家觉得对吗？√-5，负数能开平方吗（在实数范围内）？不能！算出个没意义的东西。可是一开始的 (-5)² 是 25，⁴√25 明明是一个正数啊！一个好好的正数，怎么算着算着就算没了呢？问题出在哪？”

“问题就出在约分！你把 2/4 约成 1/2 的时候，把原来那个‘偶数次方’的 2 给约掉了！偶数次方有个什么重要功能？它可以把负数变成正数！ 是个强大的‘扭转乾坤’的符号。你把它约掉了，这个功能就没了，(-5) 就被打回原形，自然就出错了！”

核心概念二：必须警惕的“绝对值陷阱”

现在，请试着分析并化简下面的表达式。思考每一步的依据，特别是当根号内出现负数和偶数次方时，应该如何正确处理。

⁴√((-5)²)

核心法则：偶次根开偶次方

“所以，请大家务必，务必记住这个法则：”

当 n 是奇数时

ⁿ√(aⁿ) = a

奇次根下奇次方，原样出来。

例: ³√(-2)³ = -2

当 n 是偶数时

ⁿ√(aⁿ) = |a|

偶次根下偶次方，加绝对值！

例: ⁴√(-2)⁴ = |-2| = 2

实战演练：数字综合题

(0.125)-1/3 + (π-3)⁰ - ³√27² + 81-3/4

实战演练：字母综合题

√(x³ · ⁴√x²) ÷ ³√x

综合练习 (四)

4. 化简：(1/32)-2/5 + ⁶√((√5 - 3)⁶)

综合练习 - 答案与解析 (上)

1. 正确答案：A

解析：
A: 根据零指数幂的定义，任何非零数的0次方都等于1。(-1)≠0，所以(-1)⁰=1，此项正确。
B: 同底数幂相乘，指数相加。a1/2 ⋅ a² = a1/2 + 2 = a5/2 ≠ a。
C: 42/4 = 41/2 = √4 = 2 ≠ 8。
D: 同底数幂相除，指数相减。a2/3 ÷ a-1/3 = a2/3 - (-1/3) = a3/3 = a ≠ a1/3。

2. 正确答案：A

解析：
a(2m+3n)/2 = (a2m+3n)1/2 = √(a2m ⋅ a3n) = √((am)² ⋅ (an)³)。
将 am = 3 和 an = 4 代入表达式：
√((3)² ⋅ (4)³) = √(9 ⋅ 64) = √576 = 24。

综合练习 - 答案与解析 (下)

3. 正确答案：B

解析：
核心策略是“见根号，化指数”。
√a√a = (a ⋅ a1/2)1/2
= (a1 + 1/2)1/2 = (a3/2)1/2
根据幂的乘方法则，指数相乘：
= a(3/2) ⋅ (1/2) = a3/4。

4. 正确答案：7 - √5

解析：
原式分为两部分计算。
第一部分：(1/32)-2/5 = (32)2/5 = (⁵√32)² = 2² = 4。
第二部分：⁶√((√5 - 3)⁶)。这是一个典型的“绝对值陷阱”。因为是偶次根开偶次方，所以结果要加绝对值。即 |√5 - 3|。
判断绝对值内正负：因为 √5 ≈ 2.236，所以 √5 - 3 是一个负数。
负数取绝对值，等于它的相反数：|√5 - 3| = -(√5 - 3) = 3 - √5。
最后，将两部分结果相加：4 + (3 - √5) = 7 - √5。

总结

降服“纸老虎”的三件法宝：

  • 翻译器：分数指数幂 (分母管开根，分子管次方)。
  • 总战略：所有根号都变成指数再计算！
  • 防盗网：偶次根下偶次方，结果一定加绝对值！
