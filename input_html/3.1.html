函数的“身份证”系统

f(x)的登场

为了区分不同的函数，我们给它们起个名字，比如 f, g。并在后面加上括号，放入自变量x。

f(x) = x - 5

g(x) = 3x²

f(x) 读作 "f of x"，意思是：
“一个名叫f的，并且由x来决定的函数”。

f(x)的核心法则

“左边怎么动，右边跟着动”！

函数：f(x) = x² + 4

  • f(3) = 3² + 4 = 13
  • f(-1) = (-1)² + 4 = 5
  • f(a+1) = (a+1)² + 4 = a² + 2a + 5

解密游戏：换元法

已知 f(2x+1) = 4x+3，求 f(x)。

  1. 换元：令 t = 2x+1。
  2. 反解：解出 x = (t-1)/2。
  3. 代入：f(t) = 4 * [(t-1)/2] + 3。
  4. 化简：f(t) = 2(t-1) + 3 = 2t + 1。
  5. 结论：f(x) = 2x + 1。

函数的本质

函数就是一个“神奇的配方”或一个“魔法盒子”。

核心不是字母x和y，而是处理原材料的规则和流程！

终极挑战：配方的嵌套

假设有两个配方：
f(x) = x+10， g(x) = √x

计算 f(g(x))

x → g(x) → √x

√x → f(√x) → √x + 10

计算 g(f(x))

x → f(x) → x+10

x+10 → g(x+10) → √(x+10)

题型三：函数求值问题

例题2．若 f(x) = x / √(1-x)，则 f(-3) = _________.

答案与解析

题型一：【答案】B。B中一个x对应了两个y值，不满足函数定义。

题型二：【答案】(1) (-∞, -2)； (2) (-2, 3)。

解析：

(1) 由题意，解不等式 3-x > 5，得到 -x > 2，即 x < -2。转化为区间表示为 (-∞, -2)。

(2) 由题意，解不等式组 x+3 > 1 且 5-x > 2，得到 x > -2 且 x < 3，所以集合的区间表示为 (-2, 3)。

题型三：【答案】-3/2。

解析：由题意得 f(-3) = (-3) / √(1 - (-3)) = -3 / √4 = -3/2。
