向量加法 (1/2): 平行四边形法则

场景：共起点

当两个向量从同一点出发时（如无人机和风），使用此法则。

口诀：“共起点，画平行，连对角”

向量加法 (2/2): 三角形法则

场景：首尾相接

当一个向量的终点是另一个向量的起点时（如送快递的连续位移），使用此法则。

口诀：“首尾接，连两端”

向量减法：相对位置的奥秘

向量减法 a - b 可以看作是加上b的相反向量：a + (-b)。

几何捷径 (机场飞机问题)

口诀：“共起点，连终点，指向前”。两架飞机(OA, OB)从同机场O起飞，A看B的相对位置就是BA，即OA - OB。

向量数乘：向量的伸缩魔法

一个数 λ 乘以向量 a，就是对向量施展伸缩和转向的魔法：

  • λ > 1 (如 2a)：同向拉伸。
  • 0 < λ < 1 (如 0.5a)：同向压缩。
  • λ < 0 (如 -1.5a)：方向反转，再伸缩。
  • λ = 0 (如 0a)：变为零向量 (一个点)。

随堂练习 (3/4)

3. 已知非零向量 a，那么 -2a 与 a 的关系是？

(A) 方向相同，长度是 a 的2倍

(B) 方向相反，长度是 a 的2倍

(C) 方向相反，长度是 a 的一半

随堂练习 (4/4)

4. 在边长为1的正方形 ABCD 中，|AB + AD| 的值是多少？

(A) 1

(B) 2

(C) √2

(D) √3

练习题解析

1. 答案：B | 解析：AB + BC = AC。原式变为 AC + CA。起点终点互换，是相反向量，和为零向量。

2. 答案：B | 解析：共起点减法，连终点(C到B)，指向被减向量(AB)的终点B，所以结果是CB。

3. 答案：B | 解析：负号表示方向相反，系数的绝对值2表示长度变为2倍。

4. 答案：C | 解析：根据平行四边形法则，AB + AD = AC。即求正方形对角线长度，由勾股定理得 |AC| = √(1²+1²) = √2。
