课后修炼题解析 (1/2)

1. 解析 y = (x²+4)/x, x>0

方法：分离常数，构造对勾函数。

① 化简： y = x²/x + 4/x = x + 4/x。

② 分析：这是一个经典的对勾函数，且定义域为 x>0。根据基本不等式（或对勾函数性质），当 x=4/x 时，即 x=2 时，函数取得最小值。

③ 求解： y_min = 2 + 4/2 = 4。

所以，值域为 [4, +∞)。

2. 解析 y = (x+1)/(x-2), x∈[3, 5]

方法：利用函数单调性。

① 化简： y = ((x-2)+3)/(x-2) = 1 + 3/(x-2)。

② 判断单调性：函数在区间 (2, +∞) 上是单调递减的。因此，它在子区间 [3, 5] 上也是单调递减的。

③ 计算端点值：最大值在 x=3 处取得，最小值在 x=5 处取得。

  • y_max = (3+1)/(3-2) = 4。
  • y_min = (5+1)/(5-2) = 6/3 = 2。

所以，值域为 [2, 4]。

课后修炼题解析 (2/2)

3. 解析 y = 4/x, x∈(0, 2]

方法：利用函数单调性。

① 判断单调性：函数 y = 4/x 在区间 (0, +∞) 上是单调递减的。因此，它在子区间 (0, 2] 上也是单调递减的。

② 分析边界：

  • 当 x=2 时，函数取得最小值，y_min = 4/2 = 2。
  • 当 x 从右侧趋近于 0 (x→0+) 时，y 趋近于正无穷大 (+∞)。

所以，值域为 [2, +∞)。

4. 解析 y = x + 4/x, x∈[1, 4]

方法：分析对勾函数在特定区间上的图像。

① 分析函数：这是一个对勾函数，对称轴为y轴，在 (0, +∞) 上，当 x=2 时取得最小值 y=4。

② 结合区间：函数的“对勾”最低点 x=2 正好在区间 [1, 4] 内部。所以函数在 [1, 2] 上递减，在 [2, 4] 上递增。

③ 比较端点与最值：

  • 区间内的最小值为 y(2) = 4。
  • 比较两个端点的值：y(1) = 1+4/1=5，y(4)=4+4/4=5。

所以，值域为 [4, 5]。
