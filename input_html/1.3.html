第一部分：生活中的集合与基本概念

🏠 情景热身，发现集合

想象一下，周末咱们班要组织活动，有三个备选方案：A去看科幻大片，B去公园搞户外运动，C在教室里玩桌游。

  • 既想看电影，又想玩桌游的同学有哪些？(共同点)
  • 电影、运动、桌游都行的同学有哪些？(合起来)
  • 除了户外运动，其他都可以的同学有哪些？(去掉)

这些想法，就是我们今天要学的“集合的运算”！

🤝 认识新朋友一：交集 (Intersection)

“既想看电影，又想玩桌游的同学”，就是电影爱好者集合和桌游爱好者集合的“交集”。

定义：指那些“同时属于”好几个集合的共同元素。

符号：∩ (一个倒过来的U)

关键词：都 且 共同的

举例：喜欢数学的有{小华, 小丽, 小军}，喜欢物理的有{小丽, 小强, 小军}。那么数学 ∩ 物理 = {小丽, 小军}。

🤗 认识新朋友二：并集 (Union)

“电影、运动、桌游，去哪个都开心的同学”，就是把所有愿意参加的同学合并起来，这就是“并集”。

定义：把好几个集合里的所有元素都放在一起，组成的一个新集合。

符号：∪ (一个正的U)

关键词：或 所有 一共

举例：喜欢数学的 ∪ 喜欢物理的 = {小华, 小丽, 小军, 小强}。注意：重复的元素只写一次！

🧐 认识新朋友三：补集 (Complement)

要理解补集，得先有个大框框，叫“全集”(用U表示)。

定义：相对于全集U，一个集合A的补集，就是指全集U中，所有不属于A的元素组成的集合。

符号：∁UA

关键词：不是 除了…以外的 剩下的

举例：全集U是{1..10}，集合B是偶数{2,4,6,8,10}，那么B的补集就是奇数{1,3,5,7,9}。

📏 神器一：数轴来帮忙！

当集合是连续的范围时，数轴是最好的朋友！

例：U=R, A = {x | x > -2}, B = {x | x ≤ 5}。

  • A ∪ B (并集)：画图发现覆盖了整条数轴，所以是 R。
  • A ∩ B (交集)：重叠的部分是 {x | -2 < x ≤ 5}。
  • ∁UA (A的补集)：A是大于-2的，补集就是小于等于-2的，即 {x | x ≤ -2}。

核心思想：数形结合！

🎨 神器二：神奇的韦恩图！

用圆圈代表集合，更直观地展示关系，专治计数和抽象问题。

韦恩图应用：解决计数问题

问题：班里30人唱歌，25人跳舞，12人都会。问至少会一项的有多少人？

解：先填中间(12)，再算两边(30-12=18, 25-12=13)。总人数 = 18+13+12 = 43人。

课后习题

4. (韦恩图) 已知全集U, (A∪B)的补集是{1,5,6}，B的补集是{1,4,6}，则图中阴影部分(A∩(∁UB))表示的集合是?

答案与解析

思考完毕？来看看正确答案吧！

答案与解析

1. 【答案】C. {x|1 < x ≤ 2}

【解析】画数轴，集合A表示大于1的区域，集合B表示小于等于2的区域。它们的公共重叠部分（交集）就是从1到2的区域，不包括1但包括2。

答案与解析

2. 【答案】C. {2,4,5}

【解析】补集是指在全集U中，但不在集合A中的元素。全集U是{1,2,3,4,5}，从中“去掉”A的元素{1,3}后，剩下的就是{2,4,5}。

答案与解析

3. 【答案】{x|x≤3}

【解析】第一步，求B的补集：B是{x|x>2}，那么它的补集∁UB就是{x|x≤2}。第二步，求A与B的补集的并集，即{x|-1≤x≤3} ∪ {x|x≤2}。在数轴上画出这两个范围并将它们“合并”起来，得到的结果是{x|x≤3}。

答案与解析

4. 【答案】B. {4}

【解析】阴影部分是 A \ B，也等于 A ∩ (∁UB)。题目已知 (∁UB) = {1,4,6}，所以我们要求 A ∩ {1,4,6}。又已知 (A∪B)的补集 = {1,5,6}，这说明 A 和 B 都不包含1, 5, 6。所以 A ∩ {1,4,6} 不可能包含1和6，只可能包含4（如果4在A中的话）。我们需要确定4是否在A中。因为 4 ∉ (A∪B)'，所以 4 ∈ (A∪B)。又因为 4 ∈ (∁UB)，所以 4 ∉ B。一个元素在A∪B中，但不在B中，那么它一定在A中。所以 4 ∈ A。因此 A ∩ {1,4,6} = {4}。

第三部分：总结与展望

今日总结

  • 三大核心运算：交集(∩)找共同，并集(∪)全都要，补集(∁)找剩余。
  • 两大神器：数轴解决范围问题，韦恩图直观展示关系。
  • 核心思想：数形结合！
