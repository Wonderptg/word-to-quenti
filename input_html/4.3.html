你好，我是对数！

Logarithm

一个分裂细菌引发的故事

嘿，同学们好！咱们先来玩个小游戏。想象一下，你有一种超级细菌，它每分钟分裂一次，数量翻一倍。

从1个细菌变成8个，需要几分钟？ 2³ = 8，所以是 3 分钟！

那变成64个呢？ 2⁶ = 64，所以是 6 分钟！

现在难度升级：

从1个细菌变成40个，需要几分钟？

嗯... 5分钟是32个，6分钟是64个。那40个肯定是在5到6分钟之间... 这个精确的时间点该怎么表示呢？

为了“命名”这个精确时间，数学家们发明了一个新工具，它的名字就叫做——对数。

给新朋友“上户口”

所以，当 2ˣ = 40 时，我们就把这个神秘的 x 记作：

x = log₂40

跟我读：“以 2 为 底，40 的 对数”。
这个 小小的2 叫 底数，正常的40 叫 真数。
整个式子的含义就是 “2的多少次方等于40？”

最重要的核心技能：自由转换！

指数和对数就像一枚硬币的两面，可以随时翻转。

5³ = 125 <=> log₅125 = 3

对数的“家规”

不是什么数都能放进对数里。它的规矩来自于指数：

底数 a

必须 a > 0 且 a ≠ 1。

（你想想，如果底数是1，那1的任何次方都是1，太无聊了！）

真数 b

必须 b > 0。

（因为一个正数的任何次方，结果永远是正的。）

对数的“超能力” (一)

超能力一：两个“隐藏彩蛋”

logₐ1 = 0 (任何数的0次方都等于1)

logₐa = 1 (任何数的1次方都等于它自己)

对数的“超能力” (二)

超能力二：合体与分裂 (加减法)

同底相加，真数相乘：
log₆2 + log₆18 = log₆(2 × 18) = log₆(36) = 2

同底相减，真数相除：
log₂40 - log₂5 = log₂(40 ÷ 5) = log₂(8) = 3

对数的“超能力” (三)

超能力三：指数的“弹射座椅”

logₐᵐ(bⁿ) = (n/m)logₐb

记忆方法：上面的帽子飞出去还在上面（分子），下面的帽子飞出去就跑到下面（分母）。

“弹射座椅”应用

实战演练：log₂₇9

对数的“超能力” (四)

超能力四：终极变身术 (换底公式)

logₐb = logcb / logca

超好用的“倒装句”：1 / logₐb = logba

“换底公式”应用

实战演练：计算 log₂5 × log₅8

挑战大BOSS

计算：2log₆3 + log₆4 - 1/log₂6

课堂练习 (题型一：概念)

问题: 方程 2ˣ = 7 的解为 ______。

课堂练习 (题型二：运算)

问题: lg2 + lg5 = (   )
A. 4 B. 3 C. 2 D. 1

课堂练习 (题型三：转化)

问题: 求下列各式中的x值：
(1) log₅x = 3
(2) log₃(2x+1) = 3
(3) log₁/₈x = 3
(4) log₂8ˣ = -3

课堂练习 (题型四：性质)

问题: 设 log₇4 = a, log₇3 = b，则 log₄₉36 = (   )
A. (1/2)a - b B. (1/2)b + a C. (1/2)a + b D. (1/2)b - a

课堂练习 (题型五：换底)

问题: 若 ln2 = a, ln3 = b, 则 log₈18 = (   )
A. (a+3b)/a³ B. (a+2b)/3a C. (a+2b)/a³ D. (a+3b)/3a

课堂练习 - 答案

题型一: 答案：x = log₂7
解：根据对数的概念可得方程 2ˣ = 7 的解为：x = log₂7。

题型二: 答案：D
解：lg2 + lg5 = lg(2 × 5) = lg10 = 1。

题型三: 答案：(1) 125 (2) 7/2 (3) 1/2 (4) -1
(1)解：因为 log₅x = 3，所以 x = 5³ = 125；
(2)解：因为 log₂(2x+1) = 3 所以 2x+1 = 2³ = 8，解得 x = 7/2；
(3)解：因为 log₁/₈x = 3，所以 (1/8)x = (1/2)³，所以 x = 1/2；
(4)解：因为 log₂8ˣ = -3，所以 8ˣ = 2⁻³ = 8⁻¹，所以 x = -1。

题型四: 答案：C
解：log₄₉36 = log₇²6² = log₇6 = log₇(2+3) = log₇2 + log₇3 = (1/2)log₇4 + log₇3 = (1/2)a + b。

题型五: 答案：B
解：log₈18 = ln18 / ln8 = ln(3² × 2) / ln(2³) = (2ln3 + ln2) / (3ln2) = (2b+a)/3a。

总结

记住，对数不可怕，它只是指数的“反面”，它只问一个问题：“我是多少次方？”

我们学了它的四大超能力：

  • 加减法（合体分裂）
  • 幂运算（弹射座椅）
  • 换底公式（终极变身）
  • 还有两个隐藏彩蛋！

数学就是这样，不断发明新的工具来解决新的问题。现在，这个强大的工具交到你们手上了！
