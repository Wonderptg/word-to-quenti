玩转Tan的两角和差公式

从推导到应用

"如何只用 tanα 和 tanβ 来表示 tan(α−β)？"

公式推导 (一)：思路与展开

目标明确：推导 tan(α+β)。看到Tan，我们最先想到的关系式是？没错，tanθ = sinθ/cosθ！

所以，我们很自然地可以写出： tan(α+β) = sin(α+β)/cos(α+β)。接下来，代入Sin和Cos的和角公式：

(sinαcosβ + cosαsinβ) / (cosαcosβ - sinαsinβ)

这个式子全是sin和cos，不够“纯净”。我们的目标是得到一个只含有 tanα 和 tanβ 的公式。怎么才能创造出tan呢？

公式推导 (二)：构造与化简

关键一步：为了凑出 tanα 和 tanβ，我们需要用sin除以cos。为了公平，我们将分式的分子分母四项同时除以一个“公分母”：cosαcosβ。

我们看看会发生什么奇迹：

分子第一项：(sinαcosβ)/(cosαcosβ) = tanα
分子第二项：(cosαsinβ)/(cosαcosβ) = tanβ
分母第一项：(cosαcosβ)/(cosαcosβ) = 1
分母第二项：(sinαsinβ)/(cosαcosβ) = tanαtanβ

好了，见证奇迹的时刻！整理一下，我们得到了：

tan(α+β) = (tanα + tanβ) / (1 - tanαtanβ)

公式推导 (三)：变形与结论

那 tan(α−β) 怎么推呢？数学的美妙之处在于优雅。我们知道减法就是加上一个负数，只需将上面公式里所有的β，都换成 -β。

回忆一下，Tan是奇函数，tan(−β) = −tanβ。代入上式：

tan(α+(−β)) = (tanα + tan(−β)) / (1 - tanαtan(−β))

立即得到清爽的差角公式：

tan(α−β) = (tanα - tanβ) / (1 + tanαtanβ)

核心公式总结

tan(α + β) = (tanα + tanβ) / (1 - tanαtanβ)
tan(α - β) = (tanα - tanβ) / (1 + tanαtanβ)

记忆诀竅：

“分子的符号跟着走，分母的符号反着来。”

随堂练习 (一)

1. tan(15°) 的值是？
(A) 2+√3 (B) 2-√3 (C) (√6-√2)/4 (D) 1

随堂练习 (二)

2. (tan50°+tan10°)/(1-tan50°tan10°) 的值是？
(A) tan(40°) (B) 1/√3 (C) 1 (D) √3

随堂练习 (三)

3. 已知 tanα = 1/3，则 tan(α + π/4) 的值是？
(A) 2 (B) -2 (C) 1/2 (D) -1/2

随堂练习 (四)

4. tanα, tanβ 是 x²−4x+1=0 的两根, 则 tan(α+β) 的值是？
(A) 4/3 (B) -4/3 (C) 2 (D) 不存在

练习题解析

1. 答案：B

解析：tan(15°)=tan(45°-30°)=(1-tan30°)/(1+tan30°) = (1-√3/3)/(1+√3/3) = 2-√3。

2. 答案：D

解析：结构为 tan(α+β), 等于 tan(50°+10°) = tan(60°) = √3。

3. 答案：A

解析：tan(α+π/4)=(tanα+1)/(1-tanα) = (1/3+1)/(1-1/3) = (4/3)/(2/3) = 2。

4. 答案：D

解析：由韦达定理, tanα+tanβ=4, tanα·tanβ=1。tan(α+β)=(tanα+tanβ)/(1-tanαtanβ) = 4/(1-1) = 4/0, 分母为0, 故不存在。

  • 我们学习了公式的三种用法：
    • 正着用：拆角、代入求值。
    • 代数结合用：配合韦达定理。
    • 逆着用和变着用：考验眼力和构造能力。
