平面向量基本定理

“万物皆可拆”的艺术

"想象一下玩乐高，给你两种基础块，你就能拼出整个世界！"

定理内容与理解

如果 \(\vec{e}_1\) 和 \(\vec{e}_2\) 是同一平面内两个不共线的向量，那么对于这个平面内的任意向量 \(\vec{a}\)，有且只有一对实数 \(\lambda_1, \lambda_2\)，使得：

$$\vec{a} = \lambda_1\vec{e}_1 + \lambda_2\vec{e}_2$$
  • 基底：我们称不共线的向量 \(\vec{e}_1, \vec{e}_2\) 为一组基底。
  • 核心思想：一个字——拆！把任何复杂的向量，拆解成用基底表示的形式。
  • 关键：表示方法是唯一的！这为我们列方程提供了理论基础。

第一关：常规拆解——“按图索骥”

【例题一】

在梯形ABCD中, \(AB \parallel DC\), \(DC=2AB\)。E是BC中点，用 \(\vec{AB}\) 和 \(\vec{AD}\) 作基底表示 \(\vec{AE}\)。

第二关：进阶拆解——“双线作战”

【例题二】

在\(\triangle OAB\)中, \(\vec{OC}=\frac{1}{3}\vec{OA}\), D是AB中点, OD与BC交于P。用 \(\vec{OA}\), \(\vec{OB}\) 表示 \(\vec{OP}\)。

第三关：终极技巧——“换基底”

【例题三】

在正方形ABCD中，E是BC中点, F是CD上靠近C的三等分点(\(CF = \frac{1}{3}CD\))。P在对角线AC上，若\(\vec{AP} = x\vec{AE} + y\vec{AF}\)，求x和y的关系式。

随堂练习 (1/4)

1. 下列哪组向量可以作为平面内所有向量的一组基底？

  • (A) \(\vec{e}_1 = (1, 2)\), \(\vec{e}_2 = (2, 4)\)
  • (B) \(\vec{e}_1 = (0, 0)\), \(\vec{e}_2 = (1, 3)\)
  • (C) \(\vec{e}_1 = (1, 0)\), \(\vec{e}_2 = (0, -1)\)
  • (D) \(\vec{e}_1\) 和 \(\vec{e}_2\) 方向相同

随堂练习 (2/4)

2. 根据平面向量基本定理，如果 \(\vec{e}_1\) 和 \(\vec{e}_2\) 是一组基底，且向量 \(\vec{a} = 3\vec{e}_1 + 4\vec{e}_2\)，那么这种表示方法有几种？

  • (A) 一种
  • (B) 两种
  • (C) 无数种
  • (D) 不确定

随堂练习 (3/4)

3. 在 \(\triangle ABC\) 中，点 D 是 BC 边上的中点，若以 \(\vec{AB}\) 和 \(\vec{AC}\) 为基底，则向量 \(\vec{AD}\) 可以表示为？

  • (A) \(\vec{AC} - \vec{AB}\)
  • (B) \(\vec{AB} - \vec{AC}\)
  • (C) \(\frac{1}{2}(\vec{AB} + \vec{AC})\)
  • (D) \(\frac{1}{2}(\vec{AC} - \vec{AB})\)

随堂练习 (4/4)

4. 已知向量 \(\vec{a}\) 与 \(\vec{b}\) 不共线，若向量 \(\vec{c} = 2\vec{a} + k\vec{b}\) 与向量 \(\vec{d} = -\vec{a} + 3\vec{b}\) 共线，则实数 k 的值是？

  • (A) 3
  • (B) -3
  • (C) 6
  • (D) -6

练习题解析

1. 答案： (C)

解析：根据基底的定义，作为基底的两个向量必须是不共线的。
(A) \(\vec{e}_2 = 2\vec{e}_1\)，共线。
(B) 零向量与任何向量共线。
(C) \((1, 0)\) 和 \((0, -1)\) 显然不共线。
(D) 方向相同即为共线。

2. 答案： (A)

解析：平面向量基本定理的关键内容之一就是表示的唯一性。定理中明确指出“有且只有一对实数”，因此表示方法只有一种。

3. 答案： (C)

解析：根据向量加法法则, \(\vec{AD} = \vec{AB} + \vec{BD}\)。因为 D 是 BC 的中点，所以 \(\vec{BD} = \frac{1}{2}\vec{BC}\)。而 \(\vec{BC} = \vec{AC} - \vec{AB}\)。代入整理得: \(\vec{AD} = \vec{AB} + \frac{1}{2}(\vec{AC} - \vec{AB}) = \frac{1}{2}\vec{AB} + \frac{1}{2}\vec{AC}\)。

4. 答案： (D)

解析：因为 \(\vec{c}\) 和 \(\vec{d}\) 共线，所以存在实数 \(\mu\)，使得 \(\vec{c} = \mu\vec{d}\)。代入得 \(2\vec{a} + k\vec{b} = \mu(-\vec{a} + 3\vec{b})\)。根据唯一性，对应系数必须相等，得 \( \begin{cases} 2 = -\mu \\ k = 3\mu \end{cases} \)，解得 \(\mu = -2, k = -6\)。

总结与展望

解题核心：万物皆可“拆”！

三大策略

  • 常规题：找对路径，步步替换。
  • 交点题：双重身份，列方程组。
  • 难题：基底不好，果断换掉！(正交基底有奇效)

理论基石

平面向量基本定理是向量坐标化的理论基础。我们熟悉的平面直角坐标系，本质就是以互相垂直的单位向量 \(\vec{i}=(1,0)\) 和 \(\vec{j}=(0,1)\) 为基底。点(a, b)对应的向量就是 \(\vec{v} = a\vec{i} + b\vec{j}\)。
