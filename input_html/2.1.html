不等式？小 Case！

inequalities-01

开场白与引入

今天我们来聊一个老朋友——不等式。

核心问题：

如果已知 “A 比 B 大” (即 A>B)，
你还能顺藤摸瓜，知道些啥别的秘密呢？

基本性质1：加加减减，方向不变！

如果 A > B, 那么 A±C > B±C

口语解释： 就像你比同桌高，俩人同时踩高跷 (都加上C) 或同时掉坑里 (都减去C)，身高差的“方向”不变，你还是比他高。

例子： 已知 9 > 5

→ 两边都加 3: 9+3 > 5+3 (12 > 8)

→ 两边都减 4: 9−4 > 5−4 (5 > 1)

基本性质2：乘除运算，小心陷阱！

a) 当 C 是正数时 (C > 0)

如果 A > B, 两边同乘或除以一个正数C, 不等号方向不变。

例子： 已知 12 > 8

→ 两边同乘 3: 12×3 > 8×3 (36 > 24)

→ 两边同除以 4: 12÷4 > 8÷4 (3 > 2)

基本性质2：乘除运算，小心陷阱！

b) 当 C 是负数时 (C < 0) - 重点!

如果 A > B, 两边同乘或除以一个负数C, 不等号方向必须反转！

例子： 已知 6 > 3

→ 两边同乘 -2: 6×(-2) < 3×(-2) (-12 < -6)

→ 两边同除以 -3: 6÷(-3) < 3÷(-3) (-2 < -1)

基本性质2：乘除运算，小心陷阱！

c) 当 C = 0 时

若乘以 0，则 A · 0 = B · 0 ⟹ 0 = 0。

除以 0 无意义。

基本性质3：两个不等式手拉手

假设我们有两个方向相同的不等式：A > B 且 X > Y

a) 同向相加，强者恒强

A+X > B+Y (大的+大的 > 小的+小的)

例: 8>3 且 6>2 => 8+6 > 3+2 (14 > 5)

b) 同向同正相乘

如果 A,B,X,Y 均为正数, 那么 A·X > B·Y

例: 5>2 且 4>3 => 5×4 > 2×3 (20 > 6)

注意：若不全是正数，结果不一定！

基本性质4：正数世界的乘方与开方

如果 A > B 且 A, B 均为正数

a) 乘方

Aⁿ > Bⁿ

例: 16 > 9 => 16² > 9² (256 > 81)

b) 开方

ⁿ√A > ⁿ√B

例: 16 > 9 => √16 > √9 (4 > 3)

不等式性质的应用

解题演练

题型一：选择题小杀手——特殊值法

策略：当直接判断困难时，代入满足条件的特殊数字进行检验，往往能快速排除错误选项。

例子：若 m < n < 0，则下列哪个一定成立？

  • A) m+p < n+p (两边加同个数，不变号，成立！)
  • B) mp < np (p的正负未知，方向不一定！)
  • C) m² > n² (m=-2, n=-1 => 4 > 1，成立！)
  • D) 1/m > 1/n (m=-2, n=-1 => -1/2 > -1，成立！)

题型二：比较大小 (作差法)

常规武器：作差法！

比较 M 和 N ⟹ 计算 M−N。若差 > 0 则 M > N。

例子 (配方法)：比较 a²+b²+2 与 2a+2b。

作差：(a²+b²+2) − (2a+2b) = (a−1)²+(b−1)² ≥ 0。
因此，a²+b²+2 ≥ 2a+2b。

题型二：比较大小 (平方比较法)

特殊武器：平方比较法

对付正数根号：若 M>0, N>0，则 M > N ⟺ M² > N²。

例子：比较 √11+√5 与 √8+√7。

两边平方：(√11+√5)² = 16+2√55，(√8+√7)² = 15+2√56。
问题转化为比较 16+2√55 和 15+2√56。

题型三：求取值范围 (直接凑)

基本款：直接凑

例子：已知 −1 < a < 3 且 2 < b < 5。求 2a−3b 的范围。

1. 求 2a 的范围：-2 < 2a < 6。
2. 求 −3b 的范围：-15 < -3b < -6。
3. 同向相加：-17 < 2a-3b < 0。

题型三：求取值范围 (换元法)

升级款：换元大法

例子：已知 0 < 2x−y < 3 且 1 < x+y < 4。求 5x−y 的范围。

1. 设 M=2x-y, N=x+y。
2. 解出 5x-y = 2M+N。
3. 求 2M+N 范围：0 < 2M < 6，1 < N < 4。
4. 相加得：1 < 2M+N < 10。所以 1 < 5x-y < 10。

重点题型一：比较代数式大小

例题1．若 M = x² +y²+1 ， N=2(x+y-1) ，则 M 与 N 的大小关系为（    ）

  • A． M < N
  • B． M > N
  • C． M = N
  • D．不能确定

重点题型一：比较代数式大小

例题2．已知a,b ∈R ，则 5a²+b²+2 _______ 4ab+2a．（用“>”或“<”填空）

答案与解析

例题1 解析

【答案】B

【解析】使用作差法。
M - N = (x² + y² + 1) - 2(x + y - 1)
= x² + y² + 1 - 2x - 2y + 2
= (x² - 2x + 1) + (y² - 2y + 1) + 1
= (x-1)² + (y-1)² + 1
因为 (x-1)² ≥ 0 且 (y-1)² ≥ 0，所以 (x-1)² + (y-1)² + 1 > 0。
因此 M - N > 0, 即 M > N。故选B。

例题2 解析

【答案】>

【解析】同样使用作差法并配方。
(5a²+b²+2) - (4ab+2a)
= 5a² - 4ab + b² - 2a + 2
= (4a² - 4ab + b²) + (a² - 2a + 1) + 1
= (2a-b)² + (a-1)² + 1
因为 (2a-b)² ≥ 0 且 (a-1)² ≥ 0, 所以 (2a-b)² + (a-1)² + 1 > 0。
因此 5a²+b²+2 > 4ab+2a。

课堂总结

今天咱们把不等式的核心性质过了一遍：

  • 加减同数，方向不变。
  • 乘除同数，正数不变号，负数要变号！
  • 同向不等式：可相加；同向且同正，方可相乘。
  • 正数专属：乘方开方，方向不变。

解题方法：“作差法”是万能钥匙！
