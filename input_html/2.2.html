基本不等式

探寻最值的奥秘

开场白：是何方神圣？

用一条12米长的绳子围出一块长方形花圃，怎样才能让面积最大？

这个问题的答案，就藏在基本不等式里！

a² + b² ≥ 2ab

(当a, b ≥ 0)

“等号”何时能画上？

a² + b² ≥ 2ab

当且仅当 a = b 时，等号成立。

这为什么重要？
我们算出的最值只是“理论值”，必须验证题目条件是否允许 a=b，否则最值可能取不到！

举个“坑”例：

求 f(x) = x + 9/x 的最小值 (当 x > 0)。

实战演练：和积定值问题

积定和最小

一块面积为36㎡的长方形地，周长最小是多少？

设长l, 宽w。lw=36。周长P=2(l+w)。
l+w ≥ 2√lw = 2√36 = 12。
所以 P ≥ 2×12=24。当l=w=6时取等。

实战演练：和积定值问题

和定积最大

用20米长的绳子围成一个长方形，最大面积是多少？

设长l, 宽w。2(l+w)=20 => l+w=10。
10 = l+w ≥ 2√lw => 5 ≥ √lw => 25 ≥ lw。
所以最大面积为25㎡。当l=w=5时取等。

实战演练：非齐次式问题

特征：式子里的各项“长得不太一样”，经常是一项和它倒数相关的形式。

核心目标：变形，让根号里的变量能被约掉！

技巧1：直接约分

求 f(x) = 3x + 27/x 的最小值 (当 x>0)。

技巧2：“凑项”大法

求 f(x) = x² - 2 + 4/(x²-2) 的最小值 (当x²>2)。

技巧3：分式变形

求 f(x) = (x²+2x+5)/(x+1) 的最小值 (当 x+1>0)。

实战演练：齐次式问题

特征：通常是分式，分子分母各项“次数”相同。

技巧1：直接约分

求 f(x,y) = 2x/3y + 27y/8x 的最小值 (x,y同号)。

技巧2：拆分子

求 f(x,y) = (2x²+8y²)/(xy) 的最小值 (x,y>0)。

技巧3：“换元法”

求 f(a,b) = (2a+b)/(a-3b) + 4(a-3b)/(2a+b) 的最小值 (同号非0)。

技巧4：“1的代换”

已知 2x+5y=10 (x,y>0)，求 1/x + 1/y 的最小值。

题型一：和为定值求积的最值

例题1．若a,b都为正实数，a+2b=1，则ab的最大值是（    ）

  • A． 1/4
  • B． 2/9
  • C． 1/2
  • D． 1/8

题型一：和为定值求积的最值

例题2．已知正数 x 、 y 满足 x + y/2 = 4，则 xy 的最大值为_______.

答案与解析

例题1 解析

【答案】D

【解析】因为 a,b 都为正实数，a+2b=1，
所以，1 = a+2b ≥ 2√(a * 2b) = 2√2ab。
两边平方：1 ≥ 4 * 2ab = 8ab。
所以 ab ≤ 1/8。
当且仅当a=2b，代入a+2b=1得 a=1/2, b=1/4 时，ab取最大值 1/8。
故选：D

例题2 解析

【答案】8

【解析】 4 = x + y/2 ≥ 2√(x * y/2) = 2√(xy/2)。
两边除以2: 2 ≥ √(xy/2)。
两边平方: 4 ≥ xy/2。
所以 8 ≥ xy。
当且仅当 x = y/2，代入 x+y/2=4 得 x=2, y=4 时，xy取最大值8。
故答案为：8。

课程小结

今天我们学了啥？

  • 基本不等式： a+b ≥ 2√ab (a,b≥0)。
  • 等号成立的关键：当 a=b 的时候。
  • 三大经典题型：“和积定值”，“非齐次式”(凑项)，“齐次式”(拆分)。

基本不等式就像个多面手，能解决很多看起来复杂的最值问题！
