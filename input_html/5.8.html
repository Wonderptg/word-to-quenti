两角和与差的三角函数

"sin(105°) 到底等于多少？"

推导 (一): 余弦的秘密

一切始于“基石公式”——两角差的余弦公式。

cos(α - β) = cosαcosβ + sinαsinβ

要得到 cos(α + β)，只需将上方公式中的 β 替换为 -β 即可。

cos(α + β) = cos(α - (-β))
= cosαcos(-β) + sinαsin(-β)

根据诱导公式 cos(-β) = cosβ 和 sin(-β) = -sinβ，可得：

= cosαcosβ - sinαsinβ

推导 (二): 从余弦到正弦的桥梁

利用重要的“桥梁”公式 sinθ = cos(90° - θ)，我们可以从余弦推导出正弦。

推导 sin(α + β) 的过程如下：

sin(α + β) = cos[90° - (α + β)]

将括号内变形，以套用已知的余弦差角公式：

= cos[(90° - α) - β]

展开后，再次使用诱导公式：

= cos(90°-α)cosβ + sin(90°-α)sinβ

= sinαcosβ + cosαsinβ

推导 (三): 补全最后的拼图

最后一个公式 sin(α - β)，可以通过替换法轻松得到。

在刚刚推导出的 sin(α + β) 公式中，将 β 替换为 -β：

sin(α - β) = sin(α + (-β))

= sinαcos(-β) + cosαsin(-β)

利用诱导公式化简：

= sinαcosβ - cosαsinβ

至此，四个核心公式全部推导完毕！

四大核心公式

余弦公式 (cos): 同名相乘，符号相反

cos(α - β) = cosαcosβ + sinαsinβ
cos(α + β) = cosαcosβ - sinαsinβ

正弦公式 (sin): 异名相乘，符号相同

sin(α + β) = sinαcosβ + cosαsinβ
sin(α - β) = sinαcosβ - cosαsinβ

3. 下列恒等式中，正确的是？
(A) cos(α-β)=cosαcosβ-sinαsinβ (B) cos(α+β)=cosαcosβ+sinαsinβ (C) sin(α-β)=sinαcosβ-cosαsinβ (D) sin(α+β)=sinαsinβ+cosαcosβ

随堂练习 (4/4)

4. 化简 cos(x+y)cos(y) + sin(x+y)sin(y) 的结果是？
(A) cos(x) (B) cos(x+2y) (C) sin(x) (D) sin(x+2y)

练习题解析

1. 答案：A

解析：cos(15°) = cos(45°-30°) = cos45°cos30° + sin45°sin30° = (√2/2)(√3/2) + (√2/2)(1/2) = (√6+√2)/4。

2. 答案：A

解析：结构为 sin(α-β)，等于 sin(47°-17°) = sin(30°) = 1/2。

3. 答案：C

解析：A,B选项cos公式符号反了。C选项sin公式正确。D选项是余弦公式的结构，张冠李戴了。

4. 答案：A

解析：结构为cos(X-Y)，其中X=x+y, Y=y。原式 = cos((x+y)-y) = cos(x)。
