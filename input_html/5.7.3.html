实战应用 (1): 文字信息题

文字题："g(x)=cos(ωx+φ)图像关于(π/2, 0)中心对称"

翻译： 这句话的意思就是，x = π/2 是对称中心的一个横坐标。

实战应用 (2): 图像解析

翻译：
1.从最小值到相邻的最大值，水平距离正好是半个周期！
2.所以 T/2 = 3π/4 - π/4 = π/2。
3.那么，完整的周期 T = π。

实战应用 (3): 图像信息题

图像题："图像在x=π/4取最小值，在x=3π/4取相邻最大值"

随堂练习 (1)

1. 函数 f(x)=5cos(x)−2 的值域是什么？
(A) [−7,3] (B) [−5,5] (C) [−2,5] (D) [−3,7]

随堂练习 (2)

2. 函数 y=sin(3x) 的最小正周期是多少？
(A) 2π/3 (B) π/3 (C) 2π (D) π

随堂练习 (3)

3. 得到 g(x)=cos(x+π/4) 的图像，需将 f(x)=cos(x) 如何平移？
(A) 右移π/4 (B) 左移π/4 (C) 下移π/4 (D) 上移π/4

随堂练习 (4)

4. 函数 f(x)=2sin(½x) 在 x=π 处取得什么值？
(A) 最大值 (B) 最小值 (C) 零点 (D) 非最值点

练习题解析

1. 答案：A

解析：cos(x)范围[-1,1] → 5cos(x)范围[-5,5] → 5cos(x)-2范围[-7,3]。

2. 答案：A

解析：周期 T = 2π/|ω| = 2π/3。

3. 答案：B

解析：水平平移“左加右减”，x变为x+π/4，是向左平移。

4. 答案：A

解析：f(π) = 2sin(π/2) = 2*1 = 2。函数最大值为2，所以是最大值点。

课堂总结：组合拳

乾坤大挪移

令 ωx+φ=t，化繁为简。

照猫画虎

套用sin(t), cos(t)的性质公式。

顺藤摸瓜

把t换回x，解方程/不等式。

警惕：当ω为负数时，内层函数单调性反转，“同增”变“异增”！
