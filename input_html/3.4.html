函数的奇偶性

图像的对称之美

生活中的对称

扑克牌K，旋转180度还是它自己 —— 中心对称

我们的脸，左右两边基本一样 —— 轴对称

函数图像，当然也有这两种超酷的对称特性！

核心定义

偶函数

图像关于 y轴 对称

f(-x) = f(x)

奇函数

图像关于 原点 对称

f(-x) = -f(x)

判断方法 (一)：看定义域

第一步：查户口 —— 定义域是否对称？

函数的定义域必须关于原点对称。

如果不对称，函数就既不是奇函数，也不是偶函数（非奇非偶）。

例：f(x) = √(x-1) 的定义域是 [1, +∞)，不对称，所以是非奇非偶函数。

判断方法 (二)：算关系式

第二步：验身份 —— 计算 f(-x)

在定义域对称的前提下，将x换成-x，化简后与f(x)比较：

  • 如果 f(-x) = f(x)，那么它是 偶函数。
  • 如果 f(-x) = -f(x)，那么它是 奇函数。
  • 如果二者都不相等，那就是非奇非偶函数啦。

实例演练 (偶函数)

判断 f(x) = |x-1| + |x+1| 的奇偶性。

实例演练 (奇函数)

判断 g(x) = (x³)/(x² + 1) 的奇偶性。

性质与结论：武功秘籍

  • 常见函数：x的奇次幂是奇函数，偶次幂是偶函数。|x|是偶函数。
  • 运算法则：把“奇”当负号，“偶”当正号。
    • 奇 × 奇 → 偶
    • 奇 × 偶 → 奇
    • 偶 + 偶 → 偶
    • 奇 + 奇 → 奇
  • 必杀技：如果一个奇函数在 x=0 处有定义，那么 f(0) = 0！
