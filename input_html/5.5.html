化繁为简的终极秘籍

温故知新：三角函数的定义

装备1：三角函数的定义

单位圆中，角α终边与圆交于点 P(x, y):

  • cos(α) = x (横坐标)
  • sin(α) = y (纵坐标)
  • tan(α) = y/x (纵 / 横)

关键：三角函数就是坐标！

温故知新：符号看象限

装备2：符号看象限

坐标有正负，三角函数值也有正负：

  • 第一象限 (+, +): All (+)
  • 第二象限 (-, +): sin (+)
  • 第三象限 (-, -): tan (+)
  • 第四象限 (+, -): cos (+)

口诀：一全正、二正弦、三正切、四余弦

第一组：负角公式 (-α)

角 α 和 -α 的终边关于 x轴对称。它们的交点坐标 (x, y) 关系为：

横坐标 x 相同 → cos(-α) = cos(α) (cos把负号吃掉了！)

纵坐标 y 相反 → sin(-α) = -sin(α) (sin把负号吐出来了！)

第二组：π ± α 公式

角 α 和 π+α 的终边关于 原点对称。它们的交点坐标 (x, y) 关系为：

横坐标 x 相反 → cos(π+α) = -cos(α)

纵坐标 y 相反 → sin(π+α) = -sin(α)

注意：函数名(sin, cos)没有发生改变！

第三组：π/2 ± α 公式

角 α 和 π/2-α 的终边交点所构成的三角形全等，但坐标交换了位置！

x → y' → cos(α) = sin(π/2-α)

y → x' → sin(α) = cos(π/2-α)

高能预警：函数名变了！sin↔cos

归纳总结：终极破解口诀

所有公式都可以总结为一句话：

奇变偶不变
符号看象限

奇变偶不变：看角是 k·(π/2)±α 中的k是奇数还是偶数。奇数 (π/2, 3π/2...) 则函数名互变 (sin↔cos, tan↔cot)；偶数 (π, 2π...) 则函数名不变。

符号看象限：假设α是锐角，看原角 k·(π/2)±α 落在第几象限，判断原函数在该象限的符号，添上即可。

随堂练习 1

1. 若角α终边在第二象限，哪个值一定是正数？
  • (A) cos(α)
  • (B) tan(α)
  • (C) sin(α)−cos(α)
  • (D) sin(α)∙cos(α)

随堂练习 2

2. 化简 cos(π−α) 的结果是？
  • (A) sin(α)
  • (B) -sin(α)
  • (C) cos(α)
  • (D) -cos(α)

随堂练习 3

3. 化简 sin(3π/2+α) 的结果是？
  • (A) sin(α)
  • (B) -sin(α)
  • (C) cos(α)
  • (D) -cos(α)

随堂练习 4

4. 计算 sin(210°) 的值是？
  • (A) 1/2
  • (B) -1/2
  • (C) √3/2
  • (D) -√3/2

练习题解析

1. 答案：C

解析：第二象限，sin(α)>0, cos(α)<0。 (正数) - (负数) = 正数。

2. 答案：D

解析：口诀：偶不变(cos)，符号看象限(π-α在第二象限，cos为负)。所以是 -cos(α)。

3. 答案：D

解析：口诀：奇变(cos)，符号看象限(3π/2+α在第四象限，原函数sin为负)。所以是 -cos(α)。

4. 答案：B

解析：sin(210°) = sin(180°+30°)。偶不变(sin)，符号看象限(210°在第三象限，sin为负)。所以是 -sin(30°) = -1/2。
