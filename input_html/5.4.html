核心神装：单位圆

在一个半径为1的单位圆中，角α的终边与圆的交点为 P(x, y)。从今天起，三角函数与坐标牢牢绑定：

cos(α) = x (横坐标)
sin(α) = y (纵坐标)
tan(α) = y/x (斜率)

上手实战：求240°函数值

  1. 定位：180°+60°，终边在第三象限。
  2. 找参考：终边与x轴的锐角是 240°-180°=60°。
  3. 定大小：参考60°三角形，交点坐标绝对值为 (1/2, √3/2)。
  4. 定符号：第三象限 x, y 均为负。P点真实坐标为 (-1/2, -√3/2)。
  5. 出答案：

    cos(240°) = x = -1/2

    sin(240°) = y = -√3/2

    tan(240°) = y/x = √3

规律总结：符号看象限 (推理)

Sine 看 y 坐标

y 在坐标系上方为正
(一、二象限)

Cosine 看 x 坐标

x 在坐标系右侧为正
(一、四象限)

Tangent 看 x, y 同号

x, y 同号时为正
(一、三象限)

记忆口诀：符号看象限

一个简单好记的中文口诀：

一全正，二正弦，三正切，四余弦

内功心法：商数关系

tan(α) = sin(α) / cos(α)

正切是终边斜率，即 y / x。

内功心法：平方关系 (最重要)

sin²(α) + cos²(α) = 1

源于单位圆中的勾股定理 x² + y² = 1²。

内功应用：“知一求二”

经典问题：

已知角α在第三象限，cos(α) = -5/13，求sin(α)和tan(α)？

技巧应用：齐次式问题

已知 tan(α) = 4，求 (sin(α) - 3cos(α)) / (2sin(α) + cos(α)) 的值？

2. 已知角 α 的终边在第四象限，且 sin(α) = -12/13，求 cos(α) 和 tan(α) 的值。

A. cos(α) = -12/13, tan(α) = 1

B. cos(α) = -5/13, tan(α) = 12/5

C. cos(α) = 5/13, tan(α) = -12/5

3. 如果角 θ 满足 tan(θ)>0 且 cos(θ)<0，那么角 θ 的终边在哪个象限？

A. 第二象限

B. 第一象限

C. 第三象限

D. 第四象限

实战练习 (4/4)

4. 已知 tan(α) = 3，求表达式 (2sin(α)-cos(α))/(3sin(α)+2cos(α)) 的值。

A. 7/9

B. 1

C. 5/11

D. 1/3

练习题解析

1. 答案：B (sin=1/2, cos=-√3/2, tan=-√3/3)

解析：150°在第二象限，参考角30°。根据口诀“二正弦”，只有sin为正。sin(150°)=sin(30°)=1/2, cos(150°)=-cos(30°)=-√3/2, tan(150°)=sin/cos=-1/√3=-√3/3。

2. 答案：C (cos=5/13, tan=-12/5)

解析：辅助三角形法，对边12，斜边13，则邻边为5。第四象限根据口诀“四余弦”，只有cos为正。所以cos(α)=5/13, tan(α)=-12/5。

3. 答案：C (第三象限)

解析：tan>0说明在第一或第三象限。cos<0说明在第二或第三象限。取交集，共同的象限是第三象限。

4. 答案：C (5/11)

解析：齐次式，分子分母同除cos(α)，得(2tanα-1)/(3tanα+2)。代入tan(α)=3，得(2*3-1)/(3*3+2) = 5/11。

规律：符号看象限

平方关系与商数关系，解决“知一求二”。

技巧：齐次式
