全面解析函数世界

揭开函数的神秘面纱

函数就像一个“魔法自动售货机”，本质上就是一个“输入-处理-输出”的过程。

定义一个处理过程 f(x) = 2x - 3

  • 输入 5，输出 f(5) = 2*5 - 3 = 7
  • 输入 0，输出 f(0) = 2*0 - 3 = -3
  • 输入 (a+1)，输出 f(a+1) = 2(a+1) - 3 = 2a - 1

函数三要素

定义域 (Domain)

“原料”的范围，即自变量x的合法取值集合。

对应法则 (Rule of Correspondence)

“处理程序f”，决定如何计算。

值域 (Range)

“产品”的范围，即所有可能输出的f(x)的集合。

函数的“准入规则”——求定义域

求定义域就像机场安检，有几条明确的规定：

  • 分母不能为零！ (如 1/(x-2) 中 x≠2)
  • 偶次根号下面必须大于等于零！ (如 √(x-1) 中 x≥1)
  • 一个数的零次幂，底数不能是零！ (如 (x-4)⁰ 中 x≠4)

综合安检：多规则叠加

当一个函数同时包含多种情况时，我们需要同时满足所有安检规则。

例如，求函数 f(x) = √(x-1) / (x²-9) 的定义域：

我们来分析：

  1. 看到根号 √(x-1)，安检员立刻亮灯：x-1 ≥ 0，解出来 x ≥ 1。
  2. 看到分母 x²-9，安检员再次亮灯：x²-9 ≠ 0，解出来 x ≠ 3 且 x ≠ -3。

这两个条件必须同时满足！我们画个数轴，x 要大于等于1，同时还要把 3 和 -3 这两个点挖掉。-3 本来就不在范围内，所以我们最终的定义域就是：

[1, 3) U (3, +∞)

搞定！

抽象函数定义域：以不变应万变

如果 f(x) 的定义域是 (0, 9]，求 f(x²) 的定义域？

黄金法则：同一个函数f，对括号里装的东西的要求，是永远不变的！

f(x)要求括号里的x满足 0 < x ≤ 9。

那么f(x²)就要求括号里的x²满足 0 < x² ≤ 9。

解这个不等式：x² > 0 ⟹ x ≠ 0；x² ≤ 9 ⟹ -3 ≤ x ≤ 3。

最终定义域：[-3, 0) U (0, 3]。

手段一：待定系数法

案情简介：

已经知道罪犯是“一次函数”或“二次函数”这种明确的身份。

侦破思路：

先把他的标准像画出来（比如设 f(x)=ax+b），然后根据线索（题目条件）去确定 a 和 b 的值。

案例练习：待定系数法

已知 f(x) 是一次函数，且满足 2f(x+1) - f(x) = x+3，求 f(x)。

手段二：换元法

案情简介：

f 括号里被塞进一个很复杂的“伪装”，比如 f(1/x + 1)。

侦破思路：

把这个复杂的伪装，直接起个新名字 t，然后想办法用 t 去表示式子里其他所有部分。

案例练习：换元法

已知 f(1/x + 1) = 2/x² + 3，求 f(x)。

手段三：整体代换法

案情简介：

换元后，发现用新名字 t 去表示其他部分特别困难，但其他部分和这个“伪装”长得很像，像亲兄弟。

案例练习：整体代换法

已知 f(x+2√x) = x² + 4x√x + 4x - 1，求 f(x)。

手段四：构造方程组法

案情简介：

式子里同时出现了 f(x) 和它的“影子”，比如 f(1/x)。一个方程，两个未知，解不了。

侦破思路：

我们就再制造一个方程！把原式中所有的 x 都换成它的“影子” 1/x，得到一个新方程，然后联立求解！

案例练习：构造方程组法

已知 f(x) + 3f(1/x) = 2x，求 f(x)。

挑战升级：分段函数

f(x) = { x+3, x < 0 }

f(x) = { -x²,  x ≥ 0 }

求 f(f(-4))：

先算内层 f(-4) = -4+3 = -1。

再算外层 f(-1) = -1+3 = 2。最终答案是2。

若 f(a) = -9, 求a:

分情况讨论：若a<0, a+3=-9, a=-12 (符合)。若a≥0, -a²=-9, a=3或a=-3 (舍去-3)。所以a=-12或3。

答案与解析

题型一：【答案】[-√2, 0) U (0, √2]。由 2-x²≥0 且 x≠0 解得。

题型二 (角度一)：【答案】[1, 3]。一次函数，代入端点即可。

题型二 (角度二)：【答案】[0, 2]。二次函数-x²+2x+3 = -(x-1)²+4 ≤ 4，所以根号下取值范围是[0,4]，开方后是[0,2]。

题型二 (角度三)：【答案】(-∞, 2) U (2, +∞)。f(x) = 2 - 2/(x+1)，因为 2/(x+1)≠0，所以函数值取不到2。

题型三：【答案】B。观察函数y=g(x)的图象得 g(2)=1，由表格知 f(1)=2，所以 f(g(2)) = f(1) = 2。

题型四：【答案】B。因为 -2 < 1，所以 f(-2) = -2+3 = 1。因为 1 ≥ 1，所以 f(f(-2)) = f(1) = 1²+1 = 2。
