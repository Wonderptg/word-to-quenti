第一部分：热身运动——认识“空空如也”的空集！

1. 什么是空集？

像“我们班上既是男生又是女生”的同学，或者“比2大的偶数质数”，这种一个元素都没有的集合，我们就叫它 空集。

它的专属徽章是：∅。记住，空集也是个集合哦！

它常常喜欢藏起来，变成解题路上的小陷阱，需要我们特别留意。

空集小试牛刀 (带参数版)

例：集合 P={x∈R | k−1 < x < 5−k}。要使 P 是空集，参数 k 需满足什么条件？

思路：一个区间 (L, R) 要想是空的，就需要左端点 L ≥ 右端点 R。

解题：所以我们得让 k−1 ≥ 5−k。解得：2k ≥ 6，即 k ≥ 3。

敲黑板：看到带字母参数的集合，先想“它会不会是空集？”

第二部分：闪亮登场——子集！

1. 子集是啥意思？

打个比方：A是“咱们班所有同学”，B是“整个高一年级所有同学”。

A里的每一个同学，B里头全有！我们就说，A是B的 子集。

符号：A ⊆ B (读作“A包含于B”)。

子集的“变身”形态

  • 真子集 (A ⊊ B)：A是B的子集，且B里至少有一个元素不属于A。 (A是B的“真小弟”)
  • 集合相等 (A = B)：A是B的子集，B也是A的子集。(咱俩一模一样)
  • 万能的空集：空集是任何集合的子集 (∅ ⊆ A)。空集是任何非空集合的真子集。

子集大挑战 1 (数轴显神通)

题目：集合 A={x|1≤x<7}，B={x|p≤x≤2p+1}。如果 B ⊆ A，求 p 的取值范围。

第一步：B不是空集时 (p ≤ 2p+1 ⇒ p ≥ -1)

画数轴分析，B要在A里面，则需满足：p ≥ 1 且 2p+1 < 7。解得 1 ≤ p < 3。

第二步：B是空集时 (p > 2p+1 ⇒ p < -1)

空集是任何集合的子集，所以 p < -1 也满足条件。

第三步：合并答案

最终答案是: {p | 1 ≤ p < 3 或 p < -1}。

子集大挑战 2 (分类讨论是好汉)

题目：集合 A={x|x≤−2 or x≥2}，B={x|ax>1}。如果 B ⊆ A，求 a 的取值范围。

Case 1: a > 0 ⇒ x > 1/a。要使 B ⊆ A, 需 1/a ≥ 2 ⇒ 0 < a ≤ 1/2。

Case 2: a = 0 ⇒ 0 > 1，不成立。B是空集 ∅。∅ ⊆ A 成立，所以 a=0 是解。

Case 3: a < 0 ⇒ x < 1/a。要使 B ⊆ A, 需 1/a ≤ -2 ⇒ -1/2 ≤ a < 0。

汇总：三种情况的解合起来，最终答案是 [-1/2, 1/2]。

第三部分：子集的个数

一个集合里有 n 个元素，
那么它的子集就有 2n 个！

为啥是 2n 呢？(披萨的诱惑！)

对于原集合里的每一个元素，在构成子集时，它要么“被选进”，要么“不被选进”，都是2种选择。n个元素就是n个2连乘！

子集家族成员点名 (必背！)

  • 子集总数：2n 个
  • 真子集个数：2n - 1 个 (排除自己)
  • 非空子集个数：2n - 1 个 (排除空集)
  • 非空真子集个数：2n - 2 个 (排除自己和空集)

例题1．已知集合 A = {1, 3, x}，B = {x2, 1}，若 A = B，则 x = ？

答案与解析

题一：子集的个数

【答案】B

【解析】集合有3个元素，n=3。非空真子集个数公式为 2n - 2。所以个数为 23 - 2 = 8 - 2 = 6。故选：B。

答案与解析

题二：集合之间关系的判断

【答案】B

【解析】A是所有偶数的集合，B是所有4的倍数的集合。所有4的倍数肯定都是偶数，所以B是A的子集。但A中有不属于B的元素（如2），所以B是A的真子集。故选：B。

答案与解析

题三：求子集、真子集

【答案】{a}, {b}, {a, b}

【解析】子集包括：空集 ∅，单元素子集 {a}, {b}，双元素子集 {a, b}。其中非空子集为 {a}, {b}, {a, b}。

答案与解析

题四：集合相等关系的应用

【解析】若A = B，则两集合元素必须完全相同。A有3个元素，B只有2个。要使它们相等，B必须有重复元素，即 x² = 1，解得 x=1 或 x=-1。

  • 当 x=1 时，A={1, 3, 1}，元素重复，不满足互异性，舍去。
  • 当 x=-1 时，A={1, 3, -1}，B={1, 1}，元素个数和内容都不相等。

【结论】原题条件有误，无解。在考试中遇到此类问题，应复查题目。

第四部分：课堂小结与展望

  • 空集 ∅：不含任何元素，是任何集合的子集。
  • 子集 A⊆B：A中所有元素B中都有。别忘了真子集 A⊊B。
  • 解题法宝：遇到带参数的子集问题，画数轴、分类讨论是王道，时刻警惕空集！
  • 子集个数：记住 2n 和它的“兄弟姐妹们”。
