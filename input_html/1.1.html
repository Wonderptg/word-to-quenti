课程介绍

这节课虽然涉及到的概念不少，但其实不难。我们就像拼拼图一样，一块一块拼起来，最后你会发现，原来集合挺有意思的！

第一部分：万物皆可“研究对象”

我们生活在一个充满信息的世界，各行各业都需要“研究对象”。

侦探破案

研究案发现场留下的线索：脚印、毛发、指纹等。

植物学家

关注各种植物：小草、灌木、大树等。

游戏策划

研究玩家行为：谁最爱玩刺客、谁总爱换皮肤等。

换句话说，只要你想研究，它就能成为你的研究对象！

第二部分：把研究对象“装进篮子”——这就是集合

“我不想只研究大树，我还想研究蘑菇、小草、蒲公英，一起研究！”

恭喜你，你就在“无意识”地创建一个集合了！

我们把某一类研究对象“归在一起”，这个“整体”就叫 集合。

集合 = 一组对象的总体

元素 = 集合里的每一个具体成员

第三部分：换个角度理解集合和元素

一个 班级 就是一个集合。

班里的每个同学——王小明、李小红、张大龙……他们就是这个集合里的 元素。

班级（集合）表示“整体”，学生（元素）表示“组成整体的一个个具体个体”。

你的 “文具大宝盒” 就是一个集合！

里面的圆珠笔、橡皮擦、尺子、便利贴……它们就是 元素。

第四部分：最贴近生活的集合例子

“我们学校食堂里最受欢迎的四道菜”：

红烧鸡腿 番茄炒蛋 麻辣豆腐 糖醋里脊

这四道菜可以组成一个集合：“本周最受欢迎食堂菜品集合”。

✔ 集合 是“最受欢迎菜品”这个整体。

✔ 元素 是具体的那几道菜！

元素关系与数学符号

一个元素和集合的关系只有两种：

  • 一个元素 属于 某个集合。
  • 一个元素 不属于 某个集合。

数学中的表示方法：

我们用符号 ∈ 表示“属于”。

我们用符号 ∉ 表示“不属于”。

例如：1 ∈ {1, 2, 3} (1 属于集合 {1, 2, 3})

例如：-1 ∉ {1, 2, 3} (-1 不属于集合 {1, 2, 3})

集合的基本特性 (1): 确定性

确定性 就是：能不能明确判断某个元素到底在不在集合里？有没有一个统一的判断标准？

❌ 不具备确定性

所有“唱歌好听的同学” (标准主观)

“成绩好的学生” (标准模糊)

✅ 具备确定性

数学成绩在 90 分及以上的学生 (标准明确)

比 100 大的自然数 (标准明确)

小游戏时间：哪些能构成集合？

1. 所有“刷抖音时间超过3小时”的同学？ ❌ 不行 (定义模糊)

2. 在一次测试中英语成绩低于60分的同学？ ✅ 可以 (标准明确)

3. 喜欢辣条的人？ ❌ 不行 (没统一标准)

4. 放学后第一时间冲去小卖部的学生？ ❌ 不行 (难界定)

✔ 所以只有第 2 项是可以构成集合的。

集合的基本特性 (2): 无序性

无序性 指的是：集合中元素的排列顺序没有关系。

{2, 4, 6}

=

{4, 2, 6}

=

{6, 4, 2}

只要元素一样，不管你怎么排列，它们都是 同一个集合。

集合的基本特性 (3): 互异性

互异性 指的是：集合中不能出现重复元素。

❌ 错误写法

{3, 3, 5, 7}

✅ 正确写法

{3, 5, 7}

集合中的每一个元素都是独一无二的。

经典数字例题

题目：已知集合 S = {A², A + B, B ÷ A}，并且 S = {1, A, 0}，问 A 和 B 的值是多少？

1. 分析元素 0： 集合中有 0，所以 B ÷ A = 0，得出 B = 0 (且 A ≠ 0)。

2. 代入 B=0： S = {A², A, 0}。因为 S = {1, A, 0}，所以 A² = 1。

3. 求解 A： A² = 1 的解是 A = 1 或 A = -1。

4. 检验互异性：

- 如果 A = 1，那么集合 S = {1, 1, 0}。出现了重复元素 1，不满足互异性！ ❌

- 如果 A = -1，那么集合 S = {1, -1, 0}。元素各不相同，满足互异性！ ✅

答案：A = -1, B = 0

常见数集及其符号

自然数集 (N): 包含0和正整数。 N = {0, 1, 2, 3, ...}

正整数集 (N⁺ 或 N*): 不包含0的自然数。 N⁺ = {1, 2, 3, ...}

整数集 (Z): 包括正整数、负整数和0。 Z = {..., -2, -1, 0, 1, 2, ...}

有理数集 (Q): 能写成分数形式的数。 Q = {p/q | p,q ∈ Z, q ≠ 0}

实数集 (R): 数轴上所有的点，包括有理数和无理数 (如 π, √2)。

这些字母是数学中的固定约定，必须熟记！

必背总结：常见数集符号

数集名称 符号 内容举例
自然数 N 0, 1, 2, 3, ...
正整数 N⁺ / N* 1, 2, 3, ...（不含0）
整数 Z ..., -2, -1, 0, 1, 2, ...
有理数 Q 1/2, -3, 0.75
实数 R 所有有理数 + 无理数（π、√2）

集合的表示方法

列举法

(Roster Method)

描述法

(Set-Builder Notation)

一、列举法 (一个个列出来)

例1: 大于1且小于5的整数

A = {2, 3, 4}

例2: 绝对值小于3的整数

B = {-2, -1, 0, 1, 2}

例3: 所有偶数 (用省略号)

C = {..., -2, 0, 2, ...}

二、描述法 (用“条件”来刻画)

{ 研究对象 | 满足的条件 }

例1: 大于1且小于5的整数

A = {x | 1 < x < 5, x ∈ Z}

例2: 绝对值小于3的整数

B = {x ∈ Z | |x| < 3}

描述法进阶

所有偶数:

C = {x | x = 2k, k ∈ Z}

所有奇数:

D = {x | x = 2k + 1, k ∈ Z}

第一象限的点集:

E = {(x, y) | x > 0, y > 0}

课后习题

重点题型一：集合的概念

例题1．下面各组对象中不能形成集合的是（    ）

  • A．所有的直角三角形
  • B．一次函数y=x+1
  • C．高一年级中家离学校很远的学生
  • D．参加智选未来线上课的所有同学

【答案】C

【解析】集合的元素必须是确定的。选项A，B，D中的对象都是确定的，可以构成集合。而选项C中“家离学校很远”的标准不确定，因人而异，没有一个明确的界限，所以这些学生无法构成一个确定的集合。故选：C。

课后习题

重点题型二：元素与集合的关系

例题1．给出下列关系：① π ∈ R；② √2 ∈ Q；③ -3 ∉ N*；④ |-√5| ∉ Q，其中正确的个数为（    ）

  • A．1
  • B．2
  • C．3
  • D．4

【答案】B

【解析】π是实数，属于实数集R，故①正确；√2是无理数，不属于有理数集Q，故②错误；-3是负整数，不属于正整数集N*，故③正确；|-√5| = √5 是无理数，不属于有理数集Q，故④正确。所以正确的个数为2。故选：B。

课后习题

重点题型三：集合的表示方法（1）列举法

例题1．方程 x² - x = 0 的所有实数根组成的集合为（    ）

  • A．{0}
  • B．{1}
  • C．{0, 1}
  • D．{(-1, 0), (1, 0)}

【答案】C

【解析】解方程 x² - x = 0，可得 x(x - 1) = 0，解得 x = 0 或 x = 1。所以方程的所有实数根组成的集合为 {0, 1}。故选：C。

课后习题

重点题型三：集合的表示方法（2）描述法

例题1．由大于-3且小于2的偶数所组成的集合是（    ）

  • A．{-1, 1}
  • B．{-2, 0}
  • C．{x | -3 < x < 2, x ∈ Z}
  • D．{-2, 0, 2}

【答案】B

【解析】大于-3且小于2的整数有-2, -1, 0, 1。在这些数中，偶数是-2和0。因此，所求集合为 {-2, 0}。故选：B。

✅ 总结：两种表示方法

列举法

适用于元素个数有限或规律明确时。

描述法

适用于元素个数无限或不好列出时。
