指数函数

指数级增长的奥秘

什么是指数函数？

y = aˣ

严格的“门槛”：

  • 底数 a > 0
  • 且底数 a ≠ 1

要和幂函数 y = x² 分清楚：x在楼上当指数才是指数函数！

图像探索：增长联盟 (a > 1)

第一个代表：y = 3ˣ

我们来描几个点：

  • 当 x = -1 时，y = 3⁻¹ = 1/3
  • 当 x = 0 时，y = 3⁰ = 1
  • 当 x = 1 时，y = 3¹ = 3
  • 当 x = 2 时，y = 3² = 9

函数图像从左向右，一路向上！

图像探索：衰减联盟 (0 < a < 1)

第二个代表：y = (1/3)ˣ

再来描几个点：

  • 当 x = -1 时，y = (1/3)⁻¹ = 3
  • 当 x = 0 时，y = (1/3)⁰ = 1
  • 当 x = 1 时，y = (1/3)¹ = 1/3
  • 当 x = 2 时，y = (1/3)² = 1/9

函数图像从左向右，逐渐“衰减”。

看图说话：共同性质

  • 定义域：R (全体实数)
  • 值域：(0, +∞)
  • 定点：所有指数函数都经过大本营 (0, 1)！
  • 单调性：a > 1 时递增，0 < a < 1 时递减。
  • 对称性：y = aˣ 和 y = (1/a)ˣ 的图像关于 y 轴对称。

应用一：比较图像高低 (策略篇)

如何比较 y=5ˣ, y=2ˣ, y=(1/2)ˣ, y=(1/5)ˣ？

第一步：分两组。

根据底数a的大小，y=5ˣ, y=2ˣ 是增函数 (a>1)，y=(1/2)ˣ, y=(1/5)ˣ 是减函数 (0<a<1)。

第二步：画垂线 x=1 比较。

在y轴右侧(x>0)，图像“高低”和底数“大小”顺序一致。底数越大，图像越高。

结论：在y轴右侧，图像从上到下，底数a从大到小。

应用一：图像直观对比

观察直线 x=1 与各图像交点的高低顺序。

应用二：巧找定点

求 y = a¹⁻ˣ - 5 的定点

核心技巧是让指数部分为0，因为任何数的0次幂都等于1，这样就能摆脱变化的底数`a`的干扰。

  1. 令指数 `1-x = 0`，解得 `x=1`。
  2. 将`x=1`代入原函数，计算y值：
    `y = a¹⁻¹ - 5 = a⁰ - 5 = 1 - 5 = -4`。

所以，定点为 (1, -4)。

指数函数的“套娃”玩法

如何求解复合函数 y = 4(-x²+2x+3) 的值域和单调性？

解题方法：“剥洋葱法”

“剥洋葱法”四步走：

1. 看“洋葱心”(内层函数)：

令 t = -x²+2x+3 = -(x-1)²+4。这是一个开口向下的二次函数，所以 t ≤ 4。

2. 看“洋葱皮”(外层函数)：

原函数变为 y = 4ᵗ。这是一个底数大于1的指数函数，是增函数。

3. 求值域 (内到外)：

因为 t ≤ 4 且 y=4ᵗ 递增，所以 y ≤ 4⁴ = 256。结合指数函数值域恒>0，最终值域为 (0, 256]。

4. 看单调性 (同增异减)：

当x>1时，内层函数t递减，外层函数y递增。一增一减，所以整体是减函数。

课堂练习（一）

函数 f(x) = ax + 1 (a>0, 且 a≠1) 的图像过的定点是？

  • A. (0,1)
  • B. (1,0)
  • C. (0,2)
  • D. (2,0)

课堂练习（二）

下列是指数函数的是？

  • A. y = -3x
  • B. y = 2x² - 1
  • C. y = ax+1
  • D. y = πx

课堂练习（三）

函数 f(x) = a(x+2) + 1 的图像恒过的定点是？

  • A. (1,2)
  • B. (-1,2)
  • C. (0,2)
  • D. (-2,2)

课堂练习（四）

若 y = (a²-3a+3)ax 是指数函数，则a=？

  • A. a=1 或 2
  • B. a=1
  • C. a=2
  • D. a>0 且 a≠1

课堂练习：答案与解析

1. 答案：C. (0,2)

解析：基础指数函数 y=ax 恒过定点(0,1)。函数 f(x)=ax+1 是将 y=ax 的图像向上平移1个单位得到的，所以定点也向上平移1个单位，变为 (0, 1+1)，即 (0,2)。

2. 答案：D. y = πx

解析：指数函数的严格定义是 y = ax (a>0, a≠1)。选项D中底数π是满足条件的常数。A选项系数不为1，B选项是二次函数，C选项指数不为x。

3. 答案：D. (-2,2)

解析：利用“巧找定点”的方法，令指数部分为0。令 x+2=0，得x=-2。此时 y = a0+1 = 1+1 = 2。所以定点为 (-2,2)。

4. 答案：C. a=2

解析：要使该函数成为指数函数，必须满足：1. 系数 (a²-3a+3) 等于 1；2. 底数 a>0 且 a≠1。由条件1解得 a=1 或 a=2。再结合条件2，必须舍去a=1。所以最终答案是 a=2。

总结回顾

好了，今天的内容就差不多了。我们来回顾一下：

  • 我们认识了指数函数 y=aˣ 和它的两个“阵营”：底数大于1的“增长联盟”和底数在0和1之间的“衰减联盟”。
  • 我们掌握了它们图像的五大核心性质，最重要的是单调性，以及它们都在 (0, 1) 这个“大本营”集合。
  • 我们学会了如何比较大小、找定点，还接触了复合函数的分析方法。

记住，研究函数最重要的思想就是数形结合！把图像牢牢记在脑子里，所有问题都会迎刃而解。

指数函数是我们未来学习对数函数的基础，也是解决很多现实问题的钥匙，大家一定要掌握好！
