函数的心跳

单调性

【概念引入】—— 说人话！

想象两个同学小明(x₁)和小红(x₂)在跑道上，小红跑在前面 (x₁ < x₂)。

单调递增

跑在前面的小红，分数f(x₂)也更高。
“强者恒强”，图像是上坡！

单调递减

跑在前面的小红，分数f(x₂)反而更低。
“后来居上”，图像是下坡！

【核心方法】—— 画图

图像是函数的“心电图”，单调性一眼看穿！

例1：y = |x-3|

这是一个在 x=3 处触底的“V”字形。

单调减区间：(-∞, 3)

单调增区间：(3, +∞)

建议用开区间，永远不会错！

【核心方法】—— 画图

例2：y = tan(x)

图像是一条条向上‘窜’的曲线。

单调增区间：(-π/2 + kπ, π/2 + kπ), k∈Z

灵魂拷问：能用并集符号吗？
绝对不行！多个区间用“和”或“，”隔开。

【知识回顾】—— 单调性判断

2. 下列函数中，在区间\((0, +\infty)\)上单调递减的是 (     )

A. \(f(x) = x + 1\)

B. \(f(x) = (\frac{1}{2})^x\)

C. \(f(x) = x^2\)

D. \(f(x) = \cos x\)

【知识回顾】—— 解析

第1题解析：

这是一个开口向上的二次函数。判断其在某个区间上的单调性，关键是看对称轴的位置。

对称轴公式为 \(x = -\frac{b}{2a}\)。对于 \(y = x^2 - 6x + 10\)，对称轴是 \(x = -\frac{-6}{2 \cdot 1} = 3\)。

题目给定的区间是 \((2, 4)\)，对称轴 \(x=3\) 恰好在这个区间内部。因此，函数在对称轴左侧是递减的，在对称轴右侧是递增的。

具体来说，函数在区间 \((2, 3]\)上单调递减，在区间 \([3, 4)\)上单调递增。

所以，在整个区间 \((2, 4)\) 上是“先减后增”。正确答案：C

第2题解析：

需要判断各个基本函数在区间 \((0, +\infty)\) 上的单调性。

  • A: \(f(x) = x + 1\) 是一次函数，斜率k=1>0，在R上单调递增。
  • B: \(f(x) = (\frac{1}{2})^x\) 是指数函数，底数 \(0 < \frac{1}{2} < 1\)，在R上单调递减。
  • C: \(f(x) = x^2\) 是二次函数，在 \((0, +\infty)\) 区间上单调递增。
  • D: \(f(x) = \cos x\) 是三角函数，周期性变化，在 \((0, +\infty)\) 上不是单调函数。

因此，唯一在指定区间单调递减的是B。正确答案：B

【问题进阶】—— 分段函数的单调性

要在定义域上单调，必须满足：“内部和谐，外部统一”

设函数
f(x) = {
-2x + 3, x ≤ 1 (a-3)x, x > 1
在 R 上单调递减，求a。

Step 1: 内部和谐 (即，函数在每一段区间内都必须是单调递减的。)

  • 当 x≤1 时，f(x) = -2x+3，斜率为-2，是递减的，满足要求。
  • 当 x>1 时，f(x) = (a-3)x，要使其递减，斜率 a-3 必须小于 0。

a - 3 < 0 ⟹ a < 3

【问题进阶】—— 分段函数的单调性 (续)

Step 2: 外部统一

即，在分段点 (x=1) 处，函数图像不能“向上跳”，否则就会出现一个增区间。

具体来说，左侧区间在分段点的值必须 大于等于 右侧区间在分段点的值。

左侧值：f(1) = -2(1) + 3 = 1

右侧值（在x=1处的极限）：(a-3)(1) = a-3

1 ≥ a - 3 ⟹ a ≤ 4

【问题进阶】—— 分段函数的单调性 (完)

Step 3: 取交集

两个条件必须同时满足：

  • 由“内部和谐”得到： a < 3
  • 由“外部统一”得到： a ≤ 4

将两个不等式取交集，得到最终的答案。

最终答案: a < 3
