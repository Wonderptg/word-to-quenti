"1440度的角真的存在吗？"

给角“松绑”：从静态到动态

忘掉“两条射线的夹角”，我们用旋转来定义！

  • 始边：光束的起始位置 (X轴正方向)。
  • 终边：光束旋转后停止的位置。
  • 角：从始边到终边的旋转量。

方向的意义：上楼还是下楼？

正角 (+)

逆时针旋转 (上楼)，角度为正。例如：+150° (终边在第二象限)。

负角 (-)

顺时针旋转 (下楼)，角度为负。例如：-60° (终边在第四象限)。

殊途同归：终点一样的不同旅程

45°, 405°, -315° ... 它们的终边完全重合！

所有与角 α 终边相同的角，都可以表示为：α + k · 360° (k为整数)

打破思维定势

🤔 第二象限角 = 钝角？

不一定！比如 130°+360° = 490°。终边在第二象限，但远大于180°。

🤔 小于90°的角 = 锐角？

不一定！比如 -200°。远小于90°，但终边在第二象限。

结论：角的象限只看终边，和角的大小是两回事！

实战：从公式到图

画出 {α | k·180°+30° ≤ α ≤ k·180°+90°, k∈Z} 的区域。

  • 当 k=1: [210°, 270°] (第三象限)
  • 当 k=2: 回到第一象限...

  • A. 45° + k·180°, k∈Z
  • B. 45° + k·360°, k∈Z
  • C. 135° + k·180°, k∈Z

随堂练习 (4/4)

4. 已知角α的终边在右图阴影表示的范围内(不包含边界)，那么角α的集合是 ________.

随堂练习 - 答案解析

1. 答案：B

【详解】终边相同的角相差周角的整数倍，A不正确；相等的角终边一定相同，所以B正确；小于90°的角是锐角可以是负角，C错；第一象限的角是正角，也可以是负角，D错误。故选：B。

2. 答案：D

【详解】∵ 2022° = 5 × 360° + 222°，∴ 与 2022°终边相同的角是 222°。故选：D。

3. 答案：A

【详解】终边与直线 y = x 重合的角可表示为 45° + k·180°, k∈Z。故选：A。

4. 答案：{α | k·360° + 45° < α < k·360° + 150°, k∈Z}

【详解】观察图形可知，阴影区域的右边界与x轴正方向成45°角，左边界与x轴负方向成30°角，即与x轴正方向成180°-30°=150°角。因为不包含边界，所以角的集合是 {α | k·360° + 45° < α < k·360° + 150°, k∈Z}。
