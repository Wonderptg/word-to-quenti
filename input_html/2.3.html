不等式轻松搞定

从二次函数到参数问题

热身与基石：二次函数

解开所有不等式谜题的钥匙，就是我们的老朋友——二次函数！

二次函数的“脸谱”怎么画？

  • 开口方向 (a)
  • 对称轴 (x = -b/2a)
  • 判别式 (Δ = b²-4ac)
  • 与y轴交点 (x=0)

二次函数的三张“身份证”

一般式：y = ax² + bx + c

例：y = x² - 4x + 3

顶点式：y = a(x-m)² + n

例：y = (x-2)² - 1

两根式：y = a(x-x₁)(x-x₂)

例：y = (x-1)(x-3)

两根的“悄悄话”——韦达定理

对于 ax² + bx + c = 0 的两根 x₁, x₂

x₁ + x₂ = -b/a

x₁x₂ = c/a

核心技能：一元二次不等式

本质就是画出函数图像，然后“看图说话”！

解不等式 x² - 4x + 3 < 0

1. 看作函数 y = x² - 4x + 3

2. 开口向上，与x轴交于 x=1, x=3

3. 小于0，即x轴下方的部分

解集：1 < x < 3

换个花样：换元大法

解 e²ˣ - 5eˣ + 4 ≤ 0

这个看着不像二次的呀？别慌！

你看，e²ˣ 是 (eˣ)²。咱们就令 t = eˣ。

因为 eˣ 总是正的，所以有个隐藏条件 t > 0！

换掉之后，不等式就变成了：

t² - 5t + 4 ≤ 0

换个花样：看图说话

解 t² - 5t + 4 ≤ 0

因式分解 (t-1)(t-4) ≤ 0。

画个关于t的抛物线，交点是 t=1 和 t=4。要‘小于等于0’，就是 t 轴下方的部分。

解集：1 ≤ t ≤ 4

还没完！咱们求的是x...
代回 t = eˣ，得 1 ≤ eˣ ≤ 4。
两边取对数: ln(1) ≤ x ≤ ln(4)。
最终解集: 0 ≤ x ≤ ln(4)

拓展延伸：分式不等式

变形咒语：除法变乘法，分母不为零！

A/B > 0 ⟺ A·B > 0

A/B < 0 ⟺ A·B < 0

🚨 B ≠ 0

来个简单的：解 (x-4)/(x+2) < 0

  1. 用咒语，变成 (x+2)(x−4) < 0。
  2. 这是个开口向上，与x轴交于 x=-2 和 x=4 的抛物线。‘小于0’的部分，就是 -2 < x < 4。
  3. 别忘了检查分母！x+2 ≠ 0 ⟹ x ≠ -2。解集 -2 < x < 4 已经满足。

如果右边不是0呢？

解 (x+5)/(x-1) ≥ 1

  1. 不能直接两边同乘 x−1！标准做法是移项通分！
  2. (x+5)/(x-1) - 1 ≥ 0 ⟹ 6/(x-1) ≥ 0。
  3. 分子6是正数，所以分母 x−1 必须是正数。
  4. 所以 x-1 > 0 ⟹ x > 1。（分母不能为0，所以没有等号）

再强调一遍“带等号”的陷阱

解 (x-1)/(x+3) ≤ 0

  1. 可以化为 (x−1)(x+3) ≤ 0 且 x+3 ≠ 0。
  2. 解 (x−1)(x+3) ≤ 0 得到 −3 ≤ x ≤ 1。
  3. 但是！x+3 ≠ 0 ⟹ x ≠ −3。
  4. 综合一下，最终答案是 −3 < x ≤ 1。-3那边的等号被去掉了！

挑战升级：参数来了！

解关于 x 的不等式 x² + mx + 4 > 0

万变不离其宗——还是看图像，但要“看情况”画图！

这个“情况”由谁决定？还是判别式 Δ = m² - 16！

Δ 的三种“脸色”：情况一

情况一：Δ < 0 (判别式害羞了)

1. m²−16 < 0 ⟹ −4 < m < 4。

2. 抛物线开口向上，且跟x轴没交点（整个飘在x轴上方）。

3. 那么 x²+mx+4 是不是永远都大于0？是的！

4. 所以，当 −4 < m < 4 时，解集是 全体实数R！

Δ 的三种“脸色”：情况二

情况二：Δ = 0 (和x轴握了个手)

1. m²−16 = 0 ⟹ m=4 或 m=−4。

2. 抛物线开口向上，刚好和x轴在顶点处碰了一下。f(x)≥0 恒成立。

3. 我们要的是 x²+mx+4 > 0，所以除了那个等于0的点 (顶点 x=−m/2) 都满足。

4. 当 m=4 时，(x+2)²>0，解为 x ≠ -2。

5. 当 m=-4 时，(x-2)²>0，解为 x ≠ 2。

Δ 的三种“脸色”：情况三

情况三：Δ > 0 (热情拥抱了两次)

1. m²−16 > 0 ⟹ m < -4 或 m > 4。

2. 抛物线开口向上，和x轴有两个不同的交点 x₁, x₂。

3. x₁,₂ = (-m ± √m²-16) / 2

4. 要使 x²+mx+4 > 0，x应该在两根之外。

5. 解集是 x < x₁ 或 x > x₂。

课堂练习

题型一：一元二次不等式

例题1．解不等式：(2x-3)(4-x) < 0

题型一：一元二次不等式

例题2．解不等式：-2x² + x + 1 < 0

题型二：分式不等式

例题1．解不等式：(x+1)/(x-2) ≥ 3

题型二：分式不等式

例题2．解不等式：(2x+1)/(x+2) ≥ 1

答案与解析

题型一 解析

例题1：

(2x-3)(4-x) < 0 => (2x-3)(x-4) > 0. 解得 x > 4 或 x < 3/2。

例题2：

-2x² + x + 1 < 0 => 2x² - x - 1 > 0 => (2x+1)(x-1) > 0. 解得 x > 1 或 x < -1/2。

题型二 解析

例题1：

(x+1)/(x-2) - 3 ≥ 0 => (-2x+7)/(x-2) ≥ 0 => (2x-7)(x-2) ≤ 0, 且 x≠2. 解得 2 < x ≤ 7/2。

例题2：

(2x+1)/(x+2) - 1 ≥ 0 => (x-1)/(x+2) ≥ 0 => (x-1)(x+2) ≥ 0, 且 x≠-2. 解得 x ≥ 1 或 x < -2。
