温故知新：从钟表说起

时针走一整圈，是360度。

如果时针从12点走到了4点，它扫过的角度是 120度。

这个扇形的面积占整个圆形钟面的多少呢？很简单，就是它角度占的比例：

120° / 360° = 1/3

所以，这段弧长是整个周长的 1/3，这块扇形面积也是整个圆面积的 1/3。

旧方法的本质：按比例分配

基于刚刚的钟表例子，我们可以总结出初中的核心公式：

弧长 l = (n/360) ⋅ 2πr

面积 S = (n/360) ⋅ πr²

弧度制下的核心公式

纪律：角 α 的单位必须是弧度！

1. l = αr (由定义 α=l/r 变形得)
2. S = ½αr² (按比例 α/2π 得)
3. S = ½lr (三角形类比法)

实战练习 (4/4)

4. 一个扇形的弧长为2，圆心角为1rad，则该扇形的面积为( )

A. 2     B. 3     C. 4     D. 5

练习题解析

1. 答案：C (9cm)

解析：周长 C = 2r + l = 15。又 l = αr = 3r。代入得 2r + 3r = 15 => 5r=15 => r=3。所以 l = 3*3=9cm。

2. 答案：C (6)

解析：先换算角度，40° = 40 * (π/180) = 2π/9 rad。由 l = αr 得 r = l/α = (4π/3) / (2π/9) = (4π/3) * (9/2π) = 6。

3. 答案：B (6π)

解析：60° = π/3 rad。先求半径 r = l/α = 2π / (π/3) = 6。再求面积 S = ½lr = ½ * 2π * 6 = 6π。

4. 答案：A (2)

解析：先求半径 r = l/α = 2 / 1 = 2。再求面积 S = ½lr = ½ * 2 * 2 = 2。

课堂总结

l = αr

S = ½αr²

S = ½lr

(三角形类比)

最重要的纪律：用这套公式，角 α 必须是弧度！
