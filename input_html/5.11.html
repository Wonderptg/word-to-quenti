“合二为一”的魔术

辅助角公式

"\( f(x) = 3\sin x + 4\cos x \) 的最大值是多少？"

是 7 吗？

它是怎么来的？—— 拆解公式的秘密

灵感来源于两角和公式的“逆向思维”：我们想把 \( a\sin x + b\cos x \) 凑成 \( R(\sin x \cos\phi + \cos x \sin\phi) \) 的形式。

以 \( f(x) = \sin x - \cos x \) 为例：

几何绝招：画点法

记忆技巧：对于任何 \(a\sin x + b\cos x\)，就在坐标系画出点 \(P(a, b)\)。
原点到P的距离就是系数 \(R\)，向量 \(\vec{OP}\) 与x轴正半轴的夹角就是辅助角 \(\phi\)。

应用一：轻松搞定最值和值域

求 \( f(x) = 3\sin x + 4\cos x \) 的最值。

应用二：解决定义域受限难题

求 \( g(x) = 2\sin x + 2\sqrt{3}\cos x \) 在 \( x\in[0, \frac{\pi}{2}] \) 上的值域。

应用三：作为化简“组合拳”的最后一击

化简 \( h(x) = 4\sin x \cos x - 2\cos^2 x + 1 \)。

随堂练习 (2/4)

2. 函数 \( f(x)=\sin x+\sqrt{3}\cos x \) 的最大值是？

(A) 1

(B) \(\sqrt{3}\)

随堂练习 (3/4)

3. \( \cos x − \sin x \) 可以化简为？

(A) \(\sqrt{2}\sin(x+\frac{\pi}{4})\)

(B) \(\sqrt{2}\sin(x-\frac{\pi}{4})\)

(C) \(\sqrt{2}\sin(x+\frac{3\pi}{4})\)

(D) \(2\sin(x+\frac{3\pi}{4})\)

随堂练习 (4/4)

4. 对于函数 \(f(x)=4\sin x+3\cos x\)，使用辅助角公式将其合并为一个正弦函数后，新函数的最小正周期是？

(A) \(\pi\)

(B) \(2\pi\)

(C) \(5\pi\)

(D) 周期会改变

练习题解析

1. 答案：C

解析：\(R = \sqrt{a^2+b^2} = \sqrt{5^2+(-12)^2} = \sqrt{25+144} = \sqrt{169} = 13\)。

2. 答案：C

解析：\(R = \sqrt{1^2+(\sqrt{3})^2} = 2\)。函数可化为 \(2\sin(x+\phi)\)，最大值为2。

3. 答案：C

解析：标准形式 \(-1\sin x+1\cos x\)。\(a=-1, b=1, R=\sqrt{2}\)。\(\cos\phi=-\frac{1}{\sqrt{2}}, \sin\phi=\frac{1}{\sqrt{2}}\), \(\phi\)在第二象限，为 \(\frac{3\pi}{4}\)。所以化为 \(\sqrt{2}\sin(x+\frac{3\pi}{4})\)。

4. 答案：B

解析：辅助角公式只改变振幅和相位，不改变角频率 \(\omega\)。原函数 \(\omega=1\), 周期 \(T=\frac{2\pi}{1}=2\pi\)。合并后 \(\omega\) 不变，周期依然是 \(2\pi\)。

总结一下

  • 核心操作：提出“魔法数字” \(\sqrt{a^2+b^2}\)。
  • 记忆技巧：画出点 \((a,b)\)，距离是系数R，角度是 \(\phi\)。
  • 两大用途：直接求最值；在限定定义域时，通过“换元三步法”精确求解。
  • 一个思路：在复杂化简中，它通常作为降次、统一角度之后的“最后一击”。
