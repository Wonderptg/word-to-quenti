幂函数：形态各异的“一家人”

今天的明星脸: y = xα

破冰起航：幂函数的“身份证”

y = xα

关键信息 1:

底数 x 是自变量。

关键信息 2:

指数 α 是一个常数。

例如 y=x² (二次函数), y=x⁻¹ (反比例函数) 都是这个家族的核心成员。

寻踪觅迹：家族特征

第一个家族特征：它们的图像都经过一个共同的点 (1, 1)。

第二个家族特征：在第一象限，指数 α 决定了函数的“性格”。

🚀 “火箭型” (α > 1)

如 y=x³, 增长迅猛，越来越陡。

🧗 “登山型” (0 < α < 1)

如 y=√x, 增长平缓，越走越慢。

🎢 “滑梯型” (α < 0)

如 y=x⁻², 在第一象限飞流直下。

家族成员图像对比

将“火箭”、“登山”、“滑梯”三种类型放在一起直观比较。

登堂入室：画图三句“咒语”

记住三个问题，就能画出任意幂函数！

咒语一

你在第一象限长啥样？ (定“型”)

咒语二

你的地盘有多大？ (定“义”)

咒语三

你是“对称”的吗？ (定“性”)

咒语一：你在第一象限长啥样？ (定“型”)

这句是看它的“性格”，由指数α的大小决定。

我们以 y=x5/3 为例。

它的指数 5/3 ≈ 1.67，是大于1的。

所以，它是“火箭型” 🚀，在第一象限飞速增长。

我们先画出它在第一象限的草图。

咒语二：你的地盘有多大？ (定“义”)

这句是问它的定义域，关键看指数分母是奇数还是偶数。

分母为偶，根下为正

y=x1/4 = ⁴√x。分母是4(偶)，根号下不能为负。定义域: x≥0。

分母为奇，畅通无阻

y=x5/3 = ³√x⁵。分母是3(奇)，什么数都能放。定义域: R。

咒语三：你是“对称”的吗？ (定“性”)

如果定义域关于原点对称，我们就来判断函数的奇偶性。

奇函数：关于原点对称

例如: y = x5/3

因为 f(-x) = (-x)5/3 = -x5/3 = -f(x)

咒语三：你是“对称”的吗？ (定“性”)

我们再看一个偶函数的例子。

偶函数：关于y轴对称

例如: y = x-4/3

因为 g(-x) = (-x)-4/3 = x-4/3 = g(x)

明察秋毫：别被“冒牌货”骗了

核心定义：

幂函数 y=xα 的系数必须是 1！

像 y=2x⁴ 这样的函数，不是纯正的幂函数家族成员。

“冒牌货”例题精讲

例题：已知 f(x)=(k²−3)xk 是一个幂函数, 且经过点 (2, 1/4)，求k。

  1. 第一步 (定身份): 因为是幂函数, 所以系数 k²−3 = 1。解得 k²=4, 即 k=2 或 k=-2。
  2. 第二步 (代入验真):
    • 当k=2时: 函数为 f(x)=x²。代入点(2, 1/4) => f(2)=2²=4。这与给定的y值 1/4 不符，所以 k=2 淘汰。
    • 当k=-2时: 函数为 f(x)=x⁻²。代入点(2, 1/4) => f(2)=2⁻²=1/4。完全正确！
  3. 最终答案: k = -2

练习一：解析

题目: 已知点 M(2, b) 在幂函数 f(x)=(b−1)xn 的图象上，则 b+2n= ?

答案: C. 4

① 定系数: f(x)是幂函数 ⟹ 系数 (b−1) 必须等于 1 ⟹ b=2。

② 定指数: 函数化为 f(x)=xn。点 M(2, b) 即 M(2, 2) 在图像上，代入得 2 = 2n ⟹ n=1。

③ 计算结果: b+2n = 2 + 2(1) = 4。

练习二：解析

题目: 幂函数 f(x)=(m²−(5/2)m+2)xm 在(0,+∞)上单调递增，则m=?

答案: B. m=1/2 或 m=2

① 定系数: f(x)是幂函数 ⟹ m²-(5/2)m+2 = 1。方程两边同乘2得 2m²-5m+2=0。因式分解为 (2m-1)(m-2)=0。解得 m=1/2 或 m=2。

② 定指数: 函数 f(x)=xm 在(0,+∞)上单调递增 ⟹ 指数m > 0。我们得到的两个解 m=1/2 和 m=2 都大于0，符合条件。

③ 最终结果: m=1/2 或 m=2。

练习三：解析

题目: 已知函数 f(x)=(m²−4m+5)xm (m∈R) 为幂函数，则 m=？

答案: D. 2

① 定系数: f(x)是幂函数 ⟹ 系数 m²−4m+5 必须等于 1。

② 解方程: m²−4m+4=0。这是一个完全平方公式 (m-2)²=0。

③ 最终结果: m=2。

练习四：解析

题目: 已知 f(x)=(a−1)xa 为幂函数，则 f(-2)=？

答案: C. 4

① 定系数: f(x)是幂函数 ⟹ 系数 (a−1) 必须等于 1 ⟹ a=2。

② 得函数: 函数为 f(x)=x²。

③ 计算结果: f(-2) = (-2)² = 4。

  • 发现了家族两大特征：图像都过 (1, 1) 点，第一象限有三种性格（火箭、登山、滑梯）。
  • 掌握了画图三句“咒语”：定型、定义、定性。
