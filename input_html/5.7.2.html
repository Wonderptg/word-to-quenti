y = A sin( ωx + φ ) + B

函数图像变换全解析

"四个参数，四种变换，一次搞定"

第一步：参数 B (垂直平移)

参数 B: 垂直平移

决定图像的中心线位置。B > 0 上移，B < 0 下移。

第二步：参数 A (垂直伸缩)

参数 A: 垂直伸缩 (振幅)

sin(ωx + φ) 的值域是 [-1, 1]。当它乘以 A 之后，值域就变成了 [-|A|, |A|]。

|A| 决定图像的振幅 (波峰或波谷到中心线的最大距离)。
• |A| > 1, 图像被拉伸。
• |A| < 1, 图像被压缩。

第二步 (补充): 参数 A & B 结合分析

例子：分析 y = 3sin(x) + 2

  1. 中心线 (由 B 决定): 因为 B = +2，所以中心线上移至 y=2。
  2. 振幅 (由 A 决定): 因为 A = 3，图像会从中心线 y=2 分别向上、下波动3个单位。
  3. 值域: 函数的最大值为 2+3=5，最小值为 2-3=-1。所以值域为 [-1, 5]。

第三步：参数 ω (水平伸缩)

参数 ω: 水平伸缩 (周期)

决定图像的周期 T = 2π/|ω|。
• |ω|>1, 周期变短, 图像压缩。
• |ω|<1, 周期变长, 图像拉伸。

第四步：参数 φ (水平平移)

参数 φ: 水平平移 (相位)

φ 叫作初相位，决定 x=0 时图像的初始位置。

  • 误区纠正: 平移距离不是 φ, 而是 |φ/ω|。需要将函数整理为 y = A sin(ω(x + φ/ω)) + B 的形式来判断。
  • 画图技巧: 直接令 x=0, 计算初相位 φ 对应的y值，即 y = sin(φ)，就可以找到与y轴的交点，确定图像的起点。

综合应用

y = 2sin(πx/2 - π) - 1

2. 函数 f(x) = sin(4x + π/3) 的最小正周期是？
(A) 4π    (B) 2π    (C) π    (D) π/2

随堂练习 (3/4)

3. 要得到 y = sin(2x + π/6) 的图像，需将 y = sin(2x) 如何平移？
(A) 左移 π/6    (B) 右移 π/6    (C) 左移 π/12    (D) 右移 π/12

随堂练习 (4/4)

4. 哪个函数在 x=0 时取得最大值？
(A) y = 2sin(x - π/2)    (B) y = 2sin(x + π/2)    (C) y = 2sin(x + π)    (D) y = 2sin(x)

练习题解析

1. 答案：C

解析：sin(2x) 范围 [-1,1]。乘以 A=3 得 [-3,3]。因为 B=-1，整体向下平移1个单位，得 [-4,2]。

2. 答案：D

解析：周期 T = 2π/|ω| = 2π/4 = π/2。

3. 答案：C

解析：y = sin(2(x + π/12))。根据“左加右减”，是向左平移 π/12。

4. 答案：B

解析：x=0 时取得最大值，即 sin(初相位) 需为1。sin(π/2) = 1。选项B在 x=0 时，括号内为 π/2。
