三角函数图像与性质

如何给函数“画像”

"图像是解决几乎所有函数问题的核心方法"

y = sin(x) 图像绘制

核心原理：sin(x) 的值 = 单位圆上终边交点的纵坐标。

y = sin(x) 在 (-4π, 4π) 的图像

周期性：无限的循环

正弦函数的图像呈现出一种循环往复的模式。我们只需画出其中一段，就可以通过平移得到完整的图像。

  • 周期性: 函数值会规律性地重复出现。
  • 最小正周期 (T): 完成一次完整循环所需的最短长度。对于 sin(x)，T = 2π。
  • 其他周期: 4π, 6π, 8π... 也是 sin(x) 的周期，但我们通常关注最小正周期。

sin(x) 核心性质

定义域: R
值域: [-1, 1]
周期: T = 2π
奇偶性: 奇函数
对称轴: x=π/2+kπ
对称中心: (kπ, 0)

单调性

增区间: [-π/2+2kπ, π/2+2kπ]

减区间: [π/2+2kπ, 3π/2+2kπ]

sin(x)应用题：图像应用

类型一：图像的直接应用

知识点: 看图说话，理解图像的基本含义。

例题1: “请看着y=sin(x)的图像，直接回答：当 x=7π/6 时，sin(x)的值是正数还是负数？它离-1更近还是离0更近？”

sin(x)应用题：周期性应用

类型二：周期性的应用

知识点: 利用 sin(x + 2kπ) = sin(x) 来求解。

例题2: “我们知道 sin(π/6) = 0.5，请利用周期性，直接写出 sin(13π/6) 和 sin(-11π/6) 的值。”

sin(x)应用题：单调性应用

类型三：单调性的应用

知识点: 运用函数图像的“上坡”（递增）和“下坡”（递减）趋势来比较大小。

例题3: “不使用计算器，请利用y=sin(x)图像的单调性，判断下列大小关系，应该填写 ‘ > ’ 还是 ‘ < ’ ？”

  1. sin(π/4) ______ sin(5π/12)
  2. sin(11π/18) ______ sin(8π/9)

y = cos(x) 图像的由来

核心关系： cos(x) = sin(x + π/2)

这意味着，cos(x) 的图像就是将 sin(x) 图像向左平移 π/2 个单位得到。

y = cos(x) 在 (-4π, 4π) 的图像

cos(x) 核心性质

定义域: R
值域: [-1, 1]
周期: 2π
奇偶性: 偶函数
对称轴: x = kπ
对称中心: (π/2 + kπ, 0)

单调性

增区间: [-π+2kπ, 2kπ]

减区间: [2kπ, π+2kπ]

cos(x)应用题：图像应用

类型一：图像的直接应用

知识点: 看图说话，理解cos(x)图像从(0,1)点出发的基本形态。

例题1: “请看着y=cos(x)的图像，直接回答：当 x = 2π/3 时，cos(x)的值是正数还是负数？它与cos(π/3)的值有什么关系？”

cos(x)应用题：周期性应用

类型二：周期性的应用

知识点: 利用 cos(x + 2kπ) = cos(x) 来求解。

例题2: “我们知道 cos(π/3) = 0.5，请利用周期性，快速求出 cos(7π/3) 和 cos(-5π/3) の値。”

cos(x)应用题：单调性应用

类型三：单调性的应用

知识点: 运用cos(x)图像在不同区间的“上坡”和“下坡”趋势来比较大小。

例题3: “不使用计算器，请利用y=cos(x)图像的单调性，判断下列大小关系，应该填写 ‘ > ’ 还是 ‘ < ’ ？”

  1. cos(π/9) ______ cos(π/4)
  2. cos(7π/6) ______ cos(4π/3)

y = tan(x) 介绍

定义： tan(x) = sin(x)/cos(x)

关键特征：在 x = π/2 + kπ 处有垂直渐近线。

y = tan(x) 在 (-4π, 4π) 的图像

tan(x) 核心性质

定义域: x ≠ π/2 + kπ

值域: R

周期: π

奇偶性: 奇函数

对称中心: (kπ/2, 0)

单调性: 在各开区间 (-π/2+kπ, π/2+kπ) 内单调递增

tan(x)应用题：图像应用

类型一：图像的直接应用

知识点: 理解tan(x)图像的基本形态和渐近线的概念。

例题1: “请看着y=tan(x)的图像，直接回答：tan(π/2)的值存在吗？tan(-π/2)呢？为什么？”

tan(x)应用题：周期性应用

类型二：周期性的应用

知识点: tan(x)的周期是π，而不是2π。利用 tan(x + kπ) = tan(x) 来求解。

例题2: “我们知道 tan(π/4) = 1，请利用周期性，快速求出 tan(5π/4) 和 tan(-3π/4) 的值。”

tan(x)应用题：单调性应用

类型三：单调性的应用

知识点: tan(x)在每一个被渐近线隔开的区间内，都是严格单调递增的。

例题3: “不使用计算器，请利用y=tan(x)图像的单调性，判断下列大小关系，应该填写 ‘ > ’ 还是 ‘ < ’ ？”

  1. tan(π/6) ______ tan(π/3)
  2. tan(5π/9) ______ tan(13π/18)
