化学平衡

基本概念与平衡状态

什么是可逆反应？

定义：

在相同条件下，既能向正反应方向进行，同时又能向逆反应方向进行的反应。

2SO₂(g) + O₂(g) ⇌ 2SO₃(g)

Cl₂ + H₂O ⇌ HCl + HClO

N₂(g) + 3H₂(g) ⇌ 2NH₃(g)

可逆反应辨析

这不是可逆反应：

2H₂ + O₂ --(点燃)→ 2H₂O

2H₂O --(电解)→ 2H₂↑ + O₂↑

原因：反应条件不同。“点燃”和“电解”不是相同条件，反应不能同时进行。

可逆反应在方程式中用⇌表示。

可逆反应的特征

双向性

分为方向相反的两个反应（正反应、逆反应）。

双同性

在相同条件下，正、逆反应同时进行。

共存性

反应物转化率小于100%。反应物与生成物共同存在。反应有限度。

什么是化学平衡状态？

定义：

在一定条件下的可逆反应中，当正反应速率等于逆反应速率时 (v(正) = v(逆))，反应体系中所有物质的浓度（或物质的量等）都不再发生变化的状态。

前提：只有可逆反应才能建立化学平衡。

动态平衡 (Dynamic Equilibrium)

v(正) = v(逆) ≠ 0

特点：

平衡不是反应停止了。从微观上看，正、逆反应仍在进行，只是速率相等。

例：H₂(g) + I₂(g) ⇌ 2HI(g) 达平衡时，H₂ 的消耗速率 = H₂ 的生成速率。

类比：银行存款10亿。花钱速率(逆) = 赚钱速率(正)，宏观存款(浓度)不变，但微观上钱仍在进出。

化学平衡的特征

定 (Constant)

平衡混合物中，各组分的百分含量、浓度、物质的量等保持恒定。

变 (Variable)

化学平衡是有条件的、相对的。当外界条件改变时，化学平衡可能被破坏并发生移动。

化学平衡状态的建立

以 H₂(g) + I₂(g) ⇌ 2HI(g) 为例：

Case 1: 从正反应开始 (投 H₂ 和 I₂)

[H₂] [I₂] 逐渐↓ ⟹ v(正) 逐渐↓

[HI] 逐渐↑ ⟹ v(逆) 逐渐↑

最终：v(正) = v(逆)，达到平衡。

Case 2: 从逆反应开始 (只投 HI)

[HI] 逐渐↓ ⟹ v(逆) 逐渐↓

[H₂] [I₂] 逐渐↑ ⟹ v(正) 逐渐↑

最终：v(正) = v(逆)，达到平衡。

如何判定化学平衡状态？

方法一：直接判定 (定义法)

v(正) = v(逆)

方法二：间接判定 (口诀法)

变量不变，即达平衡

“变量不变”的辨析

口诀的核心在于“变量”二字。

是“变量”：

一个物理量（如 [A] 的浓度），在反应开始后一直在变，当它突然不再变化时，说明达到了平衡。

不是“变量” (是“常量”)：

一个物理量（如总质量，或A+B⇌C+D的总物质的量），从反应开始到结束始终不变。它恒定不变不能说明达到了平衡。

判定标准 (一)：浓度/物质的量

反应：mA(g) + nB(g) ⇌ pC(g) + qD(g) (假设从A、B投料)

√ 一定是平衡的标志：

各物质的物质的量、浓度、质量、质量分数、体积分数... 不再变化。

（因为 [A], [B] 一定在↓，[C], [D] 一定在↑，它们都是“变量”。）

判定标准 (二)：速率

√ 一定是平衡的标志：

1. 单位时间内，消耗 m mol A，同时生成 m mol A。(v(A,正) = v(A,逆))

2. 单位时间内，消耗 n mol B，同时消耗 q mol D。(v(B,正) = v(D,逆)，且n:q符合计量数)

3. 同一物质，断键速率 = 成键速率。

× 不是平衡的标志：

1. v(A):v(B):v(C):v(D) = m:n:p:q (任何时刻都成立)

2. 单位时间内，生成 n mol B，同时消耗 q mol D。(同为逆反应)

判定标准 (三)：压强/体积

反应：mA(g) + nB(g) ⇌ pC(g) + qD(g)

Case 1: 反应前后气体计量数不等

m + n ≠ p + q

此时，总物质的量(n)是“变量”。

√ 平衡标志：
恒温恒容下，总压强不再变化。
恒温恒压下，总体积不再变化。

Case 2: 反应前后气体计量数相等

m + n = p + q

此时，总物质的量(n)是“常量”。

× 不是平衡标志：
总压强或总体积始终不变，无法用于判断。

判定标准 (四)：平均摩尔质量 (M̄)

M̄ = m / n

分析： m (气体总质量) 和 n (气体总物质的量) 中，至少有一个是“变量”，M̄ 才能作为判断标志。

× 不能判断：
m+n = p+q 且 全部是气体 (m, n均不变)

√ 可以判断：
1. m+n ≠ p+q (n 是变量)
2. 有非气体参与反应 (m 是变量)。
例如 A(s) + 2B(g) ⇌ C(g) + D(g)，反应前后气体总物质的量n不变 (2→2)，但固体A转化为气体C和D，气体总质量m发生变化，m是“变量”。

判定标准 (五)：T, ρ, 颜色

√ 温度 (T)

在绝热体系 (与外界无热交换) 中，反应必伴随热效应 (吸热/放热)，T是“变量”。当T不再变化，即达平衡。

× 密度 (ρ)

在恒温恒容下，对于全部为气体的反应，ρ = m / V。m (总质量) 和 V (体积) 始终不变，ρ是“常量”。

√ 体系颜色

如果反应物或生成物有颜色 (如 I₂ 紫色, NO₂ 红棕色)，其浓度是“变量”。当颜色深度不再变化，即达平衡。

随堂练习（一）

可逆反应的“可逆”是指？

(A) 反应物可以 100% 转化为生成物

(B) 反应只能正向进行

(C) 反应可以在不同条件下向正、逆方向进行

(D) 在相同条件下，正、逆反应能同时进行

练习题（一）：解析

答案：(D)

解析：

可逆反应的关键特征是在相同条件下，正向反应和逆向反应能同时发生。C选项的“不同条件”是错误的，例如电解水和氢气燃烧。

随堂练习（二）

化学平衡状态的本质特征是？

(A) 反应物浓度为 0

(B) 正、逆反应速率均为 0 (反应停止)

(C) 反应物和生成物浓度相等

(D) 正、逆反应速率相等且不为 0

练习题（二）：解析

答案：(D)

解析：

化学平衡是一种动态平衡，其根本标志是 v(正) = v(逆) ≠ 0。反应并未停止 (B错)，反应物也不会耗尽 (A错)，浓度也不一定相等 (C错)。

随堂练习（三）

下列哪个物理量在反应 H₂(g) + I₂(g) ⇌ 2HI(g) 达到平衡时不再变化？

(A) 体系的总压强

(B) 体系的总物质的量

(C) 混合气体的密度

(D) H₂ 的浓度

练习题（三）：解析

答案：(D)

解析：

该反应是气体计量数相等 (1+1=2) 的反应。在恒温恒容下，总压强(A)、总物质的量(B)、密度(C) 始终是“常量”，不能作为平衡标志。

H₂ 的浓度在反应开始后不断减小，是“变量”，当它不再变化时，说明达到了平衡。

随堂练习（四）

对于反应 2SO₂(g) + O₂(g) ⇌ 2SO₃(g)，下列哪个能说明已达平衡？

(A) 恒温恒容下，容器内密度不变

(B) SO₂, O₂, SO₃ 的浓度之比为 2:1:2

(C) 恒温恒容下，容器内总压强不变

(D) 消耗 2 mol SO₂ 的同时，消耗 1 mol O₂

练习题（四）：解析

答案：(C)

解析：

(A) 恒温恒容下，气体总质量m和体积V始终不变，密度ρ是“常量”。

(B) 浓度之比不一定等于计量数之比，与起始量有关。

(C) 此反应气体计量数不等 (2+1 ≠ 2)，总物质的量n是“变量”，总压强P也是“变量”。当P不再变化，即达平衡。

(D) 消耗SO₂和消耗O₂ 描述的同为正反应速率，任何时刻都成立。

随堂练习（五）

在一个绝热（不与外界热交换）的密闭容器中进行放热反应 A(g) ⇌ B(g)。哪个物理量不再变化时，说明反应达到平衡？

(A) 密度

(B) 压强

(C) 温度

(D) A的质量

练习题（五）：解析

答案：(C) 和 (D)

解析：

(A)(B) 反应 1(g) ⇌ 1(g) 气体计量数相等，总物质的量n和总压强P是“常量”。密度ρ也是“常量”。

(C) 体系绝热且反应放热，所以反应开始后温度T会不断升高，T是“变量”。当T不变时，即达平衡。

(D) A是反应物，其质量m(A)不断减少，是“变量”。当m(A)不变时，即达平衡。
