核外电子的排布方式

本节课内容

这节课内容是高中化学的重要基础，虽然抽象难懂，但非常重要。高一、高二、高三同学都建议学习。

能层 (K, L, M, N...)

定义：

核外电子的能量不同。离核越近，能量越低；离核越远，能量越高。我们将电子分成不同的能层。

n = 1： K 层 (1楼)

n = 2： L 层 (2楼)

n = 3： M 层 (3楼)

n = 4： N 层 (4楼)

记忆：烤(K)冷(L)面(M)(N)

能量高低：K < L < M < N ...

杰哥原子大酒店 (布局)

能层 (楼层) n 能级 (房间类型) 原子轨道 (房间数) 轨道总数 ($n^2$)
K (1楼) 1 1s 1 1
L (2楼) 2 2s, 2p 1 + 3 4
M (3楼) 3 3s, 3p, 3d 1 + 3 + 5 9
N (4楼) 4 4s, 4p, 4d, 4f 1 + 3 + 5 + 7 16

规律：第 n 能层，就有 n 种能级，共有 n² 个原子轨道（房间）。

什么是电子云？(房间的样子)

无法观测的电子：

电子质量极小、运动极快（近光速）。

我们无法像观察宏观物体（如学姐）一样去观测它。光一打到电子，电子就“飞”了（像被高铁撞到）。

小倩学姐 (鬼) 的比喻

我们无法观测电子（小倩学姐），不知道它下一秒在哪，只能描述它在某个空间出现的概率。

电子云：就是电子在核外空间概率分布的形象化描述。点越密集，出现概率越大。

电子云轮廓图 (s, p 形状)

我们用轮廓图来表示电子在空间中出现概率 > 90% 的区域形状：

s 轨道 (Spherical)

球形 (中心对称)

酒店比喻：360°无敌海景房

p 轨道 (Principal)

哑铃形/纺锤形

有3个 ($\text{p}_x$, $\text{p}_y$, $\text{p}_z$)，互相垂直。

酒店比喻：商务大床房

电子云轮廓图 (d, f 形状)

d 轨道 (Diffused)

花瓣形 (四个花瓣)

有 5 个，其中 4 个为四花瓣形，1个为双哑铃加环状。

酒店比喻：普通标间

f 轨道 (Fundamental)

形状复杂 (八花瓣或哑铃加双环)

有 7 个，形状极度复杂，高中阶段只需了解。

酒店比喻：工具间/杂物间 (最不爽)

原子轨道的能量 (房间价格)

能量越低，越稳定（住得越“爽”）。

1. 同能层 (n) 中：

s < p < d < f

(海景房 < 商务房 < 标间 < 工具间)

2. 同能级 (形状相同)：

1s < 2s < 3s < 4s...

(楼层越低，能量越低)

3. 同能层、同能级 (简并轨道)：

3px = 3py = 3pz

(同一楼层的同类型房间，能量相等)

随堂练习 (一)

在原子的四个能层 K、L、M、N 中，能量最低的是哪个能层？

(A) M层

(B) N层

(C) K层

(D) L层

练习 (一)：解析

答案：(C)

解析：

电子能量由能层决定，能层序号 $\text{n}$ 越小（离原子核越近），能层能量越低。K 层 ($\text{n}=1$) 能量最低，N 层 ($\text{n}=4$) 能量最高。

随堂练习 (二)

关于原子轨道的空间形状，下列说法正确的是？

(A) s 轨道是哑铃形

(B) p 轨道是球形

(C) d 轨道是复杂的八瓣形

(D) p 轨道是哑铃形，且有 $\text{p}_x, \text{p}_y, \text{p}_z$ 三个相互垂直的方向

练习 (二)：解析

答案：(D)

解析：

s 轨道是球形，p 轨道是哑铃形，且一个能级包含 $\text{p}_x, \text{p}_y, \text{p}_z$ 三个相互垂直的轨道。d 轨道形状多为四花瓣形，f 轨道才是更复杂的形状。
