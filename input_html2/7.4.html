空间向量求角度

空间向量求角度

拆解“公式迷魂阵”

"一个武器，搞定三“角”演义"

破冰：我们的“唯一武器”

我们用 方向向量 $\vec{v}$ 表示“一条线”，用 法向量 $\vec{n}$ 表示“一个面”。

而我们唯一能直接计算的角度关系，就是两个向量夹角 $\theta$ 的余弦值：

$\cos \theta = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}| |\vec{b}|} = \frac{x_1 x_2 + y_1 y_2 + z_1 z_2}{\sqrt{x_1^2+y_1^2+z_1^2} \sqrt{x_2^2+y_2^2+z_2^2}}$

我们的任务：将几何角 $\alpha$ (线线/线面/二面角) 与我们算出的向量角 $\theta$ 建立联系。

案例实战：搭建“演义舞台”

为了让概念更清晰，我们搭建一个具体的场景：一个四棱锥 P-ABCD。

  • 底面 $ABCD$ 是一个边长为2的正方形，位于 $xy$ 平面上。
  • $A$ 点在原点 $(0,0,0)$。
  • $B$ 点在 $x$ 轴上 $(2,0,0)$，$D$ 点在 $y$ 轴上 $(0,2,0)$，所以 $C$ 点是 $(2,2,0)$。
  • 顶点 $P$ 在底面中心正上方，坐标为 $(1, 1, 2)$。

接下来，我们将用这个模型来逐一击破三种角的计算。

第一幕：线线角 (最简单的“小弟”)

求异面直线 $PA$ 和 $BC$ 所成的角

第二幕：线面角 (最特殊的“怪咖”)

求直线 $PA$ 和底面 $ABCD$ 所成的角

第三幕：二面角 (最难缠的“Boss”)

求侧面 $PAB$ 和底面 $ABCD$ 所成的二面角

随堂练习：巩固一下 (例题 1)

1. 问题：在使用空间向量法求两条异面直线所成的角 $\alpha$ 时，如果算出的两条直线方向向量的夹角 $\theta$ 为 $120^\circ$，那么 $\cos \alpha$ 的值是多少？

  • A. $\frac{1}{2}$
  • B. $-\frac{1}{2}$
  • C. $\frac{\sqrt{3}}{2}$
  • D. $-\frac{\sqrt{3}}{2}$

随堂练习：巩固一下 (答案与解析 1)

答案：A

解析：

线线角的口诀是“恒为正，不变名”。因为线线角 $\alpha$ 定义为锐角或直角，所以其 $\cos \alpha$ 必须为非负值。向量夹角 $\theta$ 和线线角 $\alpha$ 的关系是 $\cos \alpha = |\cos \theta|$。这里 $\cos \theta = \cos 120^\circ = -\frac{1}{2}$，所以 $\cos \alpha = |-\frac{1}{2}| = \frac{1}{2}$。

随堂练习：巩固一下 (例题 2)

2. 问题：在求直线与平面所成的角 $\alpha$ 时，我们利用直线的方向向量 $\vec{v}$ 和平面的法向量 $\vec{n}$ 的夹角 $\theta$ 来计算。下列哪个公式是正确的？

  • A. $\cos \alpha = |\cos \theta|$
  • B. $\sin \alpha = |\sin \theta|$
  • C. $\sin \alpha = |\cos \theta|$
  • D. $\cos \alpha = \pm\cos \theta$

随堂练习：巩固一下 (答案与解析 2)

答案：C

解析：

线面角的口诀是“恒为正，要变名”。因为线面角 $\alpha$ 和向量夹角 $\theta$ 存在互余关系，所以函数名会改变。题目若求 $\sin \alpha$，则需要计算 $|\cos \theta|$；若求 $\cos \alpha$，则需要计算 $|\sin \theta|$。所以C是正确的。

随堂练习：巩固一下 (例题 3)

3. 问题：在用空间向量法求角时，哪种情况下计算余弦值时需要根据图形判断最终结果的正负号？

  • A. 求线线角时
  • B. 求线面角时
  • C. 求二面角时
  • D. 所有情况下都需要

随堂练习：巩固一下 (答案与解析 3)

答案：C

解析：

线线角和线面角都定义为锐角或直角，其正弦值和余弦值总是非负的，所以直接取绝对值即可。而二面角可以是钝角，其余弦值可能是负数，因此需要根据图形判断二面角的锐钝，来决定最终 $\cos \alpha$ 的正负。

随堂练习：巩固一下 (例题 4)

4. 问题：参考讲义中的四棱锥P-ABCD，直线 $PC$ 和直线 $AB$ 所成角的余弦值是多少？

  • A. $\frac{1}{\sqrt{6}}$
  • B. $-\frac{1}{\sqrt{6}}$
  • C. $\frac{2}{\sqrt{5}}$
  • D. $\frac{1}{2}$

随堂练习：巩固一下 (答案与解析 4)

答案：A

解析：

首先计算两条直线的方向向量。
$\vec{PC} = C - P = (2 - 1, 2 - 1, 0 - 2) = (1, 1, -2)$
$\vec{AB} = B - A = (2 - 0, 0 - 0, 0 - 0) = (2, 0, 0)$
然后计算向量夹角的余弦值 $\cos \theta$。
点积：$\vec{PC} \cdot \vec{AB} = (1)(2) + (1)(0) + (-2)(0) = 2$
模长：$|\vec{PC}| = \sqrt{1^2 + 1^2 + (-2)^2} = \sqrt{6}$，$|\vec{AB}| = \sqrt{2^2 + 0^2 + 0^2} = 2$
$\cos \theta = \frac{2}{2\sqrt{6}} = \frac{1}{\sqrt{6}}$
因为是求线线角，口诀是“恒为正，不变名”，所以所求角的余弦值 $\cos \alpha = |\cos \theta| = |\frac{1}{\sqrt{6}}| = \frac{1}{\sqrt{6}}$。

终极总结：一张“防错表”

角度类型 $\alpha$ 范围 向量关系 核心口诀 核心公式
线线角 $[0, \pi/2]$ 方向-方向恒为正，不变名$\cos \alpha = |\cos \theta|$
线面角 $[0, \pi/2]$ 方向-法恒为正，要变名$\sin \alpha = |\cos \theta|$
二面角 $[0, \pi]$ 法-法看图定正负, 不变名$\cos \alpha = \pm \cos \theta$

谁最怪？ → 线面角！只有它“要变名”（$\cos$变$\sin$），因为几何角和向量角互余。

谁最烦？ → 二面角！只有它的余弦值要“看图定正负”，因为它可能是钝角。

谁最乖？ → 线线角！无脑加绝对值就完事儿。
