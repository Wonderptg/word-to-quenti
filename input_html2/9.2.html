等差数列

核心概念与四大公式

"万物皆可 $a_1$ 和 $d$。"

啥叫等差？(概念入门)

例子： (5, 10, 15, 20, ...)

“等差”就是“相等的差值”。

  • $10 - 5 = 5$
  • $15 - 10 = 5$
  • $20 - 15 = 5$

核心三要素：

  • 首项 ($a_1$)： 第一个大哥。($a_1 = 5$)
  • 公差 ($d$)： 那个固定的差值。($d = 5$)
    （必须是 后项 - 前项）
  • 等差中项： 若 $A, B, C$ 成等差，则 $B$ 是中项。
    核心性质：$A + C = 2B$

概念小抢答 (看你懂了没)

问题一： 7, 7, 7, 7, ...这是不是等差数列？

答案：必须是！ 咱来算公差：$7 - 7 = 0$。公差 $d = 0$。零也是一个“定值”啊！这种叫常数列，它也是等差数列的一种特殊情况。

问题二： 100, 90, 80, 70, ...这是不是等差数列？

答案：也是！ 咱来算公差：$90 - 100 = -10$。$80 - 90 = -10$。公差 $d = -10$。谁说公差不能是负数啦？

啥叫“等差中项”？

这个概念巨简单。如果有三个数，比如 $A, B, C$，它们仨排排坐，成了一个等差数列。

那么，中间这个 $B$，就叫做 $A$ 和 $C$ 的等差中项。

比如： 100, 90, 80。 90 就是 100 和 80 的等差中项。

它有个特别重要的性质：

$A + C = 2B$

为啥呢？

因为 $B - A = d$，$C - B = d$。

所以 $B - A = C - B$，把 $B$ 移到一边，$A, C$ 移到另一边，不就是 $2B = A + C$ 吗？

说白了，中间项 $B$ 就是两边项 $A$ 和 $C$ 的平均值！ $B = \frac{A+C}{2}$

核心武器：通项公式 ($a_n$)

例：求 (5, 10, 15...) 的第100项 $a_{100}$。

$a_{100} = a_1 + (100-1)d = 5 + 99 \times 5 = 500$

第 $n$ 项，就是从 $a_1$ 的基础上跳了 $(n-1)$ 次公差。

✅ 公式一 (标准)： $a_n = a_1 + (n-1)d$

推论： $a_8$ 和 $a_3$ 差几个 $d$？差 $8-3=5$ 个 $d$。

✅ 公式二 (灵活)： $a_n = a_m + (n-m)d$

核心武器：前 $n$ 项和 ($S_n$)

求 (5, 10, ..., 500) 的前100项和 $S_{100}$。

✅ 公式三 (高斯公式)： $S_n = \frac{n(a_1 + a_n)}{2}$

应用： $S_{100} = \frac{100 \times (a_1 + a_{100})}{2} = \frac{100 \times (5 + 500)}{2} = 25250$

推导： 把 $a_n = a_1 + (n-1)d$ 代入公式三...

✅ 公式四 (万能公式)： $S_n = na_1 + \frac{n(n-1)}{2}d$

应用： 求 $S_n$ 只需要 $a_1$ 和 $d$。

上战场！(解题思路)

思路一：【万能法】

不管题目给啥，统统换成 $a_1$ 和 $d$ 解方程组。

思路二：【基准法 / 中项法】(推荐)

灵活运用等差中项性质。(见下页实例)

练习2 (感受 $S_n$ 公式的应用)

题目：已知等差数列 \(a_n\) 中， \(a_1 = 100\)， \(d = -5\)。求前10项和 \(S_{10}\)。

实战演练

题目：已知等差数列 \(a_n\) 中， \(S_7 = S_{12}\)。求 \(S_{19}\)。

随堂练习 (1/4)

1. 在等差数列 $5, 8, 11, 14, ...$ 中，公差 $d$ 是多少？

(A) 5

(B) 3

(C) -3

(D) 8

随堂练习 (2/4)

2. 已知 $x, 10, 20$ 是一个等差数列的三项，那么 $x$ 的值是？

(A) 5

(B) 0

(C) 15

(D) 30

随堂练习 (3/4)

3. 在一个等差数列中，首项 $a_1 = 2$，公差 $d = 4$，求第5项 $a_5$？

(A) 16

(B) 18

(C) 20

(D) 22

随堂练习 (4/4)

4. 在一个等差数列中，首项 $a_1 = 1$，末项 $a_{10} = 19$，求前10项和 $S_{10}$？

(A) 100

(B) 190

(C) 200

(D) 95

练习题解析

1. 答案：B

解析：公差 $d$ = 后一项 - 前一项。$8 - 5 = 3$。

2. 答案：B

解析：根据等差中项性质 $A + C = 2B$。
$x + 20 = 2 \times 10 \implies x + 20 = 20 \implies x = 0$。

3. 答案：B

解析：用通项公式 $a_n = a_1 + (n-1)d$。
$a_5 = 2 + (5-1) \times 4 = 2 + 4 \times 4 = 18$。

4. 答案：A

解析：给了首项和末项，用高斯公式 $S_n = \frac{n(a_1 + a_n)}{2}$。
$S_{10} = \frac{10 \times (1 + 19)}{2} = \frac{10 \times 20}{2} = 100$。

总结

今日总结：四大公式（必须背）

1. $a_n = a_1 + (n-1)d$ (标准)

2. $a_n = a_m + (n-m)d$ (灵活)

3. $S_n = \frac{n(a_1 + a_n)}{2}$ (首末)

4. $S_n = na_1 + \frac{n(n-1)}{2}d$ (万能)

两大心法（必须会）

1. 万能法： 统统换成 $a_1$ 和 $d$ 解方程。

2. 基准法： 活用等差中项性质 ($a_m + a_n = a_p + a_q$, 若 $m+n=p+q$)
