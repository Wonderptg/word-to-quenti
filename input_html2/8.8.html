椭圆入门课

“这到底是个啥形状？”

"椭圆的灵魂，就在那根‘绳子’上！"

椭圆的定义

想象两根钉子 $F_1, F_2$（焦点）和一根固定长度的绳子。

用一支笔 $P$ 把绳子绷紧，画出的轨迹就是椭圆。

定义：平面上，到两个固定点 $F_1, F_2$ 的距离之和，等于一个常数（绳长 $2a$）的点的轨迹。

$|PF_1| + |PF_2| = 2a$

（注：$2a$ 必须大于两焦点间的距离 $|F_1F_2|$）

标准方程：“给椭圆上户口”

我们把焦点 $F_1(-c, 0)$ 和 $F_2(c, 0)$ 放在 $x$ 轴上，原点 $(0,0)$ 作为中点。

根据定义 $|PF_1| + |PF_2| = 2a$，设 $P(x, y)$：

$\sqrt{(x+c)^2 + y^2} + \sqrt{(x-c)^2 + y^2} = 2a$

经过两次“分而治之”的平方和整理...

我们得到：$(a^2 - c^2)x^2 + a^2y^2 = a^2(a^2 - c^2)$

为了简化，我们规定 $b^2 = a^2 - c^2$。

于是得到 $b^2x^2 + a^2y^2 = a^2b^2$。

两边同除以 $a^2b^2$，得到最终形态：

$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \quad (a > b > 0)$

椭圆的“三围”：$a, b, c$

  • $a$ (长半轴): 椭圆与 $x$ 轴的交点 $(\pm a, 0)$。长轴长 = $2a$。
  • $b$ (短半轴): 椭圆与 $y$ 轴的交点 $(0, \pm b)$。短轴长 = $2b$。
  • $c$ (半焦距): 焦点坐标 $F(\pm c, 0)$。焦距 = $2c$。

“$a$ 永远是 $a, b, c$ 中最大的那个！”

“魔法三角形”

连接短轴顶点 $B(0, b)$、原点 $O(0, 0)$ 和焦点 $F_2(c, 0)$。

这是一个直角三角形 $\Delta BOF_2$：

  • 直角边 $|OB| = b$
  • 直角边 $|OF_2| = c$

它的斜边 $|BF_2|$ 是多少？

根据定义， $B$ 点在椭圆上 $\implies |BF_1| + |BF_2| = 2a$。

因为对称， $|BF_1| = |BF_2|$。

所以 $2|BF_2| = 2a \implies |BF_2| = a$。

斜边是 $a$，直角边是 $b$ 和 $c$。

$a^2 = b^2 + c^2$

“躺着” 还是 “站着”？

核心口诀：看分母，谁大谁是 $a^2$！

例 1 (躺着)： $\frac{x^2}{10} + \frac{y^2}{9} = 1$

例 2 (站着)： $\frac{x^2}{36} + \frac{y^2}{100} = 1$

例 3 (陷阱)： $10x^2 + y^2 = 10$

离心率 $e$ —— 椭圆有多“扁”？

定义： $e = \frac{c}{a}$ （半焦距 / 长半轴）

范围： $0 < e < 1$ (因为 $a$ 是老大, $a>c$)

$e \to 0$ (越圆)

$c \to 0$，焦点合体。$a \to b$。
(记忆：数字 0 长得很圆)

$e \to 1$ (越扁)

$c \to a$，焦点跑到端点。$b \to 0$。
(记忆：数字 1 像条线)

求 $e$ 的本质：找关系

求 $e$ 的本质，就是找到 $a, b, c$ 之间的一个等式关系！

例：“椭圆的短轴长是焦距的两倍。”

翻译：
短轴长 = $2b$。焦距 = $2c$。
$2b = 2 \times (2c) \implies b = 2c$。

实战演练

新例题：已知椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 (a > b > 0)$，它的一个焦点是 $F(2,0)$。它上面的一个点 $P(2,3)$。

(1) 求这个椭圆的方程。 (2) 求这个椭圆的离心率。

随堂练习 (1/4)

1. 已知椭圆上一点 $P$ 到两焦点 $F_1, F_2$ 的距离之和为 10，两焦点间距离 $|F_1F_2| = 6$。则该椭圆的短轴长（$2b$）为？

(A) 4

(B) 5

(C) 8

(D) 10

随堂练习 (2/4)

2. 椭圆方程 $\frac{x^2}{10} + \frac{y^2}{12} = 1$ 的焦点在？

(A) x 轴上

(B) y 轴上

(C) 原点

(D) 无法判断

随堂练习 (3/4)

3. 在椭圆的标准方程中，$a, b, c$ 三个量（均大于0）的关系一定满足？

(A) $a^2 = b^2 + c^2$

(B) $b^2 = a^2 + c^2$

(C) $c^2 = a^2 + b^2$

(D) $a = b + c$

随堂练习 (4/4)

4. 椭圆的离心率 $e = \frac{c}{a}$。当 $e$ 越趋近于 1 时，椭圆的形状？

(A) 越圆

(B) 越扁

(C) 保持不变

(D) 变为一个点

练习题解析

1. 答案：C

解析：定义 $\implies 2a = 10 \implies a=5$。
焦距 $\implies 2c = 6 \implies c=3$。
关系式 $a^2 = b^2 + c^2 \implies 5^2 = b^2 + 3^2 \implies 25 = b^2 + 9 \implies b^2 = 16 \implies b=4$。
短轴长 = $2b = 2 \times 4 = 8$。

2. 答案：B

解析：口诀：“看分母，谁大谁是 $a^2$”。
$12 > 10 \implies a^2 = 12, b^2 = 10$。
$a^2$ (12) 在 $y^2$ 的下面，所以焦点在 y 轴上。

3. 答案：A

解析：核心关系式（“魔法三角形”的勾股定理）。$a$ 是斜边， $b, c$ 是直角边。所以 $a^2 = b^2 + c^2$。$a$ 是三者中最大的。

4. 答案：B

解析：$e \to 1 \implies c \to a$。根据 $b^2 = a^2 - c^2$， $b^2 \to 0$。短轴 $2b$ 没了，椭圆被压成一条线，所以越扁。

总结

  • 定义： $|PF_1| + |PF_2| = 2a$。（绳子）
  • 核心： $a^2 = b^2 + c^2$。（$a$ 是老大，记住‘魔法三角形’）
  • 辨认： 谁分母大，谁是 $a^2$，焦点就在谁的轴上。
  • 胖瘦： $e = \frac{c}{a}$。$e \to 0$ 越圆，$e \to 1$ 越扁。
