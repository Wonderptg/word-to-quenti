圆的标准方程

从定义到应用

"抓住圆心和半径，就能“锁”住圆"

核心推导：圆的标准方程

定义：圆是到定点（圆心）的距离等于定长（半径）的点的集合。

  • 设圆心为 $C(a, b)$。
  • 设半径为 $r$。
  • 设圆上任意一点为 $P(x, y)$。

根据定义，点 P 必须满足：$|CP| = r$

使用两点间距离公式：$\sqrt{(x-a)^2 + (y-b)^2} = r$

两边平方，得到标准方程：

$(x-a)^2 + (y-b)^2 = r^2$

方程的理解：“写”方程

“写”方程：从圆心半径到方程

例：圆心 $C(5, -1)$，半径 $r=4$。

代入 $(x - a)^2 + (y - b)^2 = r^2$

$(x - 5)^2 + (y - (-1))^2 = 4^2$

$\implies (x-5)^2 + (y+1)^2 = 16$

方程的理解：“读”方程 (易错点)

“读”方程：从方程到圆心半径

例：$(x+3)^2 + y^2 = 7$

进阶求解(一)：圆心在直线上

例：圆心在直线 $y=x$ 上，且经过 $A(5, 1)$ 和 $B(1, 3)$ 两点，求圆的方程。

进阶求解(二)：与坐标轴相切

例：一个圆的圆心在 $C(6, 5)$，且与 $x$ 轴相切，求圆的方程。

随堂练习 (1/4)

1. 圆的标准方程为 $(x-2)^2 + (y+1)^2 = 9$，它的圆心和半径分别是？

(A) 圆心 $(2, -1)$，半径 $9$

(B) 圆心 $(-2, 1)$，半径 $3$

(C) 圆心 $(2, -1)$，半径 $3$

(D) 圆心 $(-2, 1)$，半径 $9$

随堂练习 (2/4)

2. 已知一个圆的圆心为 $C(0, -5)$，半径为 $2$，则该圆的标准方程是？

(A) $x^2 + (y-5)^2 = 4$

(B) $x^2 + (y+5)^2 = 4$

(C) $(x-5)^2 + y^2 = 2$

(D) $x^2 + (y+5)^2 = 2$

随堂练习 (3/4)

3. (计算题) 一个圆的圆心为 $C(3, -4)$，且该圆与 $x$ 轴相切，那么它的半径 $r$ 是多少？

(A) $3$

(B) $4$

(C) $5$

(D) $-4$

随堂练习 (4/4)

4. (计算题) 已知圆 $(x-3)^2 + y^2 = 1$，圆上一点 $M$ 到原点 $O(0, 0)$ 的最大距离是多少？

(A) $1$

(B) $2$

(C) $3$

(D) $4$

练习题解析

1. 答案：C

解析：对比 $(x-a)^2 + (y-b)^2 = r^2$。$a=2$, $b=-1$ (符号反读)。$r^2=9$, $r=3$ (开方)。圆心 $(2, -1)$，半径 $3$。

2. 答案：B

解析：代入公式 $(x-0)^2 + (y-(-5))^2 = 2^2$，整理得 $x^2 + (y+5)^2 = 4$。

3. 答案：B

解析：圆心 $C(3, -4)$ 到 $x$ 轴的距离等于其纵坐标的绝对值 $|-4| = 4$。与 $x$ 轴相切，则半径 $r=4$。

4. 答案：D

解析：圆心 $C(3, 0)$，半径 $r=1$。圆心到原点 $O(0,0)$ 的距离 $d = \sqrt{(3-0)^2+(0-0)^2} = 3$。圆上点到原点的最大距离 = $d + r = 3 + 1 = 4$。

课程总结

今天我们只学了一个公式：

$(x-a)^2 + (y-b)^2 = r^2$

无论题目多复杂，我们的目标永远是找到两个东西：

圆心 $(a, b)$ 和 半径 $r$！

课后作业：

1. (基础) 求圆心在 $x$ 轴上，半径为 $5$，且经过点 $P(2, -3)$ 的圆的标准方程。

2. (进阶) 求以 $A(1, 5)$ 和 $B(7, -3)$ 为直径两端点的圆的方程。
