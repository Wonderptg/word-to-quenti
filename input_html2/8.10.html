抛物线

从定义到“秒杀”单招题

"偷个懒，咱就用一个点，一条线。"

抛物线的定义

平面内，到一个定点 $F$（焦点）和一条定直线 $L$（准线）的距离相等的点的轨迹，就是抛物线。

$|PF| = |PL|$

（P到焦点的距离 = P到准线的距离）

标准方程：“上户口”

设顶点 $O(0, 0)$，焦点 $F(\frac{p}{2}, 0)$，准线 $L: x = -\frac{p}{2}$。

设抛物线上任意一点 $P(x, y)$。

根据定义 $|PF| = |PL|$：

$\sqrt{(x - \frac{p}{2})^2 + y^2} = |x - (-\frac{p}{2})| = x + \frac{p}{2}$

两边平方并化简：

$x^2 - px + \frac{p^2}{4} + y^2 = x^2 + px + \frac{p^2}{4}$

$y^2 - px = px$

得到最标准的方程：

$y^2 = 2px \quad (p > 0)$

方程的秘密：“四倍关系”

口诀：谁是一次项（不带平方），焦点就在谁的轴上！

秘籍：$x$ (或 $y$) 前面的系数 $\div 4$，直接得到焦点坐标！

方程 开口 焦点 (系数$\div$4) 准线
$y^2 = 2px$ → 右 $F(\frac{2p}{4}, 0) = F(\frac{p}{2}, 0)$ $x = -\frac{p}{2}$
$y^2 = -2px$ ← 左 $F(-\frac{2p}{4}, 0) = F(-\frac{p}{2}, 0)$ $x = \frac{p}{2}$
$x^2 = 2py$ ↑ 上 $F(0, \frac{2p}{4}) = F(0, \frac{p}{2})$ $y = -\frac{p}{2}$
$x^2 = -2py$ ↓ 下 $F(0, -\frac{2p}{4}) = F(0, -\frac{p}{2})$ $y = \frac{p}{2}$

随堂练习 (1/4)

1. 抛物线 $y^2 = 8x$ 的焦点坐标是？

(A) $(2, 0)$

(B) $(8, 0)$

(C) $(4, 0)$

(D) $(0, 2)$

随堂练习 (2/4)

2. 焦点为 $(0, -1)$ 的抛物线的标准方程是？

(A) $x^2 = -y$

(B) $y^2 = -4x$

(C) $x^2 = -4y$

(D) $x^2 = -2y$

随堂练习 (3/4)

3. 点 $P$ 为抛物线 $y^2 = 4x$ 上一点，已知 $P$ 到其准线的距离为 $3$，则 $P$ 到其焦点 $F$ 的距离 $|PF|$ 是？

(A) 1

(B) 3

(C) 4

(D) 无法确定

随堂练习 (4/4)

4. 已知抛物线 $y^2 = 2px$ 经过点 $A(4, 4)$，则其准线方程为？

(A) $x = -1$

(B) $x = -2$

(C) $x = -4$

(D) $x = -8$

练习题解析

1. 答案：A

解析：“四倍关系”口诀：系数 $8 \div 4 = 2$。$y^2$ 项，$x$ 是一次项，焦点在 $x$ 轴。$\implies (2, 0)$。

2. 答案：C

解析：焦点 $(0, -1)$ 在 $y$ 轴负半轴，开口向下。方程 $x^2 = -2py$。
焦点坐标 $-1$。系数 $= -1 \times 4 = -4$。
$\implies x^2 = -4y$。

3. 答案：B

解析：考定义！抛物线上任意一点到焦点的距离 等于 它到准线的距离。
已知 $P$ 到准线距离为 $3$，所以 $|PF|$ 也必须等于 $3$。

4. 答案：A

解析：1. 点 $(4, 4)$ 代入方程 $y^2 = 2px$。
2. $4^2 = 2p(4) \implies 16 = 8p \implies p = 2$。
3. 方程为 $y^2 = 4x$。
4. 准线方程 $x = -\frac{p}{2} = -\frac{2}{2} = -1$。

总结

单招抛物线，你就记住两件事：

  • 第一：定义就是一切！
    $|PF| = |PL|$ (到焦点 = 到准线)。看到 $|AF|$ 就换成 $|AL|$，看到 $|AL|$ 就换成 $|AF|$。
  • 第二：方程就是地图。
    口诀1：“一次项定轴”（$x$ 不带平方，焦点在 $x$ 轴）。
    口诀2：“系数除以四”（$x$ 前的系数 $\div 4$，得焦点坐标）。

把这两招练熟，抛物线就是送分题。下课！
