概率基础与古典概型

概率的基本概念

概率是用来衡量一个事件发生可能性大小的数。

  • 范围：$0 \le P(A) \le 1$
  • 必然事件：$P(\Omega) = 1$（一定发生）
  • 不可能事件：$P(\emptyset) = 0$（绝不发生）

什么是古典概型？

必须同时满足两个核心条件：

1. 有限性

样本空间 $\Omega$ 里的样本点（结果）只有有限多个。

2. 等可能性

每一个样本点发生的可能性是完全相等的。

古典概型的判定

✅ 是古典概型

  • 扔硬币：$\{\text{正}, \text{反}\}$，有限且均等。
  • 扔骰子：$\{1, 2, 3, 4, 5, 6\}$，有限且均等。

🚫 不是古典概型

  • 明天是否下雨：$\{\text{下雨}, \text{不下雨}\}$。
    原因：可能性不相等（不等可能）。
  • 区间取数：在 $[0, 1]$ 选一个数。
    原因：有无穷多个数（无限性）。

古典概型的计算公式

$$P(A) = \frac{n(A)}{n(\Omega)} = \frac{\text{事件A包含的样本点个数}}{\text{样本空间的总样本点个数}}$$

例： 扔骰子，事件 A 是“正面朝上的数字是奇数”。

$\Omega = \{1,2,3,4,5,6\}$ (6个)，$A = \{1,3,5\}$ (3个)

$$P(A) = \frac{3}{6} = \frac{1}{2}$$

⚠️ 经典易错点

问题：扔两枚硬币，一正一反的概率是多少？

❌ 错误的思路：

列举样本空间：$\Omega = \{ \text{正正}, \text{反反}, \text{一正一反} \}$

认为是 3 种情况，所以概率是 $1/3$。

思考： 为什么这样做是错的？

✅ 正确的解法

错误原因：上述模型不满足等可能性。“一正一反”包含两种情况。

正确样本空间（区分硬币）：

$$\Omega = \{ \text{正正}, \text{正反}, \text{反正}, \text{反反} \}$$

总共有 4 个等可能的样本点。

事件 A（一正一反）= $\{\text{正反}, \text{反正}\}$，共 2 个。

$$P(A) = \frac{2}{4} = \frac{1}{2}$$

互斥事件 (Mutually Exclusive)

如果 $A \cap B = \emptyset$（不能同时发生），则：

$$P(A \cup B) = P(A) + P(B)$$

一般加法公式 (容斥原理)

如果事件有重叠，必须减去重叠部分：

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

事件的独立性与频率估计

事件的独立性

如果 A 和 B 的发生互不影响：

$$P(AB) = P(A) \times P(B)$$

判定独立的唯一数学标准。

用频率估计概率

当试验次数 $N$ 足够大时（大数定律），事件发生的频率会越来越接近真实的概率。

🎯 课堂总结

  1. 古典概型：有限、等可能。$P = n(A)/n(\Omega)$。
  2. 计数关键：枚举时要不重不漏，注意顺序（如硬币问题）。
  3. 运算性质：互斥加法、对立事件、容斥原理。
  4. 独立性：$P(AB) = P(A)P(B)$。

📝 课后小测：第 1 题

1. 下列哪个试验满足古典概型的条件？

  • A. 在区间 $[0, 5]$ 上随机选取一个实数
  • B. 向上抛掷一枚质地不均匀的硬币，观察正反面
  • C. 向上抛掷一枚质地均匀的骰子，观察向上的点数
  • D. 射击运动员射击一次，观察是否中靶（假设中靶率80%）

✅ 答案解析

答案：C

A 错： 样本点有无穷多个（不满足有限性）。

B 错： 硬币不均匀，正反面概率不等（不满足等可能性）。

C 对： 6个面，有限且等可能。

D 错： 中靶与脱靶概率不等（80% vs 20%）。

📝 课后小测：第 2 题

2. 同时抛掷两枚质地均匀的硬币，恰好出现“两枚正面朝上”的概率是？

  • A. $1/2$
  • B. $1/3$
  • C. $1/4$
  • D. $3/4$

✅ 答案解析

答案：C

样本空间 $\Omega = \{ \text{正正}, \text{正反}, \text{反正}, \text{反反} \}$，共 4 种情况。

事件 A = $\{ \text{正正} \}$，共 1 种情况。

$$P(A) = \frac{1}{4}$$

📝 课后小测：第 3 题

3. 已知事件 A 与 B 互斥，且 $P(A)=0.2, P(B)=0.5$，则 $P(A \cup B)$ 等于？

  • A. $0.1$
  • B. $0.3$
  • C. $0.7$
  • D. $1.0$

✅ 答案解析

答案：C

因为 A 与 B 互斥，使用互斥事件加法公式：

$$P(A \cup B) = P(A) + P(B)$$

$$P(A \cup B) = 0.2 + 0.5 = 0.7$$

📝 课后小测：第 4 题

4. 如果事件 A 和 B 相互独立，且 $P(A)=0.5, P(B)=0.4$，那么 A 和 B 同时发生的概率 $P(AB)$ 是？

  • A. $0.9$
  • B. $0.2$
  • C. $0.1$
  • D. $0.5$

✅ 答案解析

答案：B

因为 A 和 B 相互独立，使用独立性公式：

$$P(AB) = P(A) \times P(B)$$

$$P(AB) = 0.5 \times 0.4 = 0.2$$

📝 课后小测：第 5 题

5. 关于频率与概率的关系，下列说法正确的是？

  • A. 频率就是概率，两者永远相等
  • B. 试验次数很少时，频率也能精准代表概率
  • C. 随着试验次数增加，频率会越来越接近概率
  • D. 概率是随机的，每次试验都在变

✅ 答案解析

答案：C

A 错： 频率是实验值，概率是理论值。

B 错： 次数少时波动大，不准。

C 对： 大数定律保证了这一点。

D 错： 概率是固定的常数（如硬币正面的概率始终是0.5），频率才是随机波动的。
