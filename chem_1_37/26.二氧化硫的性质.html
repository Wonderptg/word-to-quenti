二氧化硫 (SO₂)

—— 性质多变的“考点之王”

二氧化硫的物理性质

颜色/状态/气味：无色、有刺激性气味的有毒气体。

密度：相对分子质量为64，密度比空气大（比空气“重”）。

溶解性：易溶于水 (1体积水约溶40体积SO₂)。

化学性质：酸性氧化物

SO₂是典型的酸性氧化物，具有酸性氧化物的通性。可与水、碱性氧化物、碱反应。

与水反应：生成亚硫酸 (H₂SO₃)

SO₂ + H₂O ⇌ H₂SO₃

SO₂ + H₂O ⇌ H₂SO₃

亚硫酸(H₂SO₃)是中强酸，不稳定易分解，反应可逆。

与碱反应 (以NaOH为例)

SO₂是二元酸性氧化物，生成盐类与SO₂的量有关：

SO₂ (少量) + 2OH⁻ → SO₃²⁻ + H₂O

SO₂ (过量) + OH⁻ → HSO₃⁻

化学性质：还原性 (Part 1)

SO₂中的硫为+4价，可被氧化至+6价，表现出较强的还原性。

与氧气反应 (工业制硫酸核心步骤)

SO₂ +4价
被氧化 (+2价)
SO₃ +6价

2SO₂ + O₂ (催化剂, 加热) ⇌ 2SO₃

工业制硫酸流程简述

1. S 或 FeS₂ 燃烧 → SO₂

2. SO₂ 催化氧化 → SO₃

3. SO₃ 被浓硫酸吸收 → 浓硫酸

化学性质：还原性 (Part 2)

SO₂能被多种强氧化剂氧化，常使有色氧化剂褪色，体现还原性。

与卤素单质水溶液 (Cl₂, Br₂, I₂)

SO₂ + X₂ → H₂SO₄ 褪色

SO₂ + X₂ + 2H₂O → H₂SO₄ + 2HX (X=Cl, Br, I)

现象：卤素水溶液褪色。

与酸性KMnO₄溶液 (用于定性检验SO₂)

SO₂ + KMnO₄ → 无色 Mn²⁺ 紫红色褪去

5SO₂ + 2MnO₄⁻ + 2H₂O → 5SO₄²⁻ + 2Mn²⁺ + 4H⁺

还原性的特例与应用

重要特例：SO₂ 不与浓硫酸反应！

SO₂ + 浓H₂SO₄ ❌ = 无反应

虽然浓硫酸有强氧化性，SO₂有还原性，但由于没有稳定的中间价态硫氧化物，两者不发生氧化还原反应。

应用：可以用浓硫酸干燥SO₂气体。

化学性质：氧化性 (较弱)

SO₂中的+4价硫也可被还原至0价或-2价，表现出氧化性，但通常只在遇到强还原剂时体现。

与硫化氢 (H₂S) 反应

典型的归中反应。

SO₂ +4价
+
H₂S -2价

+ H₂O

SO₂ + 2H₂S → 3S↓ + 2H₂O

现象：产生淡黄色沉淀(硫单质)。

化学性质：漂白性

SO₂能使某些有色物质（如品红溶液）褪色。

🔴 品红 (有色)
+
💨 SO₂
⇌
⚪ 无色物质

漂白原理：SO₂与有色物质结合生成不稳定的无色物质。

特点：这种漂白是暂时性的，生成的无色物质不稳定，加热后可恢复原来的颜色。

局限性：不能使石蕊、酚酞等酸碱指示剂褪色（只能使其变色）。

应用：可用于漂白纸浆、毛、丝等。

SO₂漂白性 vs 氯水漂白性

SO₂ (二氧化硫)

原理：化合漂白 (生成不稳定无色物)

效果：暂时性，加热可复原

范围：可漂白品红等

不能漂白指示剂

氯水 (含HClO)

原理：氧化漂白 (HClO强氧化性)

效果：永久性，不可逆

范围：可漂白品红、石蕊等

能使石蕊先变红后褪色

注意：若将SO₂和氯水混合，漂白性会消失！
(SO₂ + Cl₂ + 2H₂O → H₂SO₄ + 2HCl)

易混淆的“褪色”现象

SO₂使品红褪色

体现SO₂的漂白性。

SO₂使溴水、酸性KMnO₄溶液褪色

体现SO₂的还原性 (发生氧化还原反应)。

SO₂使含酚酞的NaOH溶液褪色

体现SO₂的酸性氧化物性质 (中和了NaOH)。

随堂练习 (一)

下列关于SO₂的说法，错误的是？

(A) 无色、有刺激性气味的气体

(B) 易溶于水，其水溶液是亚硫酸

(C) 具有漂白性，能使石蕊试液褪色

(D) 既有氧化性，又有还原性

练习 (一)：解析

答案：(C)

解析：

SO₂具有漂白性，但其漂白范围有限，不能使石蕊等酸碱指示剂褪色。它溶于水生成亚硫酸，会使石蕊试液变红。

随堂练习 (二)

将SO₂气体通入下列溶液中，溶液会褪色，且体现SO₂还原性的是？

(A) 品红溶液

(B) 含有酚酞的NaOH溶液

(C) 紫色石蕊试液

(D) 酸性KMnO₄溶液

练习 (二)：解析

答案：(D)

解析：

A. 使品红褪色体现漂白性。
B. 使含酚酞的NaOH溶液褪色体现酸性氧化物性质。
C. 使石蕊变红体现酸性，不褪色。
D. SO₂与酸性KMnO₄发生氧化还原反应，使紫红色褪去，体现SO₂的还原性。

随堂练习 (三)

下列关于SO₂和氯水漂白性的比较，正确的是？

(A) 两者原理相同，都是氧化漂白

(B) SO₂的漂白是永久性的

(C) 氯水的漂白是暂时性的

(D) 将两者混合，漂白性会减弱甚至消失

练习 (三)：解析

答案：(D)

解析：

A. 原理不同，SO₂是化合漂白，氯水是氧化漂白。
B. SO₂漂白是暂时性的，加热可复原。
C. 氯水（HClO）漂白是永久性的。
D. SO₂和Cl₂会发生氧化还原反应 (SO₂ + Cl₂ + 2H₂O → H₂SO₄ + 2HCl)，使两者都失去漂白性，正确。

随堂练习 (四)

工业制硫酸的过程中，SO₂转化为SO₃需要的条件不包括？

(A) 高温

(B) 催化剂 (V₂O₅)

(C) 常压

(D) 氧气

练习 (四)：解析

答案：(C)

解析：

反应 2SO₂ + O₂ ⇌ 2SO₃ 需要的条件是高温 (约400-500°C)、催化剂 (通常是V₂O₅) 和氧气。工业生产中为了提高反应速率和平衡转化率，通常还会采用加压的条件，而不是常压。

随堂练习 (五)

能证明SO₂具有氧化性的反应是？

(A) SO₂ + Br₂ + 2H₂O → H₂SO₄ + 2HBr

(B) SO₂ + 2H₂S → 3S↓ + 2H₂O

(C) SO₂ + 2NaOH → Na₂SO₃ + H₂O

(D) SO₂ + H₂O ⇌ H₂SO₃

练习 (五)：解析

答案：(B)

解析：

要体现SO₂的氧化性，SO₂中的硫元素化合价必须降低。
A. S元素化合价从+4升高到+6，体现还原性。
B. S元素化合价从+4降低到0，体现氧化性 (同时H₂S中的S从-2升高到0，体现还原性)。
C, D. 非氧化还原反应。
