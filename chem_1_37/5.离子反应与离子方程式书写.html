离子反应的奥秘

—— 从“单身派对”到化学反应

一个“派对广场”的故事

想象一下，溶液就像一个巨大的派对广场，里面充满了自由自在的“单身”离子。

NaCl 溶液

Na⁺ 和 Cl⁻

AgNO₃ 溶液

Ag⁺ 和 NO₃⁻

当这两群“单身离子”相遇……

一、什么是离子反应？

定义：

有离子参加或者有离子生成的反应。

离子之间“看对眼”并“牵手成功”的过程，就是离子反应！

谁是真正的主角？

故事一：强酸遇见强碱 (HNO₃ + KOH)

当它们混合后，H⁺ 和 OH⁻ 天雷勾地火，立刻结合生成了稳定的水分子(H₂O)。而剩下的 K⁺ 和 NO₃⁻ 不来电，继续在旁边当“吃瓜群众”。

真正的主角：H⁺ 和 OH⁻

故事二：活泼金属的“逆袭” (Zn + AgNO₃)

活泼的锌(Zn)把银离子(Ag⁺)从溶液中赶了出来，自己变成了锌离子(Zn²⁺)。

主角：Zn, Ag⁺, Zn²⁺

二、如何书写离子方程式？

—— 四步写出反应“剧本”

写 → 拆 → 删 → 查

它就像是只写主角戏份的剧本，把那些“吃瓜群众”全都删掉！

演练：Na₂SO₄ + BaCl₂

第一步：「写」

写出完整的、配平的化学方程式，并正确标注状态（沉淀↓、气体↑）。

Na₂SO₄ + BaCl₂ → BaSO₄↓ + 2NaCl

第二步：「拆」

把易溶于水且易电离的物质拆成离子形式。

“拆迁大户” (要拆):

  • 强酸
  • 强碱
  • 可溶性盐

“钉子户” (不拆):

  • 沉淀、气体、水
  • 弱酸、弱碱
  • 氧化物等

(2Na⁺ + SO₄²⁻) + (Ba²⁺ + 2Cl⁻) → BaSO₄↓ + (2Na⁺ + 2Cl⁻)

第三、四步：「删」与「查」

第三步：「删」

删除反应前后都存在的“吃瓜群众”离子。

(2Na⁺ + SO₄²⁻) + (Ba²⁺ + 2Cl⁻) → BaSO₄↓ + (2Na⁺ + 2Cl⁻)

第四步：「查」

检查剩余部分的原子个数和电荷是否守恒。

Ba²⁺ + SO₄²⁻ → BaSO₄↓

(电荷检查: (+2) + (-2) = 0，守恒！)

三、离子反应发生的条件

只要离子们能通过以下方式之一“牵手成功”，反应就能发生：

1. 生成沉淀

Ca²⁺+CO₃²⁻→CaCO₃↓

2. 生成气体

2H⁺+CO₃²⁻→H₂O+CO₂↑

3. 生成弱电解质

H⁺ + OH⁻ → H₂O

四、小试牛刀

1. 镁条放入稀盐酸中：

Mg + 2H⁺ → Mg²⁺ + H₂↑

2. 氢氧化钠溶液和氯化铜溶液混合：

Cu²⁺ + 2OH⁻ → Cu(OH)₂↓

今日总结

• 我们知道了什么是离子反应。

• 我们学会了如何用离子方程式编写反应的“核心剧本”。

• 核心方法是“写、拆、删、查”四步法。

• 关键中的关键，是搞清楚谁是“拆迁大户”，谁是“钉子户”。

课程结束

思考题：如果把盐酸慢慢滴加到碳酸钠溶液里，和一次性大量倒入，发生的“故事”会一样吗？下课！

随堂练习（一）

下列物质中，哪一种在书写离子方程式时不能拆成离子形式？

(A) HNO₃ (硝酸)

(B) BaSO₄ (硫酸钡)

(C) KOH (氢氧化钾)

(D) FeCl₃ (氯化铁)

练习题（一）：解析

答案：(B)

解析：

书写离子方程式时，沉淀、气体、水、弱电解质等“钉子户”不能拆。硫酸钡(BaSO₄)是著名的沉淀，所以不能拆。而硝酸是强酸，氢氧化钾是强碱，氯化铁是可溶性盐，它们都是“拆迁大户”。

随堂练习（二）

下列离子方程式书写正确的是？

(A) 铁与稀硫酸反应: Fe + H₂SO₄ → Fe²⁺ + H₂↑ + SO₄²⁻

(B) 碳酸钙与盐酸反应: CO₃²⁻ + 2H⁺ → H₂O + CO₂↑

(C) 氢氧化铜溶于硝酸: Cu(OH)₂ + 2H⁺ → Cu²⁺ + 2H₂O

(D) 氯化铵溶液与氢氧化钠溶液共热: NH₄⁺ + OH⁻ → NH₃ + H₂O

练习题（二）：解析

答案：(C)

解析：

  • (A) H₂SO₄是强酸要拆，但SO₄²⁻是“吃瓜群众”，应该被删掉。正确的：Fe + 2H⁺ → Fe²⁺ + H₂↑
  • (B) 碳酸钙(CaCO₃)是沉淀，是“钉子户”，不能拆。
  • (C) 氢氧化铜是沉淀，不拆；硝酸是强酸，拆；产物铜离子和水，书写正确。
  • (D) 反应条件是加热，需要标注“△”，且氨气是气体，需要标“↑”。

随堂练习（三）

在水溶液中，下列哪组离子因发生反应而不能大量共存？

(A) K⁺, Ba²⁺, OH⁻, NO₃⁻

(B) Na⁺, H⁺, Cl⁻, CO₃²⁻

(C) NH₄⁺, Na⁺, Cl⁻, SO₄²⁻

(D) Mg²⁺, K⁺, Cl⁻, NO₃⁻

练习题（三）：解析

答案：(B)

解析：

判断离子能否大量共存，就是看它们之间是否会发生反应生成沉淀、气体或弱电解质。

  • (A) 两两组合均不反应，可以共存。
  • (B) H⁺ 和 CO₃²⁻ 会反应生成水和二氧化碳气体 (2H⁺ + CO₃²⁻ → H₂O + CO₂↑)，不能大量共存。
  • (C) 两两组合均不反应，可以共存。
  • (D) 两两组合均不反应，可以共存。

随堂练习（四）

向滴有酚酞的氢氧化钠溶液中，逐滴加入稀盐酸。描述该过程中溶液颜色变化的离子方程式是？

(A) HCl + NaOH → NaCl + H₂O

(B) H⁺ + OH⁻ → H₂O

(C) H⁺ + NaOH → Na⁺ + H₂O

(D) OH⁻ → H₂O

练习题（四）：解析

答案：(B)

解析：

题目描述的是一个酸碱中和反应，溶液由红色（酚酞遇碱）变为无色。离子反应的本质是氢离子(H⁺)与氢氧根离子(OH⁻)结合生成水(H₂O)。

这个反应揭示了所有强酸与强碱中和反应的本质，因此离子方程式为 H⁺ + OH⁻ → H₂O。选项(A)是化学方程式，不是离子方程式。

随堂练习（五）

在反应 Zn + CuSO₄ → ZnSO₄ + Cu 中，没有参与反应的“吃瓜群众”离子是？

(A) Zn²⁺

(B) Cu²⁺

(C) SO₄²⁻

(D) Cu

练习题（五）：解析

答案：(C)

解析：

我们来写一下这个反应的离子方程式：

Zn + Cu²⁺ + SO₄²⁻ → Zn²⁺ + SO₄²⁻ + Cu

通过“删”的步骤，我们可以看到硫酸根离子(SO₄²⁻)在反应前后没有发生任何变化，它就是那个纯属“打酱油”的“吃瓜群众”，也叫旁观者离子。
