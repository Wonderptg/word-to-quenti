阿伏伽德罗定律

—— 一位被低估的先知与一个伟大的定律

一个被忽视了50年的天才

19世纪初，化学界大佬道尔顿（原子论）和盖吕萨克（气体实验）互不相让，化学陷入混乱。

一位名不见经传的意大利科学家阿伏伽德罗提出了“分子假说”，完美解决了矛盾，但无人理睬。

直到他去世后，他的理论才被世人认可，并成为化学的基石之一。为了纪念他，后人以他的名字命名了阿伏伽德罗常数和阿伏伽德罗定律。

阿伏伽德罗定律的核心内容

在同温同压下，相同体积的任何气体，都含有相同数目的分子。

简单来说：三同（同T, 同P, 同V） → 一同（分子数n相同）

注意：定律说的是分子数相同，而不是原子数相同！

条件：同温 (T), 同压 (P), 同体积 (V)

重要推论与衍生

由核心定律可以推导出在同温同压(T, P)下的一系列正比关系：

V₁ / V₂ = n₁ / n₂ = N₁ / N₂

气体体积之比 = 物质的量之比 = 分子数之比

例：同温同压下，1L He, 2L H₂, 3L CO₂，它们的分子数之比就是 1 : 2 : 3。

1 L 气体 (n 分子)

2 L 气体 (2n 分子)

定律的初步应用：确定化学式

问题：同温同压下，2体积的 AB₂ 气体与 1体积的 B₂ 气体反应，生成 2体积的气态化合物 X，求 X 的化学式。

1. 体积比 → 计量数之比：根据定律，反应中各物质的计量数之比为 2 : 1 : 2。

2. 写出反应方程式：2AB₂ + 1B₂ → 2X

3. 原子守恒：
反应前：A原子有 2×1=2个，B原子有 2×2 + 1×2 = 6个。

4. 求解 X：2个X分子共含有2个A和6个B，所以1个X分子含有1个A和3个B。因此 X 的化学式为 AB₃。

综合应用：多角度比较

问题：同温同压下，1 L 甲烷(CH₄) 和 2 L 二氧化碳(CO₂) 进行比较。

分子数之比：体积比为 1:2，故分子数之比为 1 : 2。

原子数之比：每个CH₄有5个原子，每个CO₂有3个原子。
总原子数比 = (1×5) : (2×3) = 5 : 6。

质量之比 (m=n×M)：物质的量之比为 1:2，M之比为 16:44。
质量比 = (1×16) : (2×44) = 16:88 = 2 : 11。

密度之比 (ρ=m/V)：质量比为 16:88，体积比为 1:2。
密度比 = (16/1) : (88/2) = 16:44 = 4 : 11。

推论二：摩尔质量与密度

在同温同压(T, P)下，气体的摩尔质量与密度成正比。

M₁ / M₂ = ρ₁ / ρ₂

解释：空气的平均M约为29 g/mol，H₂的M为2 g/mol。因为 2 < 29，所以在同温同压下，氢气的密度小于空气。

同T, P, V下, M越大, 质量(m)越大, 密度(ρ)越大。

“解题神器”：理想气体状态方程

虽然高中不作要求，但理解这两个公式可以帮你解决几乎所有气体问题：

基础式

PV = nRT

变形式 (含密度)

PM = ρRT

其中P(压强), V(体积), n(物质的量), T(温度), M(摩尔质量), ρ(密度)是变量，R是常数。通过控制变量，可以轻松推导出所有关系。

“解题神器”实战：吹气球问题

问题：同温同压下，用等质量的 CH₄, O₂, CO₂, SO₂ 四种气体分别吹出四个气球，体积最大的气球里装的是什么？

1. 列出公式：PV = nRT

2. 确定常量：同温(T)、同压(P)、R是常数 → V ∝ n (体积与物质的量成正比)

3. 换算 n：n = m/M，代入上式 → V ∝ m/M

4. 再次确定常量：等质量(m) → V ∝ 1/M (体积与摩尔质量成反比)

5. 得出结论：摩尔质量(M)最小的气体，其体积(V)最大。

6. 比较 M：CH₄(16), O₂(32), CO₂(44), SO₂(64)。CH₄的摩尔质量最小。

7. 答案：体积最大的气球里装的是甲烷 (CH₄)。

随堂练习 (一)

同温同压下，相同体积的 H₂ 和 O₂ 含有相同的 ( )

(A) 原子数

(B) 分子数

(C) 质量

(D) 密度

练习 (一)：解析

答案：(B)

解析：

根据阿伏伽德罗定律，在同温同压下，相同体积的任何气体都含有相同数目的分子。原子数（1:1 vs 1:2）、质量（摩尔质量不同）和密度（摩尔质量不同）均不相同。

随堂练习 (二)

同温同压下，2L 的 CO₂ 和 1L 的 N₂，它们的分子数之比为 ( )

(A) 1 : 1

(B) 1 : 2

(C) 2 : 1

(D) 无法确定

练习 (二)：解析

答案：(C)

解析：

根据阿伏伽德罗定律的推论，在同温同压下，气体的体积之比等于其分子数之比。因此，分子数之比为 2 : 1。

随堂练习 (三)

同温同压下，已知气体X的密度是气体Y的2倍，则X的摩尔质量是Y的几倍？ ( )

(A) 1/2 倍

(B) 1 倍

(C) 2 倍

(D) 4 倍

练习 (三)：解析

答案：(C)

解析：

根据推论，在同温同压下，气体的摩尔质量之比等于其密度之比 (M₁/M₂ = ρ₁/ρ₂)。因此，X的摩尔质量是Y的2倍。

随堂练习 (四)

关于阿伏伽德罗定律，下列说法正确的是 ( )

(A) 同温同压下，相同体积的任何物质都含有相同数目的分子

(B) 同温同压下，相同体积的任何气体都含有相同数目的原子

(C) 不同温度和压强下，相同体积的气体也含有相同数目的分子

(D) 同温同压下，1 mol H₂ 和 1 mol O₂ 的体积相同

练习 (四)：解析

答案：(D)

解析：

定律的适用对象是气体。(A)错在“任何物质”，(B)错在“原子”，(C)错在“不同温度和压强”。(D)中，同温同压下，物质的量相同的任何气体，体积必然相同。

随堂练习 (五)

同温同压下，等体积的 CH₄ 和 SO₂，它们的质量之比为？ (M(CH₄)=16, M(SO₂)=64)

(A) 1 : 1

(B) 1 : 2

(C) 1 : 4

(D) 4 : 1

练习 (五)：解析

答案：(C)

解析：

同温同压等体积意味着它们的物质的量(n)相同。根据 m = n × M，质量之比就等于摩尔质量之比。所以质量比为 16 : 64，即 1 : 4。
