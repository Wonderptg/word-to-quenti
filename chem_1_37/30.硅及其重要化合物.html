硅及其重要化合物

—— 现代科技的基石

单晶硅 (Si) 的结构与性质

结构

结构与金刚石类似，每个Si原子与4个Si原子形成正四面体立体网状结构。

1 mol Si 含有 2NA 个 Si-Si 键。

物理性质

  • 带有金属光泽的灰黑色固体
  • 熔点高、硬度大、脆性
  • 导电性介于导体和绝缘体之间，是半导体

常温下化学性质不活泼。

硅单质的化学性质 (了解)

常温下稳定，高温或特定条件下可反应。

Si + 2F₂ → SiF₄

Si + 2Cl₂ (Δ) → SiCl₄

Si + 4HF → SiF₄↑ + 2H₂↑

Si + 2NaOH + H₂O → Na₂SiO₃ + 2H₂↑ (重要！类比Al)

Si + O₂ (Δ) → SiO₂

二氧化硅 (SiO₂) 的结构与性质

结构

与单晶硅类似，也是正四面体立体网状结构，但原子间是Si-O键。

1 mol SiO₂ 含有 4NA 个 Si-O 键。

物理性质

  • 存在形态：石英、水晶、玛瑙、沙子等
  • 硬度大、熔沸点高
  • 常温下为固体
  • 难溶于水
  • 不导电 (绝缘体)

二氧化硅的化学性质 (酸性氧化物)

SiO₂是酸性氧化物，具有酸性氧化物的通性，但与水不反应。

与氢氟酸(HF)反应 (特殊性！)

SiO₂ + 4HF → SiF₄↑ + 2H₂O

这是SiO₂唯一能反应的酸。用于刻蚀玻璃。

与强碱反应

SiO₂ + 2NaOH → Na₂SiO₃ + H₂O

不能用带磨口玻璃塞的试剂瓶盛放碱液。

与碱性氧化物/某些盐反应 (高温)

SiO₂ + CaO (高温) → CaSiO₃

SiO₂ + Na₂CO₃ (高温) → Na₂SiO₃ + CO₂↑ (制玻璃)

硅酸 (H₂SiO₃)

性质1：弱酸，酸性比碳酸(H₂CO₃)还弱。

性质2：难溶于水 (高中唯一难溶于水的常见酸)。

性质3：不稳定，受热易分解。

H₂SiO₃ (Δ) → SiO₂ + H₂O

性质4：浓度大时易形成凝胶。

硅胶：硅酸凝胶干燥脱水后形成的多孔固体，吸附性强，常用作干燥剂、催化剂载体。

硅酸的制备与酸性比较

利用强酸制弱酸的原理。

制备方法

Na₂SiO₃ + 2HCl → H₂SiO₃↓ + 2NaCl

Na₂SiO₃ + CO₂ + H₂O → H₂SiO₃↓ + Na₂CO₃

现象：产生白色胶状沉淀或凝胶。

实验验证酸性：HCl > H₂CO₃ > H₂SiO₃

关键：需用饱和NaHCO₃溶液除去CO₂中的HCl气体。

硅酸钠 (Na₂SiO₃)

性质：白色固体，可溶于水，水溶液俗称水玻璃或泡花碱。

水溶液显碱性 (硅酸根水解)。

是一种矿物胶，具有粘合性。

用途：

  • 制备硅胶和硅酸
  • 木材、纺织品的防腐剂、防火剂
  • 粘合剂

随堂练习 (一)

下列关于单晶硅的说法，错误的是？

(A) 结构与金刚石类似

(B) 熔点高、硬度大

(C) 是良好的导体

(D) 可用作半导体材料

练习 (一)：解析

答案：(C)

解析：

单晶硅的导电性介于导体和绝缘体之间，是典型的半导体材料，而不是良导体。

随堂练习 (二)

下列物质中，能与SiO₂反应的是？

(A) 盐酸 (HCl)

(B) 氢氟酸 (HF)

(C) 硫酸 (H₂SO₄)

(D) 水 (H₂O)

练习 (二)：解析

答案：(B)

解析：

二氧化硅(SiO₂)不与水反应，也不与除氢氟酸以外的常见酸反应。它能与氢氟酸(HF)发生特殊反应：SiO₂ + 4HF → SiF₄↑ + 2H₂O。

随堂练习 (三)

下列关于硅酸的说法，正确的是？

(A) 易溶于水

(B) 酸性比盐酸强

(C) 受热易分解

(D) 可以用SiO₂与水反应制备

练习 (三)：解析

答案：(C)

解析：

硅酸(H₂SiO₃)是难溶于水的弱酸，酸性比碳酸还弱，远弱于盐酸。它不稳定，受热易分解生成SiO₂和H₂O。SiO₂不与水反应，不能用于制备硅酸。

随堂练习 (四)

实验室盛放NaOH溶液的试剂瓶，不能选用带磨口玻璃塞的原因是？

(A) NaOH会腐蚀玻璃瓶身

(B) NaOH会与玻璃塞中的SiO₂反应生成硅酸钠，使瓶塞粘结

(C) NaOH会吸收空气中的CO₂生成Na₂CO₃，使瓶塞粘结

(D) 玻璃塞不够密封

练习 (四)：解析

答案：(B)

解析：

氢氧化钠(NaOH)溶液能与玻璃中的二氧化硅(SiO₂)缓慢反应生成硅酸钠(Na₂SiO₃)。磨口增大了接触面积，加速了反应。生成的硅酸钠具有粘合性（矿物胶），会将玻璃塞与瓶口粘结在一起，导致难以打开。

随堂练习 (五)

下列哪个俗名指的是硅酸钠的水溶液？

(A) 水玻璃

(B) 石英

(C) 硅胶

(D) 金刚砂

练习 (五)：解析

答案：(A)

解析：

硅酸钠(Na₂SiO₃)的水溶液俗称水玻璃或泡花碱。石英是SiO₂的一种晶型。硅胶是硅酸干凝胶。金刚砂是碳化硅(SiC)。
