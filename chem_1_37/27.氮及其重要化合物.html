氮及其重要化合物

—— 氮气与氮的氧化物

氮气 (N₂) 的结构与性质

结构：N≡N

两个氮原子间以共价三键 (N≡N) 结合。

键能极大，不易断裂。

物理性质与稳定性

  • 无色无味、难溶于水的气体。
  • 密度与空气接近，略小。

由于 N≡N 键稳定，通常条件下化学性质不活泼。

氮气的化学反应 (特定条件下)

在高温、放电等条件下，氮气可以参与反应。

与氧气反应 (固氮)

N₂ + O₂ (放电/高温) ⇌ 2NO

自然界中闪电可引发此反应。

与活泼金属反应 (氧化性)

N₂ + 3Mg (点燃) → Mg₃N₂ (氮化镁)

N₂在此反应中体现氧化性，氮元素价态由 0 降为 -3。

与氢气反应 (工业合成氨)

N₂ + 3H₂ ⇌ 2NH₃

条件：高温、高压、催化剂。反应可逆。

工业合成氨 (哈伯法)

哈伯法实现了氨的工业化大规模生产，是20世纪最重要的化学发明之一。

核心反应与流程

N₂ + 3H₂ (高温,高压,催化剂) ⇌ 2NH₃

重大意义

解决了氮肥大规模生产问题，极大提高了粮食产量，使人类免受饥荒之苦。

常见氮肥：铵态氮肥(NH₄⁺)、硝态氮肥(NO₃⁻)、尿素[CO(NH₂)₂]。

氮的固定：游离态 → 化合态

将大气中游离态的氮转化为含氮化合物的过程。

自然固氮

  • 高能固氮：闪电使N₂和O₂反应生成NO。
  • 生物固氮：根瘤菌等微生物将N₂转化为NH₃。

人工固氮

主要指工业合成氨。

氮元素的循环 (一)

氮元素在自然界中不断转化，维持生态平衡。

1. 氮的固定 (N₂ → 含氮化合物)

通过人工固氮（合成氨）或自然固氮（闪电、生物固氮）实现：

N₂ + 3H₂ ⇌ 2NH₃ (人工固氮)

N₂ + O₂ ⇌ 2NO (高能固氮)

2. 硝化作用 (NH₃ → 硝酸盐)

微生物将氨或铵盐氧化成硝酸盐：

NH₃ → NO₂⁻ → NO₃⁻

氮元素的循环 (二)

（接上页）氮元素在生物和环境中的其他主要转化路径：

3. 生物同化作用 (无机氮 → 有机氮)

植物吸收铵盐或硝酸盐，合成蛋白质等有机氮化合物。

NH₄⁺/NO₃⁻ (植物吸收) → 有机氮 (蛋白质)

4. 分解作用 (有机氮 → NH₃)

动植物残体和排泄物被微生物分解，将有机氮转化为氨或铵盐。

5. 反硝化作用 (硝酸盐 → N₂)

微生物在缺氧条件下将硝酸盐还原成氮气，回到大气：

NO₃⁻ → N₂

氮的氧化物：NO 和 NO₂

NO（+2价）和NO₂（+4价）都是含氮化合物，化学性质差异巨大。

一氧化氮 (NO)

  • 无色、有毒气体
  • 不溶于水
  • 空气中不稳定，易被O₂氧化 (生成NO₂)

二氧化氮 (NO₂)

  • 红棕色、有毒气体
  • 易溶于水，并与水反应
  • 易双聚生成 N₂O₄ (无色)

NO 和 NO₂ 的相互转化

NO → NO₂：空气中的氧化

2NO + O₂ → 2NO₂

2NO (无色) + O₂ → 2NO₂ (红棕色)

NO₂ → HNO₃ + NO：与水反应

3NO₂ + H₂O → 2HNO₃ + NO

3NO₂ + H₂O → 2HNO₃ + NO

这是一个歧化反应 (+4价N → +5价和+2价)。

NO 和 NO₂ 的实验室制备与收集

NO 的制备与收集

反应：Cu + 稀 HNO₃

3Cu + 8HNO₃(稀) → 3Cu(NO₃)₂ + 2NO↑ + 4H₂O

收集：排水法 (NO不溶于水，且会与空气反应)

NO₂ 的制备与收集

反应：Cu + 浓 HNO₃

Cu + 4HNO₃(浓) → Cu(NO₃)₂ + 2NO₂↑ + 2H₂O

收集：向上排空气法 (NO₂密度比空气大，且与水反应)

氮氧化物的尾气处理

NO 和 NO₂ 都是有毒气体，需用碱液吸收处理。

吸收 NO₂

2NO₂ + 2NaOH → NaNO₃ + NaNO₂ + H₂O

NO₂是酸性氧化物，但有歧化反应。

吸收 NO (需通入O₂)

先将NO氧化为NO₂，再用碱液吸收，总反应式（按比例）为：

4NO + 3O₂ + 4NaOH → 4NaNO₃ + 2H₂O

汽车尾气净化 (三效催化剂)

2NO + 2CO (催化剂) → N₂ + 2CO₂

将有毒气体转化为无害的 N₂ 和 CO₂。

氮化合物与环境问题

酸雨

NOₓ 溶于水，生成 HNO₃。

光化学烟雾

NOₓ + 碳氢化合物在阳光下反应。

水体富营养化

过量 N, P 导致藻类疯长。

随堂练习 (一)

下列关于氮气的说法，错误的是？

(A) 分子内存在共价三键

(B) 化学性质非常活泼，易与其他物质反应

(C) 在放电条件下能与氧气反应生成NO

(D) 是工业合成氨的重要原料

练习 (一)：解析

答案：(B)

解析：

氮气分子中存在非常稳定的共价三键 (N≡N)，键能很大，难以断裂。因此，通常条件下氮气的化学性质不活泼，需要高温、高压或放电等条件才能发生反应。

随堂练习 (二)

下列关于NO和NO₂的说法，正确的是？

(A) NO是红棕色气体，NO₂是无色气体

(B) 两者都能与水反应生成硝酸

(C) NO能用排水法收集，NO₂不能

(D) 两者都是酸性氧化物

练习 (二)：解析

答案：(C)

解析：

A. NO是无色气体，NO₂是红棕色气体。
B. 只有NO₂能与水反应生成硝酸和NO (3NO₂ + H₂O → 2HNO₃ + NO)。NO不与水反应。
C. NO不溶于水且不与水反应，可用排水法收集。NO₂与水反应，不能用排水法收集，正确。
D. NO和NO₂都不是酸性氧化物 (不能直接与碱反应只生成对应的盐和水)。

随堂练习 (三)

下列不属于“氮的固定”的是？

(A) 闪电使N₂转化为NO

(B) 工业合成氨

(C) 豆科植物根瘤菌将N₂转化为NH₃

(D) NO转化为NO₂

练习 (三)：解析

答案：(D)

解析：

氮的固定是指将大气中游离态的氮 (N₂) 转化为含氮化合物的过程。A, B, C都符合此定义。D是含氮化合物之间的转化，不属于氮的固定。

随堂练习 (四)

实验室制备NO₂气体时，常用的尾气吸收液是？

(A) 浓硫酸

(B) 氢氧化钠溶液

(C) 饱和食盐水

(D) 水

练习 (四)：解析

答案：(B)

解析：

NO₂是有毒气体，不能直接排放。它能与碱液反应生成盐和水 (2NO₂ + 2NaOH → NaNO₃ + NaNO₂ + H₂O)，因此常用氢氧化钠溶液吸收尾气。

随堂练习 (五)

下列环境问题与氮氧化物(NOₓ)无关的是？

(A) 酸雨

(B) 光化学烟雾

(C) 臭氧层破坏

(D) 水体富营养化

练习 (五)：解析

答案：(C)

解析：

氮氧化物是形成酸雨（生成硝酸）和光化学烟雾的主要原因之一。含氮化合物（如化肥流失）是导致水体富营养化的重要因素。臭氧层破坏主要是由氟氯烃（如氟利昂）等物质引起的。
