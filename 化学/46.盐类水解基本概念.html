水溶液中的离子反应与平衡

（四）盐类的水解

本节课内容

盐类水解一直是大家心中最困惑的部分。这节课，我们就从零基础开始，彻底讲清盐类水解的基本概念。

高一、高二、高三的同学都适合学习，让我们开始吧！

水解的概念 (一)：弱酸根

弱酸 (如 CH₃COOH)：难电离，喜欢以分子形式存在。

弱酸根 (如 CH₃COO⁻)：在盐 (如 CH₃COONa) 中被迫单身，"怨念颇深"，总想"抢"一个 H⁺ 回来，变回稳定的分子。

水解发生：

CH₃COO⁻ 抢夺“倒霉鬼” H₂O 电离出的 H⁺：

CH₃COO⁻ + H₂O ⇌ CH₃COOH + OH⁻

结果：溶液中多出了 OH⁻，使溶液显碱性。

水解的概念 (二)：弱碱根

弱碱 (如 NH₃·H₂O)：难电离，喜欢以分子形式存在。

弱碱根 (如 NH₄⁺)：在盐 (如 NH₄Cl) 中被迫单身，总想"抢"一个 OH⁻ 回来，变回稳定的分子。

水解发生：

NH₄⁺ 抢夺 H₂O 电离出的 OH⁻：

NH₄⁺ + H₂O ⇌ NH₃·H₂O + H⁺

结果：溶液中多出了 H⁺，使溶液显酸性。

盐类水解的定义

定义：

盐电离出的离子 (特指弱酸根或弱碱根) 与水电离出的 H⁺ 或 OH⁻ 相互作用，生成弱电解质的反应。

盐类水解的性质

1. 可逆

水解是可逆反应，存在水解平衡。

2. 程度小

水解程度一般很小，（通常）无沉淀、无气体。

3. 是逆反应

水解反应是酸碱中和的逆反应。

4. 吸热

酸碱中和是放热反应，因此盐类水解是吸热反应 (ΔH > 0)。

影响因素：温度

水解是吸热反应

根据勒夏特列原理：

升高温度 (T↑) → 平衡向吸热方向 (正向) 移动
→ 水解程度增大

水解规律 (一)：有弱才水解

只有弱酸根 (如 CH₃COO⁻) 或弱碱根 (如 NH₄⁺) 才会发生水解。

无弱不水解：

强酸根 (如 Cl⁻, SO₄²⁻) 和强碱根 (如 Na⁺, K⁺) 不水解。

（它们“巴不得”以离子形式存在，不会抢 H⁺ 或 OH⁻）

判断正盐溶液的酸碱性

总口诀：谁强显谁性

（两者皆弱看不定，两者皆强显中性）

正盐酸碱性 (应用一)

强酸 + 弱碱 盐 (如 NH₄Cl, CuSO₄)

弱碱根 (NH₄⁺, Cu²⁺) 水解 → 显酸性 (酸强)

弱酸 + 强碱 盐 (如 Na₂CO₃, CH₃COONa)

弱酸根 (CO₃²⁻, CH₃COO⁻) 水解 → 显碱性 (碱强)

正盐酸碱性 (应用二)

强酸 + 强碱 盐 (如 NaCl, KNO₃)

谁都不水解 → 显中性 (都强)

弱酸 + 弱碱 盐 (如 (NH₄)₂CO₃)

两者都水解 (双水解) → 不一定 (看谁水解程度大)

(例：(NH₄)₂CO₃ 中 CO₃²⁻ 水解 > NH₄⁺ 水解，故显碱性)

特例：酸式盐 (如 NaHCO₃)

注意：

酸式盐不能用“谁强显谁性”判断！

必须 PK：电离 vs 水解

酸式根 (如 HCO₃⁻) 有两条路：

电离 (显酸)： HCO₃⁻ ⇌ H⁺ + CO₃²⁻

水解 (显碱)： HCO₃⁻ + H₂O ⇌ H₂CO₃ + OH⁻

谁的程度大，溶液就显谁的性质。

酸式盐举例 (记忆)

显碱性 (水解 > 电离)

NaHCO₃
NaHS
Na₂HPO₄

显酸性 (电离 > 水解)

NaHSO₃
NaH₂PO₄
NaHC₂O₄

特例：醋酸铵 (CH₃COONH₄)

弱酸根 CH₃COO⁻ (水解显碱性)

弱碱根 NH₄⁺ (水解显酸性)

两者水解程度恰好势均力敌。

结论：醋酸铵溶液显中性

水解规律 (二)：越弱越水解

对应的酸越弱（越难电离出 H⁺），它的酸根“抢” H⁺ 的能力就越强。

酸性越弱 → 水解程度越大 → 溶液碱性越强

“越弱越水解” (应用)

已知酸性强弱：

CH₃COOH > H₂CO₃ > HClO > HCO₃⁻

可推知，对应钠盐溶液碱性强弱 (水解程度)：

CH₃COONa < NaHCO₃ < NaClO < Na₂CO₃

问：同 pH 时，上述溶液浓度大小？

答：碱性越强的 (Na₂CO₃)，只需越稀的浓度；碱性越弱的 (CH₃COONa)，需要越浓的浓度。

c(Na₂CO₃) < c(NaClO) < c(NaHCO₃) < c(CH₃COONa)

双水解 vs 彻底双水解

双水解

弱酸根和弱碱根都发生水解。

例：CH₃COONH₄

彻底双水解

双水解相互促进，反应进行到底。

标志：生成沉淀和气体。

例：Al³⁺ 和 HCO₃⁻

彻底双水解 (原理)

以 Al³⁺ 和 HCO₃⁻ 为例：

Al³⁺ 水解：Al³⁺ + 3H₂O ⇌ Al(OH)₃ + 3H⁺ (显酸性)
HCO₃⁻ 水解：HCO₃⁻ + H₂O ⇌ H₂CO₃ + OH⁻ (显碱性)

相互促进：

Al³⁺ 水解产生的 H⁺ 与 HCO₃⁻ 水解产生的 OH⁻ 结合成水，使两个平衡均向正向移动，直至反应物耗尽。

彻底双水解 (常见离子对)

Al³⁺ 或 Fe³⁺ 与 CO₃²⁻, HCO₃⁻, S²⁻, HS⁻, AlO₂⁻, ClO⁻

NH₄⁺ 与 AlO₂⁻, SiO₃²⁻

注意：CH₃COONH₄, (NH₄)₂CO₃ 只双水解，不彻底。

彻底双水解 (方程式)

写方程式时用等号 (=)，并标明沉淀 (↓) 和气体 (↑)。

泡沫灭火器：

Al³⁺ + 3HCO₃⁻ = Al(OH)₃↓ + 3CO₂↑

制备 Fe(OH)₃：

2Fe³⁺ + 3CO₃²⁻ + 3H₂O = 2Fe(OH)₃↓ + 3CO₂↑

Al³⁺ 与 AlO₂⁻ 双水解：

Al³⁺ + 3AlO₂⁻ + 6H₂O = 4Al(OH)₃↓

随堂练习（一）

盐类水解反应的实质是？

(A) 盐电离出离子

(B) 酸碱中和反应

(C) 盐的离子与水电离的离子结合生成弱电解质

(D) 盐与水发生的复分解反应

练习题（一）：解析

答案：(C)

解析：

盐类水解的定义就是盐电离出的弱酸根或弱碱根，与水电离出的H⁺或OH⁻结合，生成了弱电解质（弱酸或弱碱）。

随堂练习（二）

下列盐溶液中，呈中性的是？

(A) NH₄Cl

(B) Na₂CO₃

(C) NaCl

(D) FeCl₃

练习题（二）：解析

答案：(C)

解析：

根据“谁强显谁性”：
(A) NH₄Cl：强酸弱碱盐，显酸性。
(B) Na₂CO₃：弱酸强碱盐，显碱性。
(C) NaCl：强酸强碱盐，不水解，显中性。
(D) FeCl₃：强酸弱碱盐，显酸性。

随堂练习（三）

加热 CH₃COONa 溶液，会发生什么？

(A) 水解程度增大，碱性增强

(B) 水解程度减小，碱性减弱

(C) 水解程度增大，酸性增强

(D) 不发生变化

练习题（三）：解析

答案：(A)

解析：

盐类水解是吸热反应。加热（升高温度）会使水解平衡 (CH₃COO⁻ + H₂O ⇌ CH₃COOH + OH⁻) 正向移动，水解程度增大，[OH⁻] 浓度增大，碱性增强。

随堂练习（四）

已知酸性：H₂CO₃ > HClO。同浓度的 NaHCO₃ 和 NaClO 溶液，pH 值更高（碱性更强）的是？

(A) NaHCO₃

(B) NaClO

(C) 两者一样

(D) 无法判断

练习题（四）：解析

答案：(B)

解析：

根据“越弱越水解”的规律：
酸性：H₂CO₃ > HClO (次氯酸更弱)
水解程度：HCO₃⁻ < ClO⁻ (次氯酸根水解更强)
碱性：NaHCO₃ < NaClO (次氯酸钠碱性更强，pH更高)

随堂练习（五）

将 AlCl₃ 溶液和 Na₂CO₃ 溶液混合，会发生什么？

(A) 生成 Al₂(CO₃)₃ 沉淀

(B) 互不反应

(C) 生成 Al(OH)₃ 沉淀和 CO₂ 气体

(D) 只生成 Al(OH)₃ 沉淀

练习题（五）：解析

答案：(C)

解析：

Al³⁺ (弱碱根) 和 CO₃²⁻ (弱酸根) 在水中相遇，会发生彻底双水解反应，相互促进直至反应到底，生成氢氧化铝沉淀和二氧化碳气体。

2Al³⁺ + 3CO₃²⁻ + 3H₂O = 2Al(OH)₃↓ + 3CO₂↑
