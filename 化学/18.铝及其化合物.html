铝及其重要化合物

—— 两性元素的全面解析

铝单质 (Al)

基本性质

  • 地壳中含量最多的金属元素
  • 银白色，质地较软

特殊的“抗腐蚀性”

  • 性质活泼，常温即可与O₂反应
  • 表面形成致密的氧化铝(Al₂O₃)薄膜
  • 该薄膜能阻止内部的铝继续被腐蚀

化学性质：与酸的反应

铝能与多种酸发生反应，但与浓酸的反应条件特殊。

与非氧化性酸 (盐酸, 稀硫酸)

2Al + 6H⁺ → 2Al³⁺ + 3H₂↑

与浓硫酸、浓硝酸

常温下：钝化，生成致密氧化膜，反应停止。

加热时：反应，生成盐、SO₂/NO₂和水。

核心性质：与强碱反应 (两性)

铝是典型的两性金属，既能与强酸反应，也能与强碱溶液反应，且均产生氢气。

与氢氧化钠溶液反应

产物为四羟基合铝酸钠和氢气。

2Al + 2NaOH + 6H₂O = 2Na[Al(OH)₄] + 3H₂↑

离子方程式：2Al + 2OH⁻ + 6H₂O → 2[Al(OH)₄]⁻ + 3H₂↑

重要应用：铝热反应

利用铝的强还原性和反应放出的大量热量，来冶炼高熔点的金属。

典型反应：焊接铁轨

2Al + Fe₂O₃ (高温) → 2Fe + Al₂O₃

特点：放出大量的热，发出耀眼的光芒，生成熔融的金属。

铝热剂：铝粉和金属氧化物（如Fe₂O₃, MnO₂, Cr₂O₃）的混合物。

氧化铝 (Al₂O₃)

俗称矾土，是典型的两性氧化物。

与强酸反应

Al₂O₃ + 6H⁺ → 2Al³⁺ + 3H₂O

与强碱反应

Al₂O₃ + 2OH⁻ + 3H₂O → 2[Al(OH)₄]⁻

性质：白色固体，熔点高（>2000°C），硬度大，难溶于水，是冶炼铝的原料和耐火材料。

氢氧化铝 (Al(OH)₃)

典型的两性氢氧化物，不溶于水，是白色胶状固体。

与强酸反应 (作碱)

Al(OH)₃ + 3H⁺ → Al³⁺ + 3H₂O

与强碱反应 (作酸)

Al(OH)₃ + OH⁻ → [Al(OH)₄]⁻

其他性质：受热不稳定，分解为氧化铝和水。可作胃药的成分（中和胃酸），也用作净水剂。

核心转化关系：“铝三角”

铝的三种重要形态 Al³⁺, Al(OH)₃, [Al(OH)₄]⁻ 之间的转化关系是考查重点。

氢氧化铝的制备

制备Al(OH)₃的关键是避免其两性导致的溶解。核心思想：用“弱”制“两性”。

从 Al³⁺ 出发：应使用弱碱（如氨水，NH₃·H₂O），过量也不溶解。
Al³⁺ + 3NH₃·H₂O → Al(OH)₃↓ + 3NH₄⁺

从 [Al(OH)₄]⁻ 出发：应通入弱酸（如CO₂），过量也不溶解。
[Al(OH)₄]⁻ + CO₂ → Al(OH)₃↓ + HCO₃⁻

随堂练习 (一)

下列物质中，既能与盐酸反应，又能与氢氧化钠溶液反应的是？

(A) Na₂CO₃

(B) Al₂O₃

(C) SiO₂

(D) Fe₂O₃

练习 (一)：解析

答案：(B)

解析：

题目要求找出两性物质。氧化铝 (Al₂O₃) 是典型的两性氧化物，既能与强酸（如盐酸）反应生成盐和水，也能与强碱（如氢氧化钠）反应生成盐和水。

随堂练习 (二)

在常温下，铝制品能稳定存在于空气中的原因是？

(A) 铝的化学性质不活泼

(B) 铝的表面形成了致密的氧化膜

(C) 铝不与氧气反应

(D) 铝的熔点很高

练习 (二)：解析

答案：(B)

解析：

铝是化学性质非常活泼的金属。它之所以在空气中表现出良好的抗腐蚀性，是因为其表面能迅速与氧气反应，生成一层致密、坚固的氧化铝(Al₂O₃)保护膜，阻止了内部的铝继续被氧化。（回顾第一页的示意图）

随堂练习 (三)

下列离子方程式中，正确的是？

(A) Al + 2OH⁻ → [Al(OH)₂]⁻ + H₂↑

(B) Al(OH)₃ + 3H⁺ → Al³⁺ + 3H₂O

(C) Al₂O₃ + 2OH⁻ → 2AlO₂⁻ + H₂O

(D) Al³⁺ + 3OH⁻ → Al(OH)₃↓ (加入过量NaOH)

练习 (三)：解析

答案：(B)

解析：

A、C的产物写法不符合新教材的[Al(OH)₄]⁻规范，且原子不守恒。D项中，若加入过量NaOH，生成的Al(OH)₃沉淀会继续溶解生成[Al(OH)₄]⁻（参考“铝三角”图示）。B是氢氧化铝与强酸反应的正确离子方程式。

随堂练习 (四)

实验室制备少量氢氧化铝，最好向AlCl₃溶液中加入？

(A) 足量NaOH溶液

(B) 适量NaOH溶液

(C) 足量氨水

(D) 少量氨水

练习 (四)：解析

答案：(C)

解析：

氢氧化铝是两性氢氧化物，能溶于强碱。若使用NaOH，用量难以控制，过量则沉淀溶解。氨水是弱碱，即使过量也不能溶解氢氧化铝。因此，加入足量氨水可以确保Al³⁺完全沉淀，是实验室制备Al(OH)₃的最佳方法。

随堂练习 (五)

下列哪个反应不属于铝热反应？

(A) Al + Fe₂O₃

(B) Al + MnO₂

(C) Al + MgO

(D) Al + V₂O₅

练习 (五)：解析

答案：(C)

解析：

铝热反应是利用铝的强还原性来冶炼比它不活泼的金属。根据金属活动性顺序，镁(Mg)的活泼性强于铝(Al)，因此铝不能置换出氧化镁中的镁，该反应不能发生。
