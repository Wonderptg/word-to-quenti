概念与原理

概念：

依据中和反应，用已知浓度的酸（或碱）来测定未知浓度的碱（或酸）的实验方法。

核心：用已知测未知

原理：

n(H⁺) = n(OH⁻)

当酸可电离的 H⁺ 物质的量 与 碱可电离的 OH⁻ 物质的量恰好完全中和时，建立等式进行计算。

滴定原理计算 (通式)

对于 n 元酸 (浓度a, 体积V₁) 和 m 元碱 (浓度b, 体积V₂) 恰好完全中和：

n(H⁺) = n(OH⁻)

(a · V₁) · n = (b · V₂) · m

(酸的mol数) × n = (碱的mol数) × m

计算示例

用 0.1 mol/L 的 NaOH 溶液滴定 20.00 mL 未知浓度的 H₂SO₄ 溶液，恰好完全中和时，消耗 NaOH 溶液 20.00 mL。求 H₂SO₄ 浓度 (c)？

n(H⁺) = n(OH⁻)

(c mol/L · 0.020 L) · 2 = (0.1 mol/L · 0.020 L) · 1

(硫酸的mol数) × 2 = (NaOH的mol数) × 1

c = 0.05 mol/L

实验仪器与试剂

试剂

标准溶液 (已知浓度)、待测溶液 (未知浓度)、酸碱指示剂、蒸馏水

仪器

酸式滴定管、碱式滴定管、滴定管夹、铁架台、锥形瓶

重点仪器：滴定管

酸式滴定管

下端为玻璃活塞。

碱式滴定管

下端为橡胶管和玻璃球。

滴定管的使用 (一)

类型 酸式滴定管 (玻璃活塞) 碱式滴定管 (橡胶管)
√ 可装 酸性溶液、氧化性溶液 (如KMnO₄)、中性溶液 碱性溶液、中性溶液
× 不可装 碱性溶液 (会腐蚀玻璃活塞使其粘住)、HF 酸性溶液、氧化性溶液 (会腐蚀橡胶管)

滴定管的使用 (二)

规格

常用 25.00 mL 或 50.00 mL

分度

最小分度为 0.1 mL

读数

精密度高，应估读至 0.01 mL (如 2.30 mL)

刻度

0 刻度在上，读数由上往下增大 (表示放出液体的体积)

滴定管操作 (一)：查漏与润洗

1. 查漏

滴定管、容量瓶、分液漏斗使用前必须检查是否漏水。

2. 润洗 (重要)

滴定管用蒸馏水洗净后，必须用待装溶液润洗 2-3 次。

（目的：防止残留的蒸馏水稀释待装溶液，造成浓度误差。）

滴定管操作 (二)：排气泡

装液后，必须赶走尖嘴处的气泡：

酸式滴定管

旋转活塞，快速放液，用溶液冲走气泡。

碱式滴定管

将橡胶管向上弯折，捏开玻璃球，让溶液向上喷出，带走气泡。

滴定管操作 (三)：读数

1. 赶走气泡后，调节液面至 0 刻度或 0 刻度以下。

2. 必须准确记录起始读数 V₁ (估读到 0.01 mL)。

3. 滴定结束后，准确记录终点读数 V₂ (估读到 0.01 mL)。

4. 消耗体积 V = V₂ - V₁。

实验步骤 (一)：准备

情景：用已知浓度的 HCl 滴定未知浓度的 NaOH (恒河水)。

1. 查漏：酸、碱滴定管均查漏。
2. 洗涤：
· 滴定管：蒸馏水洗 → 标准液/待测液 润洗
· 锥形瓶：蒸馏水洗
× 陷阱：
锥形瓶绝不能用待测液润洗！（否则待测液n偏大，V(标)偏大，C(待)偏高）

实验步骤 (二)：取液

1. 装标准液 (HCl)：

用酸式滴定管装 HCl，排气泡，记录起始读数 V₁。

2. 装待测液 (NaOH)：

用碱式滴定管准确移取 25.00 mL NaOH 溶液，放入锥形瓶中。

加入 2-3 滴酚酞指示剂。（此时溶液为红色）

实验步骤 (三)：滴定

1. 准备：锥形瓶下垫白纸，以便观察颜色变化。
2. 操作：左手控制活塞，右手摇晃锥形瓶。
3. 速率：先快后慢。接近终点时（颜色变化又褪去），应“滴加半滴”。
4. 眼睛：紧盯锥形瓶内溶液颜色变化。

滴定终点的判断 (重点)

滴定终点：

当加入最后半滴标准液时，锥形瓶中溶液颜色突变，且半分钟内不恢复成原色。

本实验终点现象 (酚酞)：

溶液由 红色 变为 无色，且半分钟不褪色。

立即关闭活塞，记录终点读数 V₂。计算 V = V₂ - V₁。重复实验 2-3 次，取平均值计算。

指示剂的选择 (一)：滴定曲线

滴定终点 ≠ 恰好完全中和点 (化学计量点)。

我们选择的指示剂，其变色范围应落在 pH 突变范围内。

在化学计量点附近，半滴溶液即可引起 pH 剧烈变化（如 pH 从 4.2 → 9.8）。

指示剂的选择 (二)：常见指示剂

指示剂 pH 变色范围 低 pH 颜色 高 pH 颜色
甲基橙 3.1 ~ 4.4 红 黄
酚酞 8.2 ~ 10.0 无色 红
石蕊 5.0 ~ 8.0 红 蓝
× 注意：不用石蕊。其变色范围太宽，颜色变化不突兀（红→紫→蓝），误差大。

指示剂的选择 (三)：结论

强酸 ⇌ 强碱 滴定：

pH 突变范围极大 (约 3 ~ 11)，酚酞 和 甲基橙 均可选用。

弱酸 ⇌ 强碱 滴定：

（后续课程：盐类水解）

恰好中和时，生成强碱弱酸盐，溶液呈碱性。突变范围偏上。

→ 只能用酚酞

强酸 ⇌ 弱碱 滴定：

（后续课程：盐类水解）

恰好中和时，生成强酸弱碱盐，溶液呈酸性。突变范围偏下。

→ 只能用甲基橙
