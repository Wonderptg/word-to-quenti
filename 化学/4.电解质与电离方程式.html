看透化学反应的本质

—— 离子反应

一个熟悉的反应，一个全新的视角

溶液中真正发生变化的，其实只有 Cu²⁺ 和 OH⁻ 离子。

离子反应，就是帮助我们揪出“真正干活的”离子的工具！

一、离子反应的本质

定义：

在溶液中或熔融状态下，有离子参加或有离子生成的反应。

核心思想：

抓主要矛盾，忽略“吃瓜群众”（即那些在反应前后没有变化的旁观离子）。

二、离子方程式：记录本质的语言

用实际参加反应的离子符号来表示离子反应的式子。

化学方程式：

CuSO₄ + 2NaOH = Cu(OH)₂↓ + Na₂SO₄

离子方程式：

Cu²⁺ + 2OH⁻ = Cu(OH)₂↓

小试牛刀

在NaCl溶液和AgNO₃溶液的反应中，“旁观离子”是？

(A) Na⁺ 和 NO₃⁻

(B) Ag⁺ 和 Cl⁻

(C) 只有 Na⁺

(D) 只有 NO₃⁻

小试牛刀：解析

答案：(A)

解析：

该反应的离子方程式是 Ag⁺ + Cl⁻ = AgCl↓。

Ag⁺ 和 Cl⁻ 离子结合生成了沉淀，它们是实际参与反应的离子。而 Na⁺ 和 NO₃⁻ 在反应前后没有发生任何变化，仍然以离子的形式存在于溶液中，所以它们是“旁观离子”。

三、书写离子方程式的“四字诀”

1. 写：写出正确的化学方程式。

2. 拆：把易溶于水的强电解质拆成离子形式。

3. 删：删去反应前后完全相同的“旁观离子”。

4. 查：检查两边的原子个数和电荷总数是否守恒。

“四字诀”应用

例题：请用“四字诀”写出盐酸和氢氧化钠溶液反应的离子方程式。

1. 写: HCl + NaOH = NaCl + H₂O

2. 拆: H⁺ + Cl⁻ + Na⁺ + OH⁻ = Na⁺ + Cl⁻ + H₂O (水是弱电解质，不拆)

3. 删: H⁺ + Cl⁻ + Na⁺ + OH⁻ = Na⁺ + Cl⁻ + H₂O

4. 查: (左右电荷均为0，原子守恒)

最终结果：

H⁺ + OH⁻ = H₂O

“拆”的规则：哪些物质不能拆？

难溶物质

如 AgCl, BaSO₄, Cu(OH)₂

弱电解质

如 H₂O, CH₃COOH, NH₃·H₂O

气体

如 H₂, CO₂, SO₂

氧化物

如 CuO, Fe₂O₃

简单记：沉、弱、气、氧，还有单质，都不拆！

四、实战演练

例题：写出稀硫酸和氢氧化钡溶液反应的离子方程式。

1. 写: H₂SO₄ + Ba(OH)₂ = BaSO₄↓ + 2H₂O

2. 拆: 2H⁺+SO₄²⁻ + Ba²⁺+2OH⁻ = BaSO₄↓ + 2H₂O

3. 删: (没有旁观离子可删)

4. 查: (电荷守恒，原子守恒)

最终结果：

2H⁺ + SO₄²⁻ + Ba²⁺ + 2OH⁻ = BaSO₄↓ + 2H₂O

今日总结

• 我们明白了离子反应是发生在溶液中化学反应的本质。

• 我们学会了用离子方程式来描述这种本质，剔除了“旁观离子”的干扰。

• 我们掌握了书写离子方程式的“写、拆、删、查”四字诀，特别是“拆”的规则。

随堂练习（一）

下列反应中，哪一个属于离子反应？

(A) 氢气在氯气中燃烧

(B) 氯化钠溶液与硝酸银溶液混合

(C) 固体氯化钾和浓硫酸加热

(D) 碳在空气中燃烧

练习题（一）：解析

答案：(B)

解析：

离子反应的核心条件是在溶液中或熔融状态下，有离子参与或生成。选项A, C, D都是在非溶液/非熔融状态下进行的反应，而B是两种溶液混合，有离子参与生成了AgCl沉淀，是典型的离子反应。

随堂练习（二）

下列离子方程式书写正确的是？

(A) 铁与稀硫酸反应：2Fe + 6H⁺ = 2Fe³⁺ + 3H₂↑

(B) 碳酸钙与盐酸反应：CO₃²⁻ + 2H⁺ = H₂O + CO₂↑

(C) 氢氧化铜与稀硝酸反应：OH⁻ + H⁺ = H₂O

(D) 氯化钡溶液与硫酸钠溶液反应：Ba²⁺ + SO₄²⁻ = BaSO₄↓

练习题（二）：解析

答案：(D)

解析：

  • (A) 铁与稀酸反应生成的是亚铁离子(Fe²⁺)，不是Fe³⁺。错误。
  • (B) 碳酸钙(CaCO₃)是难溶物，不能拆成离子。错误。
  • (C) 氢氧化铜(Cu(OH)₂)是难溶物，不能拆。错误。
  • (D) 氯化钡和硫酸钠都是易溶的强电解质，可以拆；硫酸钡是沉淀，不能拆。书写完全正确。

随堂练习（三）

下列物质中，在书写离子方程式时不能拆开的是？

(A) 硝酸钾 (KNO₃)

(B) 氢氧化钠 (NaOH)

(C) 醋酸 (CH₃COOH)

(D) 硫酸 (H₂SO₄)

练习题（三）：解析

答案：(C)

解析：

根据“拆”的规则，我们需要将易溶于水的强电解质拆成离子。而弱电解质、难溶物、气体、氧化物等都不能拆。

  • (A) 硝酸钾是易溶于水的盐，是强电解质，要拆。
  • (B) 氢氧化钠是强碱，是强电解质，要拆。
  • (C) 醋酸是弱酸，属于弱电解质，不能拆。
  • (D) 硫酸是强酸，是强电解质，要拆。

随堂练习（四）

在Na₂SO₄溶液和BaCl₂溶液的反应中，没有参与反应的“旁观离子”是？

(A) Ba²⁺ 和 SO₄²⁻

(B) Na⁺ 和 Cl⁻

(C) 只有 Na⁺

(D) 只有 Cl⁻

练习题（四）：解析

答案：(B)

解析：

该反应的离子方程式是 Ba²⁺ + SO₄²⁻ = BaSO₄↓。

比较反应前后的离子，我们可以发现 Ba²⁺ 和 SO₄²⁻ 结合生成了沉淀，它们是实际参与反应的离子。而 Na⁺ 和 Cl⁻ 在反应前后没有发生任何变化，仍然以离子的形式存在于溶液中，所以它们是“旁观离子”。

随堂练习（五）

下列离子方程式中，电荷不守恒的是？

(A) Zn + 2H⁺ = Zn²⁺ + H₂↑

(B) Ca²⁺ + CO₃²⁻ = CaCO₃↓

(C) Fe + Cu²⁺ = Fe²⁺ + Cu

(D) H⁺ + OH = H₂O

练习题（五）：解析

答案：(D)

解析：

“查”是书写离子方程式的最后一步，就是要检查反应前后原子个数和电荷总数是否相等。

  • (A) 左边电荷: 2*(+1) = +2。右边电荷: +2。电荷守恒。
  • (B) 左边电荷: (+2) + (-2) = 0。右边是中性物质，电荷为0。电荷守恒。
  • (C) 左边电荷: +2。右边电荷: +2。电荷守恒。
  • (D) 左边电荷: +1。右边是中性物质，电荷为0。左边+1，右边0，电荷不守恒。正确的应为 H⁺ + OH⁻ = H₂O。
