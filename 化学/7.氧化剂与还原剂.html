氧化剂与还原剂

—— 揭开反应背后“操盘手”的神秘面纱

情景导入：酒驾测试的化学魔法

交警让司机对着一个仪器吹气，如果仪器变了颜色，就说明司机喝酒了。

这正是一个经典的氧化还原反应。司机呼出的酒精（乙醇），被仪器里的橙色物质（重铬酸钾）氧化了。

橙色物质被还原成了绿色物质。颜色的变化，就暴露了酒精的存在。

核心定义：化学反应的“操盘手”

氧化剂

在反应中得电子，化合价降低的反应物。

（特征：化合价降低）

还原剂

在反应中失电子，化合价升高的反应物。

（特征：化合价升高）

常见的氧化剂（抢匪）

第一类：消毒液类

84消毒液的有效成分是NaClO。里面的Cl是+1价，非常不安分，总想着抢电子变回-1价。

第二类：金属离子中的“贵族”

比如银离子Ag⁺、铜离子Cu²⁺。在反应 Zn + Cu²⁺ → Zn²⁺ + Cu 中，就是Cu²⁺这个“抢匪”把锌的电子抢走了。

常见的还原剂（富翁）

第一类：低价态的非金属

有臭鸡蛋气味的H₂S。这里的S是-2价，已经是最低价，只能想办法“赚钱”（失电子）升高价态。

第二类：活泼金属

比如镁条Mg。在反应 2Mg + O₂ → 2MgO 中，镁把电子给了氧气，自己从0价变成了+2价。

特殊物质：既是“抢匪”也是“富翁”

双氧水 H₂O₂ 里的氧是-1价，不高不低，处于中间。

遇到更强的“抢匪” (如KMnO₄)

H₂O₂被迫当“富翁”，失去电子被氧化，生成O₂。

遇到“富翁” (如H₂S)

H₂O₂扮演“抢匪”，得到电子被还原，生成H₂O。

产物概念对接：名字反着来

还原剂
被氧化
(失电子)
氧化产物
氧化剂
被还原
(得电子)
还原产物

千万别搞混了：“剂”在反应前，“产物”在反应后！

核心口诀：万能的“武功秘籍”

升、失、氧、还原剂、还原性

降、得、还、氧化剂、氧化性

升高价 → 失电子 → 氧化反应 → 是还原剂 → 有还原性

降低价 → 得电子 → 还原反应 → 是氧化剂 → 有氧化性

典例分析 (1)：小试牛刀

分析反应：Cl₂ + H₂S → 2HCl + S

第一步 (标价): Cl从0价变为-1价；S从-2价变为0价。

第二步 (看升降): Cl化合价降低，S化合价升高。

第三步 (用口诀):

  • “降、得、还、氧化剂” → Cl₂ 是氧化剂，HCl 是还原产物。
  • “升、失、氧、还原剂” → H₂S 是还原剂，S 是氧化产物。

典例分析 (2)：内部的转移

分析反应：2KClO₃ → 2KCl + 3O₂↑ (加热)

标价发现：

  • Cl元素：化合价从+5价 降低 到-1价。
  • O元素：化合价从-2价 升高 到0价。

结论：电子在KClO₃这种物质内部发生了转移！它自己把自己“氧化还原”了，所以，KClO₃既是氧化剂，又是还原剂。

典例分析 (3)：期末的“大BOSS”

3Cu + 8HNO₃(稀) → 3Cu(NO₃)₂ + 2NO↑ + 4H₂O

• Cu: 0价 → +2价，升高，是还原剂。

• HNO₃中的N: +5价 → +2价 (在NO中)，降低，所以HNO₃是氧化剂。

但是！ 生成物Cu(NO₃)₂中还有一部分N元素，依然是+5价，化合价没变！

结论：参加反应的8份硝酸中，只有2份被还原（体现氧化性），剩下的6份没变价，只是提供了酸根（体现酸性）。

课堂小结

  • 我们认识了化学反应中的“抢匪”和“富翁”：氧化剂和还原剂。
  • 我们掌握了识别它们的强大口诀：“升、失、氧、还原剂”和“降、得、还、氧化剂”。
  • 解决所有氧化还原问题的核心钥匙是：紧紧抓住化合价的升降变化！

既然我们知道了谁升谁降，那一个复杂的化学方程式，我们该如何快速地把它配平呢？

随堂练习 (一)

在反应 Fe + CuSO₄ → FeSO₄ + Cu 中，哪种物质是氧化剂？

(A) Fe

(B) CuSO₄

(C) FeSO₄

(D) Cu

练习题 (一)：解析

答案：(B)

解析：

首先标出变价元素的化合价：Fe从0价升高到+2价，CuSO₄中的Cu从+2价降低到0价。

根据口诀“降、得、还、氧化剂”，化合价降低的元素（Cu）所在的反应物是氧化剂。所以，CuSO₄是氧化剂。

随堂练习 (二)

在反应 H₂ + CuO → Cu + H₂O 中，哪种物质是还原剂？

(A) H₂

(B) CuO

(C) Cu

(D) H₂O

练习题 (二)：解析

答案：(A)

解析：

首先标出变价元素的化合价：H₂中的H从0价升高到+1价，CuO中的Cu从+2价降低到0价。

根据口诀“升、失、氧、还原剂”，化合价升高的元素（H）所在的反应物是还原剂。所以，H₂是还原剂。

随堂练习 (三)

下列关于氧化还原反应的说法中，正确的是？

(A) 物质失去电子，被还原

(B) 物质得到电子，被氧化

(C) 还原剂发生还原反应

(D) 氧化剂发生还原反应

练习题 (三)：解析

答案：(D)

解析：

氧化剂在反应中得到电子，化合价降低，发生的是还原反应。选项(D)正确。

  • (A) 物质失去电子，被氧化。
  • (B) 物质得到电子，被还原。
  • (C) 还原剂失去电子，发生氧化反应。

随堂练习 (四)

在反应 2Na + Cl₂ → 2NaCl 中，被氧化的元素是？

(A) 钠 (Na)

(B) 氯 (Cl)

(C) 两者都被氧化

(D) 两者都被还原

练习题 (四)：解析

答案：(A)

解析：

首先标出化合价：Na从0价升高到+1价，Cl从0价降低到-1价。

化合价升高的元素被氧化。因此，钠(Na)元素被氧化。

随堂练习 (五)

某元素在反应中，化合价从+3价变为+1价，则该元素？

(A) 被氧化

(B) 被还原

(C) 既被氧化又被还原

(D) 没有变化

练习题 (五)：解析

答案：(B)

解析：

元素的化合价从+3降低到+1。

化合价降低，意味着该元素在反应中得到了电子，发生了还原反应，因此该元素被还原。
