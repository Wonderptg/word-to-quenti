水溶液中的离子反应与平衡

（二）水的电离与离子积常数

水的电离

精确的导电实验表明，纯水能极微弱地电离。水是一种极弱的电解质。

复杂历程 (人教版)：

H₂O + H₂O ⇌ H₃O⁺ + OH⁻

(一个水分子电离出的H⁺被另一个水分子结合，形成水合氢离子 H₃O⁺)

简化写法 (常用)：

H₂O ⇌ H⁺ + OH⁻

注意：必须使用可逆符号 (⇌)。

水的离子积常数 (Kw)

定义：

当水的电离 (H₂O ⇌ H⁺ + OH⁻) 达到平衡时，电离产物 [H⁺] 和 [OH⁻] 浓度的乘积是一个常数。

Kw = [H⁺] · [OH⁻]

Kw 称为水的离子积常数，简称水的离子积。

Kw 的数值 (25°C)

实验测得，在 25°C 时：

1 L 纯水 (约 55.56 mol) 中，只有 1 × 10⁻⁷ mol 的 H₂O 分子发生电离。

H₂O ⇌ H⁺ + OH⁻

电离 10⁻⁷ mol → 产生 10⁻⁷ mol H⁺ 和 10⁻⁷ mol OH⁻

所以，在 1 L 溶液中：
[H⁺] = 10⁻⁷ mol/L
[OH⁻] = 10⁻⁷ mol/L

Kw = [H⁺] · [OH⁻] = (10⁻⁷) · (10⁻⁷) = 10⁻¹⁴

(25°C 时)

影响 Kw 的因素：温度

唯一因素：Kw 只受温度影响

温度不变，Kw 不变。

温度如何影响 Kw？

水的电离 H₂O ⇌ H⁺ + OH⁻ 是一个吸热反应 (ΔH > 0)。

（类比：酸碱中和是放热，其逆反应电离就是吸热）

根据勒夏特列原理：
升高温度 (T↑) → 平衡正向 (→) 移动 → [H⁺]↑, [OH⁻]↑ → Kw 增大

影响“水的电离平衡”的因素

注意：Kw 只受温度影响，但水的电离平衡（即 [H⁺] 和 [OH⁻] 的相对大小）受多种因素影响。

H₂O ⇌ H⁺ + OH⁻

因素 (一)：温度

升高温度 (T↑)

移动：正向 (→) (吸热方向)

[H⁺], [OH⁻]：均增大 ↑

Kw：增大 ↑

降低温度 (T↓)

移动：逆向 (←) (放热方向)

[H⁺], [OH⁻]：均减小 ↓

Kw：减小 ↓

因素 (二)：加酸 (同离子效应)

在纯水中加入 HCl 气体 (假设温度不变)：

改变： [H⁺] 增大 ↑ (来自HCl的电离)。

移动： 平衡逆向 (←) 移动 (同离子效应，抑制了水的电离)。

电离程度(水)： 减小 ↓。

最终 [H⁺]： 增大 ↑ (外加的 >> 水被抑制的)。

最终 [OH⁻]： 减小 ↓ (平衡逆移导致)。

Kw： 不变 (因为温度不变)。

因素 (三)：加碱 (同离子效应)

在纯水中加入 NaOH 固体 (假设温度不变)：

改变： [OH⁻] 增大 ↑ (来自NaOH的电离)。

移动： 平衡逆向 (←) 移动 (同离子效应，抑制了水的电离)。

电离程度(水)： 减小 ↓。

最终 [H⁺]： 减小 ↓ (平衡逆移导致)。

最终 [OH⁻]： 增大 ↑ (外加的 >> 水被抑制的)。

Kw： 不变 (因为温度不变)。

因素 (四)：加活泼金属

在纯水中加入 Na 固体 (假设温度不变)：

改变： Na 与水电离出的 [H⁺] 反应 (2Na + 2H₂O → 2NaOH + H₂↑)，导致 [H⁺] 减小 ↓。

移动： 平衡正向 (→) 移动 (补充 H⁺)。

电离程度(水)： 增大 ↑ (促进了水的电离)。

最终 [H⁺]： 减小 ↓ (溶液变碱性)。

最终 [OH⁻]： 增大 ↑ (平衡正移导致)。

Kw： 不变 (因为温度不变)。

Kw 的适用范围

水的离子积常数 Kw = [H⁺]·[OH⁻] 不仅适用于纯水，也适用于任何稀的电解质水溶液（酸、碱、盐溶液）。

Kw 在酸碱溶液中的应用

酸溶液 (如 HCl)

[H⁺] 主要来自 HCl，[OH⁻] 唯一来自 H₂O。

[H⁺] (总) = [H⁺] (酸) + [H⁺] (水)

[OH⁻] (总) = [OH⁻] (水)

碱溶液 (如 NaOH)

[OH⁻] 主要来自 NaOH，[H⁺] 唯一来自 H₂O。

[H⁺] (总) = [H⁺] (水)

[OH⁻] (总) = [OH⁻] (碱) + [OH⁻] (水)

关键结论：在任何水溶液中，水电离出的 [H⁺] 一定等于 水电离出的 [OH⁻]。

Kw 应用实例 (25°C)

0.1 mol/L 的 HCl 溶液：

[H⁺] (总) ≈ [H⁺] (酸) = 0.1 M

[OH⁻] (总) = Kw / [H⁺] = 10⁻¹⁴ / 0.1 = 10⁻¹³ M

由于 [OH⁻] 唯一来自水，所以：
[OH⁻] (水) = 10⁻¹³ M
[H⁺] (水) = [OH⁻] (水) = 10⁻¹³ M

(对比纯水的 10⁻⁷ M，水的电离被极大抑制了)

Kw 应用实例 (等效抑制)

0.1 mol/L 的 NaOH 溶液：

[OH⁻] (总) ≈ [OH⁻] (碱) = 0.1 M

[H⁺] (总) = Kw / [OH⁻] = 10⁻¹⁴ / 0.1 = 10⁻¹³ M

由于 [H⁺] 唯一来自水，所以：
[H⁺] (水) = 10⁻¹³ M

等效抑制：

0.1 M 的 HCl 和 0.1 M 的 NaOH 对水电离的抑制程度相同。

（都使水电离出的 [H⁺] 或 [OH⁻] 从 10⁻⁷ 降低到了 10⁻¹³）

随堂练习（一）

水的电离方程式书写正确的是？

(A) H₂O = H⁺ + OH⁻

(B) H₂O ⇌ H⁺ + OH⁻

(C) 2H₂O ⇌ H₃O⁺ + OH⁻

(D) H₂O → H₂↑ + O₂↑

练习题（一）：解析

答案：(B)

解析：

水是弱电解质，电离过程是可逆的，必须使用可逆符号 (⇌)。 (A) 错。 (C) 是人教版写法，但计量数应为 H₂O + H₂O。(D) 是电解，不是电离。

随堂练习（二）

在 25°C 时，纯水中 [H⁺] 和 [OH⁻] 的浓度分别是多少 (mol/L)？

(A) 10⁻⁷, 10⁻⁷

(B) 10⁻¹⁴, 10⁻¹⁴

(C) 0, 0

(D) 1, 1

练习题（二）：解析

答案：(A)

解析：

25°C 时，纯水电离达到平衡，[H⁺] = [OH⁻] = 10⁻⁷ mol/L。此时 Kw = [H⁺]·[OH⁻] = 10⁻¹⁴。

随堂练习（三）

影响水的离子积常数 (Kw) 的唯一因素是？

(A) 溶液的酸碱性

(B) 溶液的浓度

(C) 温度

(D) 压强

练习题（三）：解析

答案：(C)

解析：

Kw 是一个平衡常数，平衡常数只受温度影响。加酸或加碱会改变 [H⁺] 和 [OH⁻]，但它们的乘积 (Kw) 在温度不变时是恒定的。

随堂练习（四）

向纯水中加入少量 NaOH 固体，会发生什么？

(A) Kw 增大，水的电离被促进

(B) Kw 减小，水的电离被抑制

(C) Kw 不变，水的电离被促进

(D) Kw 不变，水的电离被抑制

练习题（四）：解析

答案：(D)

解析：

1. 假设温度不变，则 Kw 不变。
2. 加入 NaOH，[OH⁻] 增大，发生同离子效应，使 H₂O ⇌ H⁺ + OH⁻ 平衡逆向移动，水的电离被抑制。

随堂练习（五）

升高纯水的温度（如从 25°C 升到 100°C），会发生什么？

(A) [H⁺] 增大, Kw 增大

(B) [H⁺] 减小, Kw 减小

(C) [H⁺] 增大, Kw 不变

(D) [H⁺] 减小, Kw 增大

练习题（五）：解析

答案：(A)

解析：

水的电离是吸热反应。升高温度，平衡正向移动，[H⁺] 和 [OH⁻] 都会增大。因此，它们的乘积 Kw 也会增大。
