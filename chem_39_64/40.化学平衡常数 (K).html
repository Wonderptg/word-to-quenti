化学平衡常数 (K)

K值的计算与应用

实验引入：H₂ + I₂ ⇌ 2HI

新教材通过展示多组实验数据（“不是体育彩票！”），让我们探究一个问题：

当反应 H₂(g) + I₂(g) ⇌ 2HI(g) 达到平衡时，各物质的平衡浓度之间是否存在某种定量关系？

实验探究 (一)：457.6 °C

在 457.6 °C 时，进行了多组实验。无论起始浓度如何，也无论是从正向（投H₂、I₂）还是逆向（投HI）开始...

...当达到平衡时，计算下面这个比值：

[HI]² / [H₂][I₂]

实验发现：这个比值始终接近一个常数，平均值 K ≈ 48.7

实验结论 (一)

结论 1

在一定温度下，[HI]² / [H₂][I₂] 是一个常数。

结论 2

这个常数与反应的起始浓度大小无关。

结论 3

这个常数与从正向还是逆向建立平衡无关。

实验探究 (二)：改变温度

将实验温度改为 425.6 °C，重复上述实验。

...当达到平衡时，再次计算该比值：

[HI]² / [H₂][I₂]

实验发现：这个比值仍然是一个常数，但平均值 K ≈ 54.47

实验结论 (二)

这个比值（常数）与浓度、投料方式无关。

温度改变，常数发生变化。 (48.7 → 54.47)

结论：化学平衡常数 K 只受温度影响。

什么是化学平衡常数 (K)？

定义：

在一定温度下，当一个可逆反应达到化学平衡时，生成物浓度幂之积 与 反应物浓度幂之积的比值是一个常数。

平衡常数的表达式

对于反应： mA + nB ⇌ pC + qD

K = [C]p [D]q / ([A]m [B]n)

注意：

[C], [D], [A], [B] 必须是物质达到平衡时的物质的量浓度。

K的注意事项 (一)：固体/液体

重要规则：

表达式中不列入 纯固体 (s) 和 纯液体 (l) 的浓度。

（因为它们的浓度视为常数，已合并到 K 值中）

K的注意事项 (一)：示例

包含固体：

CaCO₃(s) ⇌ CaO(s) + CO₂(g)

K = [CO₂]

(CaCO₃ 和 CaO 均为固体，不写入)

稀溶液中的水：

2CrO₄²⁻(aq) + 2H⁺(aq) ⇌ Cr₂O₇²⁻(aq) + H₂O(l)

K = [Cr₂O₇²⁻] / ([CrO₄²⁻]² [H⁺]²)

(H₂O 为纯液体溶剂，不写入)

K的注意事项 (二)：反应方向

K值与方程式的书写方式有关。如果反应方向逆写：

A + 2B ⇌ 3C + D (平衡常数为 K₁)

3C + D ⇌ A + 2B (平衡常数为 K₂)

K₂ = 1 / K₁

（正、逆反应的平衡常数互为倒数）

K的注意事项 (三)：计量数

如果方程式中的化学计量数扩大或缩小 n 倍：

A + B ⇌ 2C (平衡常数为 K₁)

2A + 2B ⇌ 4C (平衡常数为 K₂)

K₂ = (K₁) ²

（系数变为 n 倍，K 变为 Kⁿ）

K 与 ΔH 的关系对比

方程式操作 ΔH 的变化 K 的变化
反应逆写 等值异号 ( -ΔH ) 互为倒数 ( 1/K )
系数 × n n 倍 ( n·ΔH ) n 次方 ( Kⁿ )
反应相加 相加 ( ΔH₁ + ΔH₂ ) 相乘 ( K₁ · K₂ )

K的注意事项 (四)：单位

1. 必须使用平衡浓度 (mol/L)，不能使用物质的量 (mol)。

2. 必须使用平衡时的浓度，不能使用任意时刻的浓度。

K的注意事项 (五)：水 (H₂O)

不写入：

1. 作为纯液体溶剂的稀薄水溶液 (aq) 中的 H₂O(l)。

要写入：

1. 作为气态反应物或生成物的 H₂O(g)。
(例: C(s) + H₂O(g) ⇌ CO(g) + H₂(g))

2. 在非水溶液（如有机反应）中生成的 H₂O(l)。
(例: 酯化反应)

化学平衡常数的意义

K 值是衡量一个可逆反应在一定温度下进行限度（程度）的定量标志。

K 值越大

[生成物] 比例越大，[反应物] 比例越小。

正反应进行的程度越大，反应越完全，转化率越高。

K 值越小

[生成物] 比例越小，[反应物] 比例越大。

正反应进行的程度越小，反应越不完全，转化率越低。

K值大小的意义

K > 10⁵

可认为该反应进行得基本完全。

K < 10⁻⁵

可认为该反应基本不进行（逆反应进行得基本完全）。

K的应用：浓度商 (Q)

K 值是在平衡状态下的浓度比值。

如果在任意时刻，我们将瞬时浓度代入 K 的表达式，得到的值称为浓度商 (Qc)。

Qc = [C]p [D]q / ([A]m [B]n)

（表达式与K相同，但代入的是任意时刻的浓度）

Q 与 K 的比较 (判断方向)

Q < K

[生成物]少 / [反应物]多

反应正向进行 (→)

Q > K

[生成物]多 / [反应物]少

反应逆向进行 (←)

Q = K

浓度比值 = 平衡常数

反应达到平衡状态

Q 与 K 的比较 (记忆法)

把 < 和 > 看作钉子，用锤子把它敲平 (敲成 =)。

Q < K

🔨 →

钉子尖在左，向右敲

Q > K

← 🔨

钉子尖在右，向左敲

Q 与 K 比较 (示例)

反应 A + B ⇌ C + D，已知某温度下 K = 2。

某时刻测得 [A]=[B]=[C]=[D] = 1 mol/L。

1. 计算 Q：

Q = ([C][D]) / ([A][B]) = (1 * 1) / (1 * 1) = 1

2. 比较 Q 和 K：

Q (1) < K (2)

结论：反应未达平衡，正向 (→) 进行。

另一个指标：平衡转化率 (α)

平衡转化率 (α) 也能表示反应的限度，且更直观。

α = (已转化的反应物量 / 反应物初始总量) * 100%

例：投 1 mol A，平衡时 A 剩余 0.4 mol。

转化量 = 1 - 0.4 = 0.6 mol

转化率 α = (0.6 / 1) * 100% = 60%

随堂练习 (计算题)

已知可逆反应 M + N ⇌ P + Q (均为气体)，在某不变的温度下进行。

(1) 起始浓度 [M]=1, [N]=2.4 (mol/L)。达平衡时 M 的转化率为 60%。求 N 的转化率。

(2) 起始浓度 [M]=4, [N]=a (mol/L)。达平衡时 [P]=2 (mol/L)。求 a 的值。

(3) 起始浓度 [M]=b, [N]=b (mol/L)。达平衡时 M 的转化率是多少？

练习解析 (1)：三段式

M + N ⇌ P + Q
初 (mol/L) 1 2.4 0 0
转 (mol/L) -0.6 -0.6 +0.6 +0.6
平 (mol/L) 0.4 1.8 0.6 0.6

M 的转化量 = 1 * 60% = 0.6 mol/L

N 的转化率 α(N) = (转化的量 / 初始量) * 100%

α(N) = (0.6 / 2.4) * 100% = 25%

练习解析 (2)：K值不变

关键：温度不变，K 不变。

1. 先求 K 值 (用第1问数据)：

K = ([P][Q]) / ([M][N]) = (0.6 * 0.6) / (0.4 * 1.8) = 0.36 / 0.72 = 0.5

M+ N⇌ P+ Q
初4a00
转-2-2+2+2
平2a-222

2. 代入 K 求解：

K = ( [P][Q] ) / ( [M][N] ) = 0.5

( 2 * 2 ) / ( 2 * (a-2) ) = 0.5

2 / (a-2) = 0.5

a - 2 = 4

a = 6

练习解析 (3)：求解转化率

关键：温度不变，K 仍为 0.5。

M+ N⇌ P+ Q
初bb00
转-x-x+x+x
平b-xb-xxx

代入 K 求解 x：

K = (x * x) / ((b-x) * (b-x)) = 0.5

x² / (b-x)² = 0.5

x / (b-x) = √0.5 ≈ 0.707 (或 1/√2)

x = 0.707b - 0.707x

1.707x = 0.707b

x ≈ 0.414b

计算转化率 α(M)：

α = (转化的量 / 初始量) = x / b = 0.414b / b = 0.414

α = 41.4%
